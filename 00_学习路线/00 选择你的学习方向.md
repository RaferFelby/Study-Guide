# 选择你的学习方向

> [!nav] 页面导航
> [[00 从这里开始|学习首页]]

## 第一次学习

先走 [[00_学习路线/01 从零开始建立共同基础|11 讲首次学习主线]]。完成一次本地模拟请求后再选择方向，不需要现在决定整库学习计划。

## 下一段学什么

选一个与你当前目标有关的方向。每条方向列出阶段与前置，按自己的练习结果继续。需要先看全貌时，打开 [[00_学习路线/07 学习流程图#再选择一个后续方向|五个方向的流程图]]。

| 我当前想做什么 | 选择路线 | 第一轮到哪里 |
|---|---|---|
| 做能查资料、调用工具的助手 | [[00_学习路线/02 学习Agent与RAG应用\|Agent 与 RAG]] | 阶段 1～3：留下查询与工具循环的正常、失败轨迹 |
| 理解模型怎样训练和改进 | [[00_学习路线/03 学习模型训练与大模型算法\|训练与大模型算法]] | 阶段 1～3：完成一次小模型与 LoRA 对照 |
| 用一张表解决分类或回归问题 | [[00_学习路线/04 学习传统机器学习与数据分析\|机器学习与数据分析]] | 阶段 1～2：完成公平比较和一页实验报告 |
| 解释速度、显存或底层计算 | [[00_学习路线/05 学习推理系统与GPU工程\|推理系统与 GPU]] | 服务入门可从 HTTP 开始；显存／并行、算子先完成阶段 1 |
| 把一个需求交成能演示的结果 | [[00_学习路线/06 学习需求分析与项目交付\|需求分析与交付]] | 阶段 1～4：完成正常／失败演示与操作交接 |

> [!tip] 阶段之间怎样切换
> 按所选路线列出的课次范围学习；到范围末尾返回路线，用“本阶段完成判断”检查产物。已经学过的共同课程，检查自己仍能独立解释与操作后继续，不必重新顺读整单元。
>
> 单元目录按主题编号，不决定跨单元学习顺序。切换方向时沿用自己的真实记录；时间安排在学习总表里按实际情况调整。
