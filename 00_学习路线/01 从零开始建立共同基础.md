## 现在只做什么

先完成下面 11 讲，目标是从自己写一个工单统计函数，走到能检查一次本地模拟请求。每讲保留完整解释、练习和排错；首次先完成跟做与本地独立题，明确标为真实服务调查或进阶的任务以后再做。

从 [[01_学习指南/01_Python工程化/逐讲学习/01 运行Python并统计工单|第 1 步：运行 Python 并统计工单]] 开始。主线中的页首标有“首次主线”，按页末“首次主线下一步”继续；跨单元时也直接进入下一篇，不必读完当前单元全部课程。

一个阶段只使用下方指定的主要工程目录。前两个阶段沿用同一组工单练习；进入测试、API 阶段时再各换一次目录。所有阶段共用工作区根目录的 `.venv`。

## 阶段 1：先运行与计数

**目标：把小函数写清楚。** 运行问候和工单计数，再拆成模块、认识数据类。

在 VS Code 打开 `01_学习指南/01_Python工程化/示例工程/`，终端也使用该目录。

1. [[01_学习指南/01_Python工程化/逐讲学习/01 运行Python并统计工单|运行Python并统计工单]]
2. [[01_学习指南/01_Python工程化/逐讲学习/02 把函数拆成模块并运行项目|把函数拆成模块并运行项目]]
3. [[01_学习指南/01_Python工程化/逐讲学习/03 用类型标注与数据类表达记录|用类型标注与数据类表达记录]]

**本阶段完成判断：** 合上答案，改变工单输入并解释计数；说清哪个文件定义函数、哪个文件调用函数。

## 阶段 2：建立可检查的工程

**目标：让输入与失败可解释。** 沿用前一阶段的工单程序，依次练引用与复制、逐条读取、异常与文件清理。`ContextVar` 的请求隔离部分可以后读；本阶段先掌握错误怎样发出、怎样处理和怎样关闭文件。

在 VS Code 打开 `01_学习指南/01_Python工程化/示例工程/`，终端也使用该目录。

4. [[01_学习指南/01_Python工程化/逐讲学习/04 分清对象引用与浅深复制|分清对象引用与浅深复制]]
5. [[01_学习指南/01_Python工程化/逐讲学习/05 用生成器逐条处理数据|用生成器逐条处理数据]]
6. [[01_学习指南/01_Python工程化/逐讲学习/06 看懂报错并安全管理资源|看懂报错并安全管理资源]]

**本阶段完成判断：** 给出一条合法和一条非法记录；能解释复制后的变化、生成器执行顺序，以及异常发生时资源如何清理。

## 阶段 3：用测试检查一次统计

**目标：用测试固定预期。** 在测试单元中继续练同一种工单统计任务。首次只学本阶段列出的一讲，更复杂的测试数据准备、依赖替换、自动检查和完整复现流程留到有需求时继续。

在 VS Code 打开 `01_学习指南/02_测试与实验复现/示例工程/`，终端也使用该目录。

7. [[01_学习指南/02_测试与实验复现/逐讲学习/01 写第一个 pytest 测试|写第一个 pytest 测试]]

**本阶段完成判断：** 亲自观察一条统计测试通过，再故意改变预期使它失败，解释原因并恢复正确预期；补一条错误输入检查。

## 阶段 4：跑通本地模拟请求

**目标：检查一次完整请求。** 在同一个 API 工程完成请求、指令、输出校验和有限重试。假服务按固定规则生成结果；这里不要求真实模型、密钥或付费调用。三版 Prompt 的评估输出留到后续评估课解释。

在 VS Code 打开 `01_学习指南/11_LLM_API与Prompt/示例工程/`，终端也使用该目录。

8. [[01_学习指南/11_LLM_API与Prompt/逐讲学习/01 发出一次安全的模型 API 请求|发出一次安全的模型 API 请求]]
9. [[01_学习指南/11_LLM_API与Prompt/逐讲学习/02 写清指令与组织上下文|写清指令与组织上下文]]
10. [[01_学习指南/11_LLM_API与Prompt/逐讲学习/03 用 Schema 验证结构化输出|用 Schema 验证结构化输出]]
11. [[01_学习指南/11_LLM_API与Prompt/逐讲学习/04 为超时限流与缓存设置边界|为超时限流与缓存设置边界]]

**本阶段完成判断：** 运行 `demo.py`，核对首次请求次数为 1、重复请求命中缓存为 True、限流后尝试次数为 2；解释结构化结果与输入证据，并构造一次参数不合法的失败。

## 首次完成后

本轮完成标准：亲自运行统计、检查失败、执行测试，并能解释本地请求中的可校验结果。按自己的练习判断是否达到标准；尚未独立做到的地方留到下一次继续。完整 API、RAG、Agent、训练和 GPU 属于后续方向课程。
