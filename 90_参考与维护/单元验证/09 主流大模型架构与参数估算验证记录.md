## 配置来源与方法

- Qwen2.5-7B 配置快照来自官方 Hugging Face 仓库提交 7c128df 的 config.json。
- Llama 3.1-8B 快照来自 Meta 官方 llama-models 仓库模型清单 arch_args；源链接指向 main 分支，可能变化，需复核。
- 参数估算包括 Dense SwiGLU Decoder 的投影矩阵、词嵌入/输出头和 RMSNorm scale；偏置按字段处理。它不是 checkpoint 逐张量计数。
- KV Cache 假设普通注意力层各自保存 K 和 V；未计分页、对齐、量化元数据、临时工作区等运行开销。

## 作者侧验证

环境：Python 3.13.12；不需要 GPU，也没有安装或变更依赖。

- Python 3.13.12 共享解释器运行 Qwen2.5-7B 配置：7,615,487,488 个参数，约 14.18 GiB BF16 权重；B=4、T=8192 时普通 KV Cache 约 1.75 GiB。
- 同一解释器运行 Llama 3.1-8B 配置：8,030,261,248 个参数，约 14.96 GiB BF16 权重；B=4、T=8192 时普通 KV Cache 约 4.00 GiB。
- 示例工程测试：5 passed；Ruff lint 与 format 检查通过；共享环境 pip check 显示 No broken requirements found。

这些是读取静态配置后按代码公式得出的结果，不代表模型已加载、GPU 已部署或真实服务达到相应显存/速度表现。

## 限制

模型仓库配置会更新，引用时必须注明具体型号和配置来源。MoE、MLA、滑动窗口混合层不由 Dense 参数和标准 KV 公式直接计数。
