## 实际测试与输出

在工程目录运行 `..\..\..\.venv\Scripts\python.exe -m unittest discover -s tests -v`：11 项通过。覆盖正负优势裁剪、平坦分支梯度、组内标准化／全同奖励、PPO 和组相对策略真实更新、固定种子重复、top-1/top-2 路由、潜在路径等价、量化零输入与误差界、适配器冻结以及非法形状／非有限输入。

七个 `demo.py` 分支都通过实际命令行运行并解析 JSON：

| 实验 | 本次结果 | 不能据此声称什么 |
|---|---|---|
| clip | 约 1.2、0.5、-1.5、-0.8 | PPO 严格限制所有参数或 KL |
| group | 约 -1.34164、-0.44721、0.44721、1.34164；常数组全 0 | 只做标准化就是完整 GRPO |
| ppo | 动作 1 概率 0.5→0.9887564122 | 语言推理能力或真实奖励泛化提高 |
| grpo | 动作 1 概率 0.5→0.9876086086 | 与 PPO 的大模型性能排名 |
| moe | 输出约 1.119203、2.880797 | 已完成稀疏计算加速或专家训练 |
| latent | 两路径相同，误差 0；缓存元素 12 与 3 | 任意 K/V 无损压缩或完整 MLA 实现 |
| adapter | MSE 0.025→约 0.00000159001；基座不变且无梯度 | NF4 QLoRA 或实际 4-bit 内存收益 |

代码使用固定两动作环境、共享低秩构造和人为可表达的目标矩阵。PPO 的价值是一个标量；组相对路径无价值参数；两者均额外使用明确的精确离散 KL 教学项，不冒充原论文完整训练器。adapter 使用 int8 容器存放 -7～7 级编码，没有真正打包低比特权重。

作者统一验证脚本 `.author-tools/verify_extensions_20261023.py` 与证据 `.author-tools/extensions-7962ddd526254618a00b24791ab71adc/evidence.json` 同时记录所有实际命令、输出和失败码。这些是工作区相对路径；个人成果仍需亲自运行。
