## 复现排错

如果出现 ModuleNotFoundError: No module named torch，先确认解释器指向仓库根目录共享环境，再按根目录 README 修复 PyTorch 安装。CUDA、驱动和 PyTorch wheel 必须匹配；没有 GPU 时使用 CPU 路径，不把 CPU 结果当成 CUDA 性能结果。若恢复 checkpoint 报配置不匹配，使用原训练配置继续，或有意重新开始训练。
