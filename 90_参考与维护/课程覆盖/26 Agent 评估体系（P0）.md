## 模块 26：Agent 评估体系（P0）

教材状态：已编写单元 19；详见 [[01_学习指南/19_Agent评估体系/00 Agent 评估体系学习地图|学习地图]]。合成机制验证已执行，真实高质量业务集与人工/LLM裁判校准仍需学习者实践，不视为验收已完成。

**学习内容**

- **K26-01** 场景覆盖、难度分层、黄金答案和轨迹标注； 见 [[01_学习指南/19_Agent评估体系/逐讲学习/02 建立分组评估集并保留难例|详细教程]]。
- **K26-02** 任务完成率、工具选择、参数准确率、证据忠实度； 见 [[01_学习指南/19_Agent评估体系/逐讲学习/03 分开检查检索规划工具与回答|详细教程]]。
- **K26-03** LLM-as-Judge、人工盲测、位置偏差与自我偏好； 见 [[01_学习指南/19_Agent评估体系/逐讲学习/04 校准裁判并抽查争议样本|详细教程]]。
- **K26-04** 回归集、对抗集和线上指标。 见 [[01_学习指南/19_Agent评估体系/逐讲学习/06 建立回归对抗集与线上观察计划|详细教程]]。

**验收标准**

- [ ] **C26-01** 构建 50～100 条高质量评估集，并保留难例； 见 [[01_学习指南/19_Agent评估体系/逐讲学习/02 建立分组评估集并保留难例|详细教程]]。
- [ ] **C26-02** 将检索、规划、工具、回答等环节分开打分； 见 [[01_学习指南/19_Agent评估体系/逐讲学习/03 分开检查检索规划工具与回答|详细教程]]。
- [ ] **C26-03** Judge 与人工标注做一致性检查并抽查争议样本； 见 [[01_学习指南/19_Agent评估体系/逐讲学习/04 校准裁判并抽查争议样本|详细教程]]。
- [ ] **C26-04** 每次关键修改自动输出回归报告和成本变化。 见 [[01_学习指南/19_Agent评估体系/逐讲学习/05 对比版本并输出成本回归报告|详细教程]]。

样本字段、超时计分、成功判定、人工/Judge 一致性与报告格式统一按第十四节执行；第一轮允许人工评分，不以接入 Judge 作为开始评估的前提。
