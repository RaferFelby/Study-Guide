## 模块 29：Code 执行器、沙箱与 Agent 安全（P0）

教材状态：已编写单元 21；详见 [[01_学习指南/21_Agent安全与执行边界/00 Agent安全与执行边界学习地图|学习地图]]。作者机制验证与学习者验收分开，未测/简化范围见验证记录。

权限与输入信任边界是核心；任意代码执行器只在项目确有需要时实现，属于 P1 扩展。没有执行器时，将对应验收记为“不适用”，先验证数据库和业务工具的访问边界。

**学习内容**

- **K29-01** 代码执行器、进程/容器隔离、超时与资源限制； 见 [[01_学习指南/21_Agent安全与执行边界/逐讲学习/06 判断是否需要代码执行器与沙箱|详细教程]]。
- **K29-02** 文件、网络、凭证和工具最小权限； 见 [[01_学习指南/21_Agent安全与执行边界/逐讲学习/03 限制文档路径与输出资源|详细教程]]。
- **K29-03** Prompt 注入、间接注入、数据外泄和越权调用； 见 [[01_学习指南/21_Agent安全与执行边界/逐讲学习/01 分清用户指令与不可信资料|详细教程]]。
- **K29-04** 内容安全、审计和红队测试。 见 [[01_学习指南/21_Agent安全与执行边界/逐讲学习/05 运行注入越权用例并检查审计|详细教程]]。

**验收标准**

- [ ] **C29-01** 若集成执行器，限制时间、内存、文件路径和网络能力，并测试超限终止； 见 [[01_学习指南/21_Agent安全与执行边界/逐讲学习/06 判断是否需要代码执行器与沙箱|详细教程]]。
- [ ] **C29-02** 针对已定义的注入测试集验证工具授权和数据访问边界，记录绕过与残余风险；权限校验在模型外执行，不能只依赖提示词； 见 [[01_学习指南/21_Agent安全与执行边界/逐讲学习/02 在模型外执行工具权限校验|详细教程]]。
- [ ] **C29-03** 构造至少三类注入和越权用例，并记录防护结果； 见 [[01_学习指南/21_Agent安全与执行边界/逐讲学习/05 运行注入越权用例并检查审计|详细教程]]。
- [ ] **C29-04** 高风险动作默认拒绝或请求明确确认，并保留审计记录。 见 [[01_学习指南/21_Agent安全与执行边界/逐讲学习/04 把高风险确认绑定到完整动作|详细教程]]。
