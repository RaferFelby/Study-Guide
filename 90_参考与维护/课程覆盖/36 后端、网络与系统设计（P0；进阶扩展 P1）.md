## 模块 36：后端、网络与系统设计（P0；进阶扩展 P1）

教材状态：已编写六讲；[[01_学习指南/18_后端网络与系统设计/00 后端网络与系统设计学习地图|学习地图]]、[[90_参考与维护/单元验证/18 后端网络与系统设计验证记录|作者验证]]。本机HTTP接口、用户隔离、持久任务、缓存去重与重启演练。学习者待验收；限制按验证记录说明。

**学习内容**

- **K36-01** HTTP/JSON、REST、状态码、SSE 与 WebSocket 适用范围；（见[[01_学习指南/18_后端网络与系统设计/逐讲学习/03 把长任务改为提交与轮询|详细教程]]）
- **K36-02** API 验证、认证/授权、会话、分页、错误响应和请求 ID；（见[[01_学习指南/18_后端网络与系统设计/逐讲学习/02 校验接口参数并隔离用户|详细教程]]）
- **K36-03** 进程/线程/协程、阻塞 IO、超时和取消；（见[[01_学习指南/18_后端网络与系统设计/逐讲学习/04 理解线程超时取消与断开|详细教程]]）
- **K36-04** 数据持久化、Redis 缓存的键与失效、任务队列与去重；（见[[01_学习指南/18_后端网络与系统设计/逐讲学习/05 加入有边界的缓存与任务去重|详细教程]]）
- **K36-05** 单体服务到分层设计，容量估算、故障恢复、配置与依赖管理。（见[[01_学习指南/18_后端网络与系统设计/逐讲学习/06 画出系统边界并演练重启恢复|详细教程]]）

**验收标准**

- [ ] **C36-01** 用 FastAPI 等框架提供查询、任务状态和健康检查接口；（见[[01_学习指南/18_后端网络与系统设计/逐讲学习/01 让两个程序通过 HTTP 交谈|详细教程]]）
- [ ] **C36-02** 验证非法参数、无权限、上游超时、客户端断开和服务重启行为；（见[[01_学习指南/18_后端网络与系统设计/逐讲学习/04 理解线程超时取消与断开|详细教程]]）
- [ ] **C36-03** 画出客户端 → API → 模型/检索/工具 → 数据库的数据流，注明同步/异步边界；（见[[01_学习指南/18_后端网络与系统设计/逐讲学习/06 画出系统边界并演练重启恢复|详细教程]]）
- [ ] **C36-04** 测试用户间的数据与缓存隔离；（见[[01_学习指南/18_后端网络与系统设计/逐讲学习/02 校验接口参数并隔离用户|详细教程]]）
- [ ] **C36-05** 只在有重复请求或长任务需求时引入缓存/队列，并说明一致性或重复执行的处理方法。（见[[01_学习指南/18_后端网络与系统设计/逐讲学习/05 加入有边界的缓存与任务去重|详细教程]]）

入门范围可参照 [FastAPI 官方教程](https://fastapi.tiangolo.com/tutorial/)。Redis、队列和微服务不作为 MVP 的强制依赖。
