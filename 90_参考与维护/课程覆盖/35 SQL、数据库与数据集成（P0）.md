**学习内容**

- **K35-01** SELECT、JOIN、GROUP BY、子查询、CTE、窗口函数和 NULL；（见[[01_学习指南/17_SQL数据库与数据集成/逐讲学习/03 用子查询 CTE 与窗口函数排名|详细教程]]）
- **K35-02** 主外键、唯一约束、索引、事务、分页与连接池；（见[[01_学习指南/17_SQL数据库与数据集成/逐讲学习/04 理解事务索引与稳定分页|详细教程]]）
- **K35-03** 参数化查询、只读角色、查询限时/限行、迁移与备份；（见[[01_学习指南/17_SQL数据库与数据集成/逐讲学习/05 给 Agent 一个受限只读查询工具|详细教程]]）
- **K35-04** 从文档/API/业务表到统一 schema，增量同步、幂等导入和来源追踪。（见[[01_学习指南/17_SQL数据库与数据集成/逐讲学习/06 完成增量导入与备份恢复|详细教程]]）

**验收标准**

- [ ] **C35-01** 建立产品、工单、用户等小型关系表，用 SQL 回答至少 10 个业务问题；（见[[01_学习指南/17_SQL数据库与数据集成/逐讲学习/01 建立关系表并查询工单|详细教程]]）
- [ ] **C35-02** 能解释一次 JOIN 重复计数问题，并测试 NULL 和无匹配数据；（见[[01_学习指南/17_SQL数据库与数据集成/逐讲学习/02 用 JOIN 和 NULL 避免统计错账|详细教程]]）
- [ ] **C35-03** 用 EXPLAIN 检查一个慢查询，解释索引选择；（见[[01_学习指南/17_SQL数据库与数据集成/逐讲学习/04 理解事务索引与稳定分页|详细教程]]）
- [ ] **C35-04** Agent 使用受限只读账户、参数化查询和行数/耗时上限；若支持生成 SQL，再加入语句限制和隔离测试；（见[[01_学习指南/17_SQL数据库与数据集成/逐讲学习/05 给 Agent 一个受限只读查询工具|详细教程]]）
- [ ] **C35-05** 完成一次重复导入不产生重复数据的验证，以及备份恢复演练。（见[[01_学习指南/17_SQL数据库与数据集成/逐讲学习/06 完成增量导入与备份恢复|详细教程]]）

可从 SQLite 做原型，再按部署需要使用 PostgreSQL；参考 [PostgreSQL 官方教程](https://www.postgresql.org/docs/current/tutorial.html)。
