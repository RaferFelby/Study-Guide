## 模块 02：Python 工程化（P0）

教材状态：已作为单元 01 完成六讲详细教程并验证参考工程；[[01_学习指南/01_Python工程化/00 Python 工程化学习地图|学习地图]]、[[90_参考与维护/单元验证/01 Python工程化验证记录|参考工程验证记录]]。本节仍使用原模块 02 的 K02/C02 编号，学习者待验收。

**学习内容**

- **K02-01** 装饰器、生成器、上下文管理器、异步编程、异常链；
- **K02-02** 类型注解、数据类、协议/抽象接口、模块与包；
- **K02-03** 配置管理、结构化日志、依赖与虚拟环境；
- **K02-04** 性能分析、资源释放、并发安全。

**验收标准**

- [ ] **C02-01** 实现带参数的计时、重试和指数退避装饰器；
- [ ] **C02-02** 用生成器流式处理 10 万条数据，并记录峰值内存；
- [ ] **C02-03** 建立可安装的多模块项目，核心代码通过静态检查；
- [ ] **C02-04** 日志包含时间、级别、请求 ID 和异常堆栈，并支持文件轮转；
- [ ] **C02-05** 不在代码中硬编码密钥，使用环境变量或密钥管理方案。
