## 模块 12：LLM API、Prompt 与结构化输出（P0）

**学习内容**

- **K12-01** system/user/tool 等消息语义与指令优先级；见 [[01_学习指南/11_LLM_API与Prompt/逐讲学习/01 发出一次安全的模型 API 请求|第 1 讲：发出一次安全的模型 API 请求]] 与 [[01_学习指南/11_LLM_API与Prompt/逐讲学习/02 写清指令与组织上下文|第 2 讲：写清指令与组织上下文]]。
- **K12-02** Few-shot、任务分解、上下文组织；见 [[01_学习指南/11_LLM_API与Prompt/逐讲学习/02 写清指令与组织上下文|第 2 讲：写清指令与组织上下文]]。
- **K12-03** JSON Schema、受约束输出、解析与修复；见 [[01_学习指南/11_LLM_API与Prompt/逐讲学习/03 用 Schema 验证结构化输出|第 3 讲：用 Schema 验证结构化输出]]。
- **K12-04** 超时、限流、重试、幂等性和缓存；见 [[01_学习指南/11_LLM_API与Prompt/逐讲学习/04 为超时限流与缓存设置边界|第 4 讲：为超时限流与缓存设置边界]]。

**验收标准**

- [ ] **C12-01** 对同一任务设计三版 Prompt，并以固定评估集比较；见 [[01_学习指南/11_LLM_API与Prompt/逐讲学习/05 用固定评估集比较三个 Prompt|第 5 讲：用固定评估集比较三个 Prompt]]。夹具只测试 evaluator，真实模型评估仍需另行运行。
- [ ] **C12-02** 结构化输出同时进行 schema 校验和语义校验；见 [[01_学习指南/11_LLM_API与Prompt/逐讲学习/03 用 Schema 验证结构化输出|第 3 讲：用 Schema 验证结构化输出]]。
- [ ] **C12-03** 统计格式成功率、任务成功率、延迟和 token 成本；见 [[01_学习指南/11_LLM_API与Prompt/逐讲学习/05 用固定评估集比较三个 Prompt|第 5 讲：用固定评估集比较三个 Prompt]]；真实成本需使用当前服务商报价。
- [ ] **C12-04** 对解析失败设置有限重试与可观测的降级路径；见 [[01_学习指南/11_LLM_API与Prompt/逐讲学习/04 为超时限流与缓存设置边界|第 4 讲：为超时限流与缓存设置边界]]。
