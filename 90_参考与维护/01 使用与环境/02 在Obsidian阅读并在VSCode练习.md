## 阅读与定位

- **找当前页的内容：** 打开右侧“大纲”，直接跳到本讲的解释、练习或常见错误。
- **继续下一步：** 首次主线按页末“首次主线下一步”继续；其他课程按“下一讲”继续。页首仍可返回上一讲，不必到文件夹重新选课。
- **先做题再看答案：** 部分参考答案放在可展开的提示框里；先尝试，再点开对照。
- **下次接着读：** 把正在学的那一讲加入 Obsidian“书签”。在文件列表中右键该页，选择“加入书签”。
- **找回某个概念：** 用左侧搜索或快速切换输入“生成器”“异常”“重试”等关键词；章节文件名和别名都尽量保留这些词。

## 练习与记录

文档解释在 Obsidian 中阅读，源码、测试和输出在 VS Code 查看。先确认终端所在的示例工程目录，再使用共享解释器。跟做完成后改一个输入，预测并核对结果；还不能独立完成时如实记录。

## 阅读版式怎样使用

- 页首的浅色导航区用于确认当前单元、返回上一讲和继续下一讲；页末单独突出本轮的下一步。
- 单元地图页首可直达“前置、课表、完成后”。首次主线涉及的 Python、测试和 API 地图先展开本轮课次，其他单元内课程放在“后续再学”中；需要继续该方向时再展开。
- 按路线只学一部分课次时，在范围末尾使用“路线续读”中的链接返回原阶段，继续下一项或检查产物；继续读完整单元时再用“下一讲”。同一课次供多个方向使用时，选择自己刚才所在的方向。
- 方向路线中的课程按步骤分行；“按阶段跳转”可直达指定阶段。地图页末列出相关方向时，只返回你当前正在走的那一条。
- 长章节可以展开“本讲导航”跳到概念、操作、练习和排错位置。参考答案继续在题目后按需要展开。
- 长命令与代码保持原缩进，超出阅读区时左右滚动；宽表也可以左右查看，避免中文被挤成逐字换行。
- 学习总表先显示按阶段组织的五列简表，需要排期或填写备注时再展开完整字段。完整表可以横向查看，名称与表头便于对照。
- 普通教材的属性不占用阅读首屏，切到编辑视图仍可查看；作者参考页保留日期等属性，便于判断记录范围。

若打开的页面仍显示旧版式，先切到另一篇笔记，再重新打开。仍未生效时，在 Obsidian“设置 → 外观 → CSS 代码片段”确认已有的 `ai-learning` 已开启；本工作区不需要安装第三方主题。

## 点击链接后怎样返回

每讲页首显示当前单元，页末的“继续学习”突出下一步。需要查看源码、运行命令和完成清单时，展开下面的“练习与记录”。跨单元复习后，使用 Obsidian 左上角的后退按钮返回刚才的位置；当前单元的地图会带你回到所在主题和方向阶段。

## 第一次打开示例工程

1. 在Obsidian打开本地图，按第01讲开始。需要补Python操作时，返回 [[01_学习指南/01_Python工程化/逐讲学习/01 运行Python并统计工单|运行Python基础]]；文件与异常返回 [[01_学习指南/01_Python工程化/逐讲学习/06 看懂报错并安全管理资源|异常与资源管理]]。不要仅凭能运行就跳过解释。
2. 在VS Code选择“文件→打开文件夹”，定位当前单元内的 `示例工程`，与 `demo.py` 或 `experiments.py` 所在目录一致。阅读本目录README的“代码导航”。教材留在Obsidian。
3. 通过“终端→新建终端”打开PowerShell。提示符末尾应为 `示例工程`。共享解释器在工作区根 `.venv\Scripts\python.exe`；从这里用三个 `..` 向上回到根。若终端处在别处，先打开正确工程目录，而不是试着增加/减少点号。
4. 在VS Code选择工作区共享Python解释器；如果选择列表没有出现，使用“输入解释器路径”指向工作区根 `.venv\Scripts\python.exe`。不要为本单元创建新虚拟环境。
5. 复制下面运行命令，先对照预期结果，再读对应源码。命令里的 `--output-dir` 或 `--output` 是脚本参数，指定新的输出目录或文件；已有同名证据时换名字，避免覆盖。

> [!warning] 遇到报错先检查
> 路径不存在：检查终端目录和共享环境是否实际存在。找不到模块：核对是否使用共享解释器、是否在本示例工程；不要把其他单元同名模块加到全局路径。缺包：先记录Python版本、完整报错和现有环境，按工作区规则提出安装方案获批准后再安装。测试通过仅覆盖所列条件，不是生产保证。
