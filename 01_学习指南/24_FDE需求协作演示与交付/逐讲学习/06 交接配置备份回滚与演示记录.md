## 本讲任务与前置

把工程交给另一个人，使他知道怎样启动、配置、更新、备份、回滚和排错，并能听懂演示的业务意义。Runbook是按条件执行的操作手册；回滚是恢复先前已核对的版本/配置，不等于无条件把代码退回旧提交。前置是文件与Path、上一讲验收记录、单元20降级边界。

## 安装和配置先写明白

本例使用工作区共享Python3.13和标准库，不需要新增依赖；pytest/Ruff只是已有作者检查工具。README说明终端A/B启动、参数端口/source-url、资料路径、停止Ctrl+C和四类预期结果。真实交付到另一台机器不能复制Windows `.venv` 跨平台，要按版本清单重建并实际验证。

配置用命令参数，未引入.env库。8766是合成源，8765是应用；仅127.0.0.1，无真实认证/云部署。本例公开demo身份不可当生产密钥。政策数据更新必须先验证字段和来源，真实授权与生效日期另由负责人决定。

## 备份更新回滚的最小实验

在示例工程创建 `lesson_restore.py`：

```python
import json
from pathlib import Path
from shutil import copyfile
from adapter import validate_policies

root = Path(__file__).parent
folder = root / "lesson-backup-01"
folder.mkdir(exist_ok=False)
active = folder / "active.json"
backup = folder / "backup.json"
copyfile(root / "fixtures" / "policies-v1.json", active)
copyfile(active, backup)
copyfile(root / "fixtures" / "policies-v2.json", active)
updated = validate_policies(json.loads(active.read_text(encoding="utf-8")))
print("更新：", updated[0]["version"])
copyfile(backup, active)
restored = validate_policies(json.loads(active.read_text(encoding="utf-8")))
print("恢复：", restored[0]["version"])
print(active.read_bytes() == backup.read_bytes())
```

预期更新v2、恢复v1、True。mkdir只允许新目录，重跑先改lesson-backup-02，不覆盖旧记录。copyfile按已明确目标复制文件；本例只改新建active，不改夹具。相同字节支持这次复制恢复成功，不证明真实数据库/多版本迁移都能这样回滚。

如果要让源使用active，停止源后按其实际文件路径设置 `--data`，重启并从应用确认引用版本/答案。重新导入资料不应只看文件有了，还需契约、实际查询和失败回归。源在启动时读取资料，复制后不重启仍用旧内存记录。

## 五分钟业务演示与十分钟技术讲解

五分钟脚本：0～1分钟用户过程与范围；1～3分钟正常与资料不足；3～4分钟访客拒权和源故障；4～5分钟来源/人工复核、未测与下一步。技术十分钟：2分钟架构/契约、2分钟身份与失败、2分钟四类UAT与测试、2分钟版本/备份/恢复、2分钟依赖/限制与扩展。

你需要实际计时演练并记录观察者或自我模拟反馈，不能因为脚本写好就登记“已完成5分钟真人演示”。作者已跑HTTP场景，但没有替你做口头演讲、浏览器交互或真实客户验收。

## 交接中的故障处理

打不开页面：核对应用进程/端口；源连接失败：核对源进程/source-url；source格式错：停自动答复、检查字段/版本；越权或不明来源：暂停扩大试用并保留脱敏证据；版本回退：检查代码/数据契约是否兼容，重跑四场景。不能为了恢复可用而绕过权限。

故障复盘记录预期/实际/影响、时间线、证据、已确认与待证原因、临时恢复和防复发措施。可参考 [Google SRE排错方法](https://sre.google/sre-book/effective-troubleshooting/) 的观察—假设—验证思路；本页提供的是当前合成工程的操作约定，不是对所有服务的通用生产保证。

## 练习与答案

跟做：v2→v1且字节一致。独立：为什么复制active后必须重新启动本例源？迁移：真实数据库升级时写回滚前必须核对的三项，不操作生产库。

> [!example]- 参考答案
> 本例启动时读取JSON并保存到handler使用的内存，文件变化不会自动刷新。真实数据库要核对备份完整/可恢复性、Schema与旧代码兼容、更新期间写入怎样处理；回滚代码不自动回滚数据。演示反馈应标观察者/日期、具体问题、实际修改与再验收结果，模拟者不能冒充客户。
