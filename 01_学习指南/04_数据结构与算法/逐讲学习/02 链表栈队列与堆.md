## 这一讲要解决什么问题

不同任务需要不同的“顺序规则”：撤销操作要后进先出，排队处理要先进先出，取出最高优先级任务又不是普通排队。链表、栈、队列和堆分别表达这些规则。理解规则比记住类名更重要。

## 链表：节点通过引用连接

数组把元素连续地放在一段可按下标访问的结构中；链表则让每个节点保存一个值和“下一个节点在哪里”。链表插入节点时不必移动整段元素，但想访问第 100 个节点，通常要从头走过去，因此按位置访问是 O(n)。

~~~python
class ListNode:
    def __init__(self, value: int, next_node: "ListNode | None" = None):
        self.value = value
        self.next = next_node


def reverse_list(head: ListNode | None) -> ListNode | None:
    previous = None
    current = head
    while current is not None:
        following = current.next
        current.next = previous
        previous = current
        current = following
    return previous
~~~

反转时必须先保存 following。如果先把 current.next 改掉而没有保存旧的下一个节点，后面的链表就找不到了。循环不变式是：每轮开始时，previous 已经是反转好的部分，current 是还没处理的部分。

## 栈和队列：先确定取出顺序

- 栈（stack）是后进先出，像一摞盘子；Python 列表的 append 和 pop 可以自然表示栈。
- 队列（queue）是先进先出，像窗口排队；用 collections.deque，从左侧 popleft，不要频繁对列表使用 pop(0)，因为后续元素要整体移动。
- 括号匹配、撤销、深度优先搜索常用栈；任务调度、广度优先搜索常用队列。

~~~python
def is_valid_parentheses(text: str) -> bool:
    pairs = {")": "(", "]": "[", "}": "{"}
    stack: list[str] = []
    for char in text:
        if char in "([{":
            stack.append(char)
        elif char in pairs:
            if not stack or stack.pop() != pairs[char]:
                return False
    return not stack
~~~

上面的函数只处理括号字符；如果题目还允许普通文本，需要先明确普通字符是否忽略。每个字符最多进出栈一次，时间 O(n)，栈空间 O(n)。

## 堆：快速取出最小或最大元素

堆是一种维护“当前最优元素”的结构。Python 的 heapq 是最小堆：heappush 加入元素，heappop 取出当前最小值。它适合 Top-K、合并有序流、任务优先级队列。

如果要维护“最大的 K 个”，常用大小为 K 的最小堆：堆顶是当前 K 个候选中最小的，遇到更大的值就替换它。这样空间是 O(k)，扫描是 O(n log k)，比完整排序的 O(n log n) 更适合 k 很小的场景。

## 实际应用：Top-K、LRU 和边界

示例工程中的 top_k_frequent 使用计数表加最小堆处理频率；LRUCache 使用字典和有序键记录“最近使用”。LRU 的全称是 Least Recently Used，意思是容量满时淘汰最久没有使用的条目。真实项目中可以使用标准库或成熟库，不要为了面试手写出未经测试的缓存。

动手时先检查：k = 0、k 大于元素数量、空输入、多个元素频率相同、缓存容量为 0。边界规则必须从题目契约中确定，不能凭感觉返回结果。

## 常见错误

- 链表反转时丢失下一个节点。
- 用列表 pop(0) 实现大队列，却没有意识到每次删除都要移动剩余元素。
- 把堆当成完全排序结构；堆只保证堆顶优先，不能直接认为遍历顺序就是有序。
- LRU 只保存键值，却没有更新访问顺序，导致淘汰结果错误。

## 练习与答案解析

### 跟做练习：用栈判断回文

输入一个字符串，忽略空格和大小写后判断是否正读反读相同。先写清是否忽略标点，再实现。

> [!example]- 参考思路
> 规范化字符串后，用左右指针即可，不一定非要用栈。这个练习的重点是比较“结构需求”和“多余工具”：如果只需要两端比较，双指针空间更小。

### 独立练习

实现一个队列模拟器，依次处理 push、pop 和 peek 操作。完成标准：空队列取出时行为明确；说明每个操作的复杂度；至少测试先进先出顺序。

### 迁移练习

解释在 Agent 任务调度中，普通队列和优先级队列分别适合什么场景。至少举出一个“优先级高但不能无限插队”的公平性风险，并提出限制办法。

## 本讲小结

链表解决节点连接和局部插入，栈表达后进先出，队列表达先进先出，堆维护当前最优元素。看到题目先问“下一步应该取谁”，再决定使用哪种结构。
