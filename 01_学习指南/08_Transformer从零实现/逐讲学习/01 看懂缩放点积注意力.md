## 本讲目标与先修知识

读完后，你应能说出 Query、Key、Value 的作用，写出注意力的四步计算，标出分数矩阵的形状，并解释为什么点积要除以 `√d_k`。先修分别见 [[01_学习指南/05_数学概率与优化/逐讲学习/01 向量矩阵与张量形状|点积、乘法与转置]]、[[01_学习指南/05_数学概率与优化/逐讲学习/02 按轴计算并分清数组视图与副本|数组轴]]、[[01_学习指南/05_数学概率与优化/逐讲学习/05 从指数与对数走到稳定softmax|softmax 与加权求和]]和 [[01_学习指南/06_PyTorch训练闭环/逐讲学习/01 Tensor设备与广播|Tensor 形状]]。本讲先用一个头，不涉及 mask；补充课的 NumPy 函数只用于理解，不替换本工程可自动求导的 PyTorch 实现。

## 为什么需要注意力

一句话中不同位置需要互相参考。例如读到“猫追狗，因为它跑得快”时，“它”需要参考前文。注意力为每个位置计算一组权重，再从其他位置收集信息。类比成“检索卡片”有助于理解，但真实机制是矩阵点积、归一化和加权求和，不会查询外部数据库。

每个位置有三个向量：

- Query（查询，Q）：当前这个位置想找什么信息。
- Key（键，K）：每个位置提供的匹配特征。
- Value（值，V）：匹配后真正取回的信息。

Q 和 K 的点积表示匹配程度；softmax 把分数变成总和为 1 的权重；权重加权 V 得到新表示。

## 最小例子：两个位置

忽略批次和多个头，只看一个样本的两个 token，每个向量维度为 2。形状约定：`Q、K、V=[T,D]`，其中 `T=2` 是 token 数，`D=2` 是每个向量的特征数。

```text
Q = [[1, 0], [0, 1]]
K = [[1, 0], [1, 1]]
V = [[10, 0], [0, 20]]
```

先算 `Q @ K.T` 得到 `[[1, 1], [0, 1]]`。除以 `√2` 后，对每行做 softmax。第一行的两个位置匹配程度相同，所以输出会平均读取两个 Value；第二行更偏向第二个 Value。分数形状是 `[T,T]`：每个 Query 对所有 Key 都有一个分数。

## 为什么要缩放

在继续解释缩放之前，先把手算变成一次可以观察的运行。在 VS Code 打开本单元 `示例工程`，新建 `lesson_attention.py`，保存以下完整内容：

```python
import math

import torch

from app.attention import scaled_dot_product_attention

query = torch.tensor([[1.0, 0.0], [0.0, 1.0]])
key = torch.tensor([[1.0, 0.0], [1.0, 1.0]])
value = torch.tensor([[10.0, 0.0], [0.0, 20.0]])
scores = query @ key.T / math.sqrt(query.shape[-1])
weights = torch.softmax(scores, dim=-1)
output = weights @ value
torch.set_printoptions(precision=4, sci_mode=False)
print("权重", weights)
print("输出", output)

reference = scaled_dot_product_attention(
    query.reshape(1, 1, 2, 2),
    key.reshape(1, 1, 2, 2),
    value.reshape(1, 1, 2, 2),
    is_causal=False,
)
print("与工程一致", torch.allclose(output, reference[0, 0]))
```

在示例工程目录的 PowerShell 运行 `..\..\..\.venv\Scripts\python.exe lesson_attention.py`。本次固定 CPU，无需训练模型；输出约为：

```text
权重 tensor([[0.5000, 0.5000],
        [0.3302, 0.6698]])
输出 tensor([[ 5.0000, 10.0000],
        [ 3.3024, 13.3952]])
与工程一致 True
```

逐步读执行顺序：`.T` 转置二维 K，`@` 做矩阵乘法，`query.shape[-1]` 是每个 Query 的维度 2，`math.sqrt` 取平方根。`softmax(...,dim=-1)` 沿最后的 Key 轴，把每一行分数转成权重；再乘 V 得到输出。显示小数位只影响打印，不先舍入计算值。

工程接口要求 `[B,H,T,D]`，所以将二维例子增加两个长度为 1 的维度；`reference[0,0]` 取回唯一 batch 和唯一 head，得到同样的二维结果。这里明确传 `is_causal=False`，因为本讲例子允许两个位置互相看见；源码默认是 True，不显式关闭会得到另一种正确但不同的掩码结果。下一讲再研究这个差别。

独立小检查：把第一行 Query 改成 `[0,0]`，应仍得到均匀权重 `[0.5,0.5]`；再把第一行改成 `[1,1]`，它更偏向第二个 Key。修改后仍应显示“与工程一致 True”，因为两条计算路径接收同一组新输入。不要把这个人工 Q/K/V 例子当作真实语言模型学到的注意力解释。

假设 Q、K 的每个分量均值为 0、方差为 1，且暂时近似独立。点积是 `q₁k₁ + … + q_dk_d`，每项方差约为 1，合计方差约为 `d_k`，标准差约为 `√d_k`。维度增大时，未缩放分数容易变大，softmax 会变得过分尖锐，反向传播信号也可能变小。

除以 `√d_k` 后，分数的尺度回到约为 1。它是一个改善数值尺度的设计，并不保证所有输入下梯度都稳定。原始 Transformer 论文采用了这个缩放形式：[Attention Is All You Need](https://arxiv.org/abs/1706.03762)。

源码位于 VS Code 的示例工程：

张量形状在完整实现中扩展为 `[B,H,T,D]`：B 批次大小，H 注意力头数，T token 数，D 每头维度。转置最后两维的 K 后，分数为 `[B,H,T,T]`，输出重新变回 `[B,H,T,D]`。

在工程目录 PowerShell 中运行测试：

```powershell
..\..\..\.venv\Scripts\python.exe -m pytest tests/test_attention.py -q
```

命令前半段选择工作区共享 Python；`-m pytest` 使用该解释器运行测试；`-q` 只显示简洁结果。成功时会看到若干 `passed`。这证明测试用例通过，不代表你已掌握，接下来还要手算形状和权重。

## 动手操作

1. 在纸上画两个 Query 行、两个 Key 列的方格，填入点积矩阵。
2. 给每个分数除以 `√2`，标出每一行独立做 softmax。
3. 用每行权重乘 V，检查输出仍有两个位置、每个位置两个特征。
4. 打开 `attention.py`，按“QK 点积 → 缩放 → softmax → 乘 V”的顺序找到代码。

预期：分数图是 `2×2`，注意力权重每行之和约为 1，输出是 `2×2`。浮点数可能显示成 0.99999994 等近似值。

## 常见错误

- 把 `K` 当成 `V`：K 参与匹配，V 才被加权求和。
- 忘记转置 K 的最后两个维度：会造成矩阵维度不匹配，或错误的对齐。
- 在所有位置一起做 softmax：应沿 Key 这一维逐 Query 行归一化。
- 认为缩放是除以 `d_k`：标准形式除以平方根 `√d_k`。

## 练习

### 跟做练习

若 `B=2,H=3,T=5,D=4`，写出 Q、分数、注意力权重与输出形状。完成标准：四个形状都正确并能说出两个 T 分别表示 Query 位置和 Key 位置。

### 独立练习

若每头维度从 4 增至 16，缩放分母怎样变化？提示：看平方根。答案是从 2 增至 4，因为点积的标准差随 `√d_k` 增长。

### 迁移练习

找一句至少 4 个 token 的短句，为其中一个位置写下它可能关注的前文信息。这里的权重由模型学出；你的解释只是在描述任务直觉，不是人工指定权重。

> [!example]- 答案解析：形状练习
> Q、K、V 都是 `[2,3,5,4]`。对 K 的最后两维转置后，QK 分数和 softmax 权重为 `[2,3,5,5]`。乘 V 后输出为 `[2,3,5,4]`。前一个 5 是 Query 数，后一个 5 是可读 Key 数。
