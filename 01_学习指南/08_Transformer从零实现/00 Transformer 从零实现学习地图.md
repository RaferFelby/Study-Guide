## 打开并运行示例工程

1. 在 VS Code 打开 `01_学习指南/08_Transformer从零实现/示例工程/`。
2. 在该目录的 PowerShell 终端运行：

   ```powershell
   ..\..\..\.venv\Scripts\python.exe train.py --device cuda
   ```

   `--device cuda` 表示明确在可用 NVIDIA GPU 上运行；若要验证 CPU 路径，将它改成 `--device cpu`。省略该参数时，程序优先选择可用 CUDA，否则使用 CPU。

3. 查看设备、样本窗口数、训练/验证 loss 与最后生成的字符。GPU 与 CPU 浮点计算细节不同，loss/生成文本可能略有不同；输出长度、张量维度和“按下一个 token 逐步生成”的行为应符合教程说明。
4. 在同一目录运行 `..\..\..\.venv\Scripts\python.exe -m pytest -q`，确认注意力、mask、梯度、标签移位和 CPU/CUDA 测试结果。
5. 阅读源码时从 [[01_学习指南/08_Transformer从零实现/示例工程/README|README 代码导航]] 找到每个模块，不要一次通读全部代码。

## 必须掌握与以后再学

先掌握形状、mask、因果性、交叉熵和训练/生成的区别。FlashAttention 的推导先会讲清楚它减少了什么；本单元不要求手写 CUDA kernel，也不声称小模型复现能验证大模型质量。Encoder-Decoder 作为结构对照学习，本示例只实现 Decoder-only。
