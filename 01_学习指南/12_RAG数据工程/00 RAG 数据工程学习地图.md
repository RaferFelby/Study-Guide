## 运行示例

使用仓库根目录共享虚拟环境，不为本单元另建 `.venv`。在 VS Code 的 `示例工程` PowerShell 终端运行：

```powershell
..\..\..\.venv\Scripts\python.exe demo.py
..\..\..\.venv\Scripts\python.exe -m pytest -q tests
```

工程只用 Python 标准库；pytest 和 ruff 来自共享开发环境。示例使用 SQLite 临时数据库和词面词项重叠，不访问网络、不下载模型、不调用 LLM、不需要 API key。它演示索引/引用数据工程，不等同于真实 Embedding 质量验证。

## 重要边界

- 本机没有 `pypdf`，PDF 页码抽取没有实际运行；扫描件还需 OCR。教程提供真实处理边界和官方资料，不能把这记成已验证的 PDF parser。
- 本机没有 sentence-transformers 或向量数据库。模型维度和向量检索部分是原理教学；未获依赖安装批准前不下载模型或修改共享环境。
- demo 的 Recall@3 使用三条人工标注 query 和来源定位，是可运行探针，不是正式基准。严肃策略比较需要更多 gold 段落和真实 embedding/BM25 等后端，后续单元继续学习。
- 示例 ACL 标签由程序传入仅作演示。真实身份认证和多租户隔离必须由服务端可信授权逻辑完成。
