## 前置与完成标准

- 需要会运行 Python 脚本、读取函数参数和列表/字典；若不熟悉项目目录、虚拟环境和错误信息，可先复习 [[01_学习指南/01_Python工程化/00 Python 工程化学习地图|单元 01：Python 工程化]]。
- 本单元会使用 NumPy 的数组、pandas 的表格、scikit-learn 的模型与评估工具。陌生术语会在第一次出现时解释，不要求先会统计学习。
- 单元 05 的概率与梯度内容有助于深入理解模型，但不是运行本工程的先修门槛；需要时回到 [[01_学习指南/05_数学概率与优化/逐讲学习/03 概率贝叶斯与参数估计|概率与参数估计]] 和 [[01_学习指南/05_数学概率与优化/逐讲学习/09 梯度下降与学习率|梯度下降]]。
- 本地共享环境解释器是仓库根目录 `.venv`。当前已验证 NumPy、pandas、scikit-learn 与 SciPy 的版本组合，见 [[90_参考与维护/单元验证/07 传统机器学习与数据分析验证记录|作者验证记录]]。若在自己的环境缺少依赖，按工作区协作约定申请安装；不要为本单元另建环境。

**本单元完成标准：** 用隔离的数据划分比较基线，分析错误并写有边界的报告。

## 准备示例工程

1. 在 VS Code 打开本页链接的“示例工程”目录。
2. 按仓库根目录 [README](../../90_参考与维护/01 使用与环境/01 共享Python环境与运行约定.md#共享-python-环境) 使用工作区共享 `.venv`；不要为本单元新建环境。
3. 确认 `pandas`、`sklearn` 可以导入后，在示例工程目录运行：

   ```powershell
   ..\..\..\.venv\Scripts\python.exe train.py
   ```

   > 从本工程目录回到仓库根目录需要三级上移；三个 `..` 与共享环境的位置对应。

4. 程序会在工程的 `results/` 目录写出合成 CSV 和 JSON 报告。运行输出中应能看到 train/dev/test 数量、开发集模型比较、选出的阈值和测试集混淆矩阵。
5. 阅读每讲，再回到源码看对应函数。源码导航见 [示例工程 README](示例工程/README.md)。

## 进阶内容

当前必须掌握的是数据划分、训练 Pipeline、基线比较、分类指标和错误检查。概率校准两讲在第 8 讲后逐步学习；多分类校准、自动绘图、复杂时间序列回测、XGBoost 和自动化超参数搜索可以稍后深入，不用为了模型名称更多而跳过公平评估。
