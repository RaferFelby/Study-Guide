## 今天先做什么

先写出 `y = 2x + 1`。代入 x=5、6，得到预测 11、13。若真实目标是 11、14，平均绝对误差是多少？先算出 0.5，再按第 5 节运行程序核对。

前置是列表、函数、数组形状和训练／测试划分；数学回顾见 [[01_学习指南/05_数学概率与优化/逐讲学习/01 向量矩阵与张量形状|矩阵形状]]、[[01_学习指南/05_数学概率与优化/逐讲学习/09 梯度下降与学习率|损失与拟合]]。本课从一维数值预测开始，不要求先懂逻辑回归或决策树。

本节补上主工程分类任务之外的**回归**：预测连续数值，例如合成文件大小对应的处理耗时。它与预测“是否续费”的类别任务不同；不能把分类准确率直接当作回归指标。

## 1. 输入、目标与一条直线

假设下面是人为构造的教学数据，x 单位为 MB，y 单位为秒；它不是实际机器测量结果：

| 用途 | x：文件大小 | y：耗时 |
|---|---:|---:|
| 训练 | 1 | 3 |
| 训练 | 2 | 5 |
| 训练 | 3 | 7 |
| 训练 | 4 | 9 |
| 留出测试 | 5 | 11 |
| 留出测试 | 6 | 14 |

模型形式为 `prediction = slope * x + intercept`。

- `prediction` 是预测值，数学常写作 ŷ，读作“y 帽”。实际观测值是 y。
- `slope` 是斜率，本例等于 2，表示模型预测中 x 每增加 1 MB，耗时增加 2 秒。
- `intercept` 是截距，本例等于 1，表示这条直线在 x=0 处的值。它是拟合参数，不自动证明真实系统存在 1 秒固定开销。

这四条训练数据恰好在一条直线上，可以用手算看出参数。真实数据常带噪声，不会所有点都贴着直线；这时要说明“哪条直线更好”的标准。

测试 x=5、6 超出了训练范围 1～4，属于**外推**。本例为了手算特意这样设置，不把它视为普遍合理的数据切分；真实任务仍按时间、用户分组或采样过程设计划分。

## 2. 最小二乘拟合在最小化什么

每个样本的误差可写作 `prediction - target`。把所有误差平方后相加，得到平方误差和；选择使它最小的斜率和截距，就是普通最小二乘。

设有 n 个训练样本：

$$
L(w,b)=\frac{1}{n}\sum_{i=1}^{n}(wx_i+b-y_i)^2
$$

这里 w 是 slope，b 是 intercept，i 是样本编号；`Σ` 表示逐项累加。固定 n 时，最小化“和”与“平均值”得到的最优参数相同。平方让正负误差不能抵消，并对大误差施加更大惩罚。

对本例比较两条直线：

| 候选 | 训练预测 | 每个误差 | 平均平方误差 |
|---|---|---|---:|
| `2x+1` | 3、5、7、9 | 0、0、0、0 | 0 |
| `x+1` | 2、3、4、5 | -1、-2、-3、-4 | `(1+4+9+16)/4=7.5` |

本工程调用成熟库 `LinearRegression().fit(...)` 求解，不手写矩阵求逆，也没有在此额外运行梯度下降循环。不同优化方法可以处理相关目标，不能因前面学过梯度下降就断言所有回归库都按同一循环实现。

训练误差为零只说明这四个点完全拟合；测试第二点仍会有误差。训练损失不能代替未见数据评价。

## 3. 四个指标逐项手算

测试目标是 `[11,14]`，预测 `[11,13]`，误差是 `[0,-1]`。

### MAE：平均绝对误差

把误差取绝对值再平均：`(|0|+|-1|)/2 = 0.5` 秒。它与目标单位相同；数值越小表示此评价集的平均绝对偏差越小。

### MSE：平均平方误差

先平方再平均：`(0²+(-1)²)/2 = 0.5`，单位是秒²。它不能直接解释为“平均差 0.5 秒”。

### RMSE：均方根误差

对 MSE 开平方：`sqrt(0.5) ≈ 0.7071` 秒。单位回到秒，但它仍更强调较大的误差，不等于 MAE。

例如误差 `[0,0,0,4]` 和 `[1,1,1,1]` 的 MAE 都是 1；MSE 分别为 4 和 1，RMSE 分别为 2 和 1。错误集中在少量样本时，只看 MAE 可能掩盖这种差异。

### R²：相对于当前评价集均值的平方误差改进

常见定义为：

$$
R^2=1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y)^2}
$$

`y_bar`（ȳ）是**当前评价集**目标的均值。本例 `(11+14)/2=12.5`；分子为 1，分母为 `(-1.5)²+1.5²=4.5`，所以 `R²=1-1/4.5≈0.7778`。

这不是“77.78% 的样本预测正确”。它也不被限制在 0～1：比评价集均值参考更差时可以为负；完美预测且目标非常量时为 1。不能用 R² 的大小直接证明因果关系。

> [!info] 常量目标和单样本
> 若所有真实目标相同，分母为 0，公式没有通常意义下的有限 R²；只有一个样本也不适合报告 R²。本教学函数明确返回 `None`，同时保留 MAE／MSE／RMSE。scikit-learn 默认对部分常量目标情况采用有限值替代，本课没有把这个便利默认值当成原公式定义。

## 4. 基线为何只能在训练数据上拟合

一个不看 x 的简单模型，可以始终预测训练 y 的均值。本例训练均值是 `(3+5+7+9)/4=6`，因此基线在测试集输出 `[6,6]`。

`DummyRegressor(strategy="mean")` 实现这个基线。它的 `.fit()` 只接收训练集；不能为了让测试更好看，把测试目标均值 12.5 当成它学到的常数。

两种均值用途要分开：

- **可部署的常数基线预测**使用训练均值 6，因为预测时尚不知道未来真实目标。
- **R² 的评价公式**使用当前评价集均值 12.5，这是知道真实目标后进行评分的参照，不是把这个均值传给模型预测。

因此训练均值基线在测试集的 R² 不一定是 0。本例误差为 -5、-8，平方误差和 89，于是 R²=`1-89/4.5≈-18.7778`。

这个很负的数还反映了当前测试集自身变化范围很小，而训练均值与它相距很远。要连同目标范围、样本量和 MAE 一起解释，不能只凭一个 R² 就评价全部业务价值。

## 5. 在 VS Code 运行并读源码

打开 `01_学习指南/07_传统机器学习与数据分析/示例工程`，在该目录 PowerShell 执行：

```powershell
..\..\..\.venv\Scripts\python.exe regression_demo.py
```

使用根共享环境已有的 NumPy 与 scikit-learn，无需新增依赖。此脚本不改分类工程结果目录，只打印结果：

```text
斜率与截距 2.0 1.0
模型预测 [11.0, 13.0]
训练均值基线 [6.0, 6.0]
model_metrics {'mae': 0.5, 'mse': 0.5, 'rmse': 0.7071, 'r2': 0.7778}
baseline_metrics {'mae': 6.5, 'mse': 44.5, 'rmse': 6.6708, 'r2': -18.7778}
```

展示保留四位小数；内部计算没有先四舍五入。不同数值库的极小浮点差异正常，不能用任意两次浮点结果完全相等代替容差检查。

打开 [regression_demo.py](../示例工程/regression_demo.py)，按以下顺序阅读：

1. `as_vector()` 把输入转换成一维浮点数组，拒绝空数据、NaN 和无穷。它是输入检查，不负责缺失值填补；带缺失的数据应回前面的 Pipeline 课。
2. `fit_and_evaluate()` 检查特征与目标数量一致。此教学函数还要求至少两个不同的训练 x，否则无法唯一辨认本课要学习的斜率。
3. `.reshape(-1,1)` 将一维 x 变成 `[样本数,1个特征]`；`-1` 让 NumPy 根据元素数推断样本数。不要写成 `[1,样本数]`，那表示一个样本有多个特征。
4. 创建直线模型和均值基线，各调用一次 `.fit(train_features, train_y)`；测试目标没有参与拟合。
5. 调用 `.predict(test_features)` 得预测，然后才把预测与 test_y 交给指标函数。
6. `coef_[0]` 是唯一特征的系数，`intercept_` 是截距；这些带尾部下划线的属性由拟合产生。返回报告还保存两组预测，便于逐条检查。

`regression_metrics()` 分别调用指标函数，并对 R² 的无定义情况明确处理；出现中间统计溢出时报告错误。它只覆盖本课有限小数值例子，不是极端数值范围的通用稳健统计实现。

## 6. 跟做、独立和迁移练习

### 跟做：逐条检查误差

新建 `lesson_regression_metrics.py`，传入目标 `[11,14]` 和预测 `[11,13]`。打印指标后，自己写出两条误差。完成标准：能说明为什么 MAE 与 MSE 此次数值相等，但单位与定义不同。

> [!example]- 完整答案
> ```python
> from regression_demo import regression_metrics
> 
> print(regression_metrics([11, 14], [11, 13]))
> ```
> 在工程目录运行共享解释器加文件名，结果接近 `mae=0.5,mse=0.5,rmse=0.7071,r2=0.7778`。数值相等来自本例非零误差绝对值正好为 1，并非指标等价。将第二条预测改成 12 后，MAE=1，MSE=2，RMSE≈1.4142，R²≈0.1111。

### 独立：集中大错误与分散小错误

比较真实目标 `[0,0,0,0]` 下两组预测 `[0,0,0,4]` 与 `[1,1,1,1]`。不要先运行，先填写 MAE、MSE、RMSE、R²。

> [!example]- 完整答案与解析
> ```python
> from regression_demo import regression_metrics
> 
> print(regression_metrics([0, 0, 0, 0], [0, 0, 0, 4]))
> print(regression_metrics([0, 0, 0, 0], [1, 1, 1, 1]))
> ```
> 保存为 `lesson_error_patterns.py` 运行。两组分别为 `(MAE=1,MSE=4,RMSE=2,R²=None)`、`(MAE=1,MSE=1,RMSE=1,R²=None)`。目标是常量，所以不能用 R² 给这两组排出一个有效分数；前三项仍能表达误差差异。

### 迁移：换单位，不换任务

把目标与预测一起从秒改为毫秒，也就是都乘 1000。哪些指标乘 1000，哪个乘 1000000，哪个保持不变？完成标准：先写量纲解释，再运行核对。

> [!example]- 完整答案与解析
> ```python
> from regression_demo import regression_metrics
> 
> print(regression_metrics([11, 14], [11, 13]))
> print(regression_metrics([11000, 14000], [11000, 13000]))
> ```
> 保存为 `lesson_metric_units.py` 运行。MAE 和 RMSE 乘 1000，MSE 乘 1000²；R² 的分子分母都乘同一平方因子，比例不变。这要求两边同时换单位；只改真实值而不改预测值，就是错误评价。

### 进一步独立检查：测试答案不能改变拟合参数

把 `fit_and_evaluate()` 的 test_y 改成 `[-100,100]`，训练集和 test_x 不变。斜率、截距、预测应仍为 2、1、11／13，但评分会改变。完成标准：比较报告里的对应字段，并指出代码中的两次 `.fit()` 都只读取训练集。

> [!example]- 完整答案
> ```python
> from regression_demo import fit_and_evaluate
> 
> first = fit_and_evaluate([1, 2, 3, 4], [3, 5, 7, 9], [5, 6], [11, 14])
> changed = fit_and_evaluate([1, 2, 3, 4], [3, 5, 7, 9], [5, 6], [-100, 100])
> print(first["predictions"] == changed["predictions"])
> print(first["slope"] == changed["slope"])
> print(first["model_metrics"] == changed["model_metrics"])
> ```
> 保存为 `lesson_holdout.py` 运行，依次 True、True、False。这是在同一训练数据、同一确定性求解流程下检查“更换评分目标不会影响拟合”，不把浮点完全相等推广为跨设备数值比较方法。

## 7. 常见错误与完成判断

| 现象 | 原因与修复 |
|---|---|
| 提示特征和目标数量不同 | 检查切分时行是否一一对应，不随便截短来消除报错 |
| 特征形状不对 | 本函数接收一维 x，内部转成 `[N,1]`；不要自己重复套一层 |
| 所有训练 x 相同 | 本课无法辨认唯一斜率；先检查数据列是否读错 |
| R² 是负数 | 检查是否比评价集均值参照更差，同时看误差和目标范围 |
| R² 是 None | 检查评价样本数及目标是否常量，不填写伪造的 0 或 1 |
| 基线得分异常漂亮 | 检查基线是否偷偷使用测试目标均值 |
| 测试不好就重新试参数 | 多次依据该集选模型后，它已经用于开发；最终评价需要新的独立数据 |

本课只拟合一个预先固定的一维模型，没有模型搜索，因此未单设开发集。若要比较多项式次数、正则强度或特征，先按第 2 讲增加开发／交叉验证安排，不能反复看测试指标选方案。

完成物：一张手算指标表、一份运行输出、一次单位迁移、一次不泄漏检查，以及一句“为何这个合成结果不代表真实系统性能”。接下来按第 4 讲分类指标、第 5 讲树模型继续，再进入 [[01_学习指南/07_传统机器学习与数据分析/逐讲学习/06 从多特征回归理解Ridge与标准化|多特征与 Ridge]]、[[01_学习指南/07_传统机器学习与数据分析/逐讲学习/07 公平比较回归模型并检查残差|回归模型比较]]。第 8 讲后进入 [[01_学习指南/07_传统机器学习与数据分析/逐讲学习/09 手算概率误差与可靠性表|概率误差]]与[[01_学习指南/07_传统机器学习与数据分析/逐讲学习/10 隔离校准数据并检查校准是否改善|独立校准实操]]。真实业务、稳健回归和预测区间仍需后续学习，不因补充固定合成实验就宣称全部覆盖。
