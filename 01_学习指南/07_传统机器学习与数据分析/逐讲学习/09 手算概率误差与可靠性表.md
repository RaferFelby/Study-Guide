## 1. 预测为正，不等于正类概率可靠

设 `y=1` 表示客户续费，`y=0` 表示没有续费；`p` 表示模型给出的续费概率。`p=0.8` 不是“这个客户有 80% 的标签”，而是一个概率判断。一个客户最后只会观察到 0 或 1；需要收集一组预测相近的客户，检查其中续费的比例，才能估计这种概率判断是否可靠。

例如 100 个预测约为 0.8 的客户中，若有约 80 个续费，便与预测相符。这是有限样本证据，不要求每批恰好 80 个，也不能证明换一个地区或月份后仍然成立。**校准**关注预测概率与发生频率是否相符。

另一个问题是**分类**：阈值 0.5 将 `p >= 0.5` 判为续费。把 0.51 改成 0.99，不会改变这条预测的类别，却会显著改变概率错误的代价。因此准确率、AP 和概率指标需要分开看。

> [!info] 这里的概率是哪一个
> 本课始终检查正类 1 的概率。`p=0.1` 是“续费概率 10%”，不是“模型对所选类别只有 10% 把握”。若模型选的是负类，对所选类别的概率是 0.9。不要把这两种定义混在同一张表中。

## 2. 先手填四组记录

下面每一行代表两个独立样本。为了方便计算，这里把相同概率放在一起；真实输出通常没有这么整齐。

| 样本序号 | 两个实际标签 | 两个预测概率 | 平均预测概率 | 实际正例比例 |
|---|---|---|---:|---:|
| 1、2 | 0、1 | 0.1、0.1 | 0.1 | 1/2 = 0.5 |
| 3、4 | 0、0 | 0.4、0.4 | 0.4 | 0/2 = 0 |
| 5、6 | 1、1 | 0.6、0.6 | 0.6 | 2/2 = 1 |
| 7、8 | 0、1 | 0.9、0.9 | 0.9 | 1/2 = 0.5 |

**分箱**就是按预测概率范围分组。先约定 5 个等宽区间：`[0,0.2]`、`(0.2,0.4]`、`(0.4,0.6]`、`(0.6,0.8]`、`(0.8,1]`。圆括号表示不含端点，方括号表示含端点。因此 0.4 进入第二箱，0.6 进入第三箱；0 和 1 都有归属。

这套端点规则与本次核对的 scikit-learn 1.9.1 等宽实现一致，是本课明确采用的约定，不是所有软件唯一可用的规则。数组边界由 `np.linspace` 生成，显示为两位小数只是排版；不要先把概率四舍五入再分箱，否则可能移动边界附近的样本。

第四箱没有样本。它的正例比例应记为“未知／无样本”，不能记为 0。后者会被误读为“这一段概率的事件全部没有发生”。也不能为了凑满箱数编出坐标点。

### 把表转换成可靠性图

**可靠性图**的横轴是每箱平均预测概率，纵轴是每箱实际正例比例。拿纸画两条 0～1 的坐标轴，再画对角线 `y=x`，标出四个非空箱的点：

| 横坐标 x | 纵坐标 y | 旁边标注的样本数 | 可以怎样读 |
|---:|---:|---:|---|
| 0.1 | 0.5 | 2 | 这一箱观察到的正例比例高于预测均值 |
| 0.4 | 0 | 2 | 这一箱观察到的正例比例低于预测均值 |
| 0.6 | 1 | 2 | 这一箱观察到的正例比例高于预测均值 |
| 0.9 | 0.5 | 2 | 这一箱观察到的正例比例低于预测均值 |

点在线上表示这一箱的两个平均值相等；线上方表示正类概率偏低，下方表示偏高，都是针对当前样本的观察。若把点连线，连线只用于阅读，不能说明空白位置有观测。这里只有每箱 2 条，证据非常弱；先学会算坐标，不能据此做真实客户结论。

本课运行程序会输出同样的坐标和箱内数量，不需要绘图库。先手画一张图，核对横纵轴没有颠倒。[定义与分箱接口：scikit-learn calibration_curve](https://scikit-learn.org/stable/modules/generated/sklearn.calibration.calibration_curve.html)。

## 3. 两个数值指标回答不同问题

### Brier：每条概率与标签的平方差

二分类正类概率的 Brier 分数在本课定义为：

`Brier = 所有 (p - y)² 的和 / 样本数`

`²` 表示平方；Python 写成 `** 2`。预测 0.1、标签 0，贡献为 `0.1²=0.01`；预测 0.1、标签 1，贡献为 `(-0.9)²=0.81`。这里对自信却错误的预测惩罚更大。

8 条贡献依次是：`0.01、0.81、0.16、0.16、0.16、0.16、0.81、0.01`。和为 2.28，除以 8 得 **0.285**。在这个二分类定义下范围是 0～1，越小表示平均平方概率误差越小。若使用对两个类别都求和的定义，数值会多一倍，比较报告时先核对约定。

Brier 同时反映概率校准、区分不同样本的能力及数据本身的不确定性。**更小的 Brier 不能单独证明更好的校准**。例如完全不区分样本、总报总体正例比例的模型，可以在粗分箱下看起来很准，却不能把高风险与低风险样本排开。[依据：scikit-learn 概率校准说明](https://scikit-learn.org/stable/modules/calibration.html)。

### ECE：分箱后平均有多大偏差

ECE 常译为“期望校准误差”。本课采用**正类概率、等宽分箱、按样本数加权的绝对偏差**：

`ECE = 各非空箱的 (箱内数量 / 总数量) × |平均预测概率 - 实际正例比例| 之和`

竖线表示绝对值，忽略差的正负方向。这里四个非空箱各有 2 条，权重都是 `2/8`；每箱绝对差都是 0.4，因此 ECE 为 `4 × (2/8) × 0.4 = 0.4`。

ECE 不是 Brier 的另一种写法：它先分组取平均，可能把方向相反的错误抵消。若将本例全部放进一个箱，平均概率为 0.5、正例比例也是 0.5，ECE 就变成 **0**，但 8 条概率完全没变，Brier 仍是 0.285。

因此报告时至少写清“正类概率、等宽、5 箱、样本数 8”。有些论文按模型所选类别的置信度计算 ECE，也有等频分箱和其他误差形式；不同定义的数值不能直接混比。ECE=0 只说明该次分箱统计没有发现偏差，不是普遍可靠性的证明。

## 4. 在 VS Code 运行最小例子

在 VS Code 打开 `01_学习指南/07_传统机器学习与数据分析/示例工程`。从 [代码导航](../示例工程/README.md)找到 [calibration_demo.py](../示例工程/calibration_demo.py)。新建并保存 `lesson_reliability.py`，内容如下：

```python
from calibration_demo import print_reliability_table, probability_metrics

labels = [0, 1, 0, 0, 1, 1, 0, 1]
probabilities = [0.1, 0.1, 0.4, 0.4, 0.6, 0.6, 0.9, 0.9]
print_reliability_table(labels, probabilities, n_bins=5)
for n_bins in [5, 1]:
    metrics = probability_metrics(labels, probabilities, n_bins=n_bins)
    print(n_bins, f"Brier={metrics['brier']:.3f}", f"ECE={metrics['ece']:.3f}")
```

终端也要位于这个 `示例工程` 目录。先输入 `Get-Location` 核对位置，再运行：

```powershell
..\..\..\.venv\Scripts\python.exe lesson_reliability.py
```

三个 `..` 返回仓库根目录；`.venv\Scripts\python.exe` 选择共享解释器；最后是脚本文件名。不需要新建环境或安装包。

前面表格的箱内数量应为 `2、2、2、0、2`，最后两行应为：

```text
5 Brier=0.285 ECE=0.400
1 Brier=0.285 ECE=0.000
```

`labels` 与 `probabilities` 必须按同样的样本顺序对齐。两个函数都以标签和概率为输入；`print_reliability_table` 负责展示，`probability_metrics` 返回含 `brier`、`ece` 两个键的字典。循环只改分箱数，没有修改任何预测。格式中的 `.3f` 将展示值保留三位小数，不改变用于计算的概率。

### 顺着源码读计算顺序

1. `validate_predictions` 把列表转成一维数组，拒绝空输入、长度不同、NaN、无穷大、非 0/1 标签及越界概率。不会静默把 1.2 截成 1。
2. `reliability_table` 用 `np.linspace(0, 1, n_bins + 1)` 生成边界。5 个箱需要 6 个端点。循环逐箱生成布尔筛选数组 `selected`；`&` 表示两项条件同时满足，每项比较都带括号。
3. `selected.sum()` 计算选中数量；`labels[selected].mean()` 是该箱正例比例，因为标签仅为 0/1。空箱保留 `None`，表示没有可估计的均值。
4. `probability_metrics` 独立计算逐样本平方差，再循环累加非空箱的加权绝对差。跳过空箱是因为没有统计值，不是把空箱的概率误差算成零。

这里为了可读性逐箱筛选，适合小型教学数据；不把它当大规模评估工具的性能实现。scikit-learn 的 `calibration_curve` 返回顺序是“正例比例、平均预测概率”，而绘图横轴应使用后者。它省略空箱，本课表格保留空箱数量以便解释。

## 5. 三种练习与答案

### 跟做：分类正确率与概率误差

沿用 8 条样本，用阈值 0.5 写出 8 个预测标签。提示：前四个预测为 0，后四个预测为 1。完成标准：能指出错了哪两条，并解释为何准确率不能代替可靠性表。

> [!example]- 参考答案
> 第 2、7 条错误，准确率为 `6/8=0.75`。阈值只关心概率在哪一边；可靠性表保留概率大小。不能用 75% 的准确率代替每个概率范围的发生频率。

### 独立：造出 ECE 为零但概率很差的例子

标签 `[0,1]`，概率 `[0.9,0.1]`。先手算 1 箱与 2 箱的 ECE，再写脚本验证。提示：一箱时两个平均值都是 0.5。完成标准：两个箱数的 Brier 一样，且能解释 ECE 为什么变化。

> [!example]- 参考答案
> 保存为 `lesson_ece_counterexample.py`，用同样解释器运行：
> ```python
> from calibration_demo import probability_metrics
> 
> for n_bins in [1, 2]:
>     result = probability_metrics([0, 1], [0.9, 0.1], n_bins)
>     print(n_bins, f"{result['brier']:.2f}", f"{result['ece']:.2f}")
> ```
> 输出 `1 0.81 0.00`、`2 0.81 0.90`。两条预测都很自信却方向错误；粗分箱只看平均，掩盖了它们的差异。不能挑最小 ECE 的箱数来证明模型好。

### 迁移：把正类改成“不续费”

将每条标签换成 `1-y`，每条概率换成 `1-p`，仍使用最初 8 条样本。先预测 Brier 是否变化，再验证；写下新的正类含义。提示：概率差只改变正负号，平方不变。

> [!example]- 参考答案
> 保存为 `lesson_positive_class.py`：
> ```python
> from calibration_demo import probability_metrics
> 
> labels = [0, 1, 0, 0, 1, 1, 0, 1]
> probabilities = [0.1, 0.1, 0.4, 0.4, 0.6, 0.6, 0.9, 0.9]
> new_labels = [1 - label for label in labels]
> new_probabilities = [1 - probability for probability in probabilities]
> before = probability_metrics(labels, probabilities)
> after = probability_metrics(new_labels, new_probabilities)
> print(f"{before['brier']:.3f}", f"{after['brier']:.3f}")
> ```
> 输出 `0.285 0.285`。现在正类 1 表示不续费，必须在图、表和报告一起改名。一般不要顺便宣称分箱 ECE 必然完全不变：分箱端点归属、浮点数及其他分箱定义仍需检查。

## 6. 常见错误与完成检查

| 现象 | 原因与修复 |
|---|---|
| ModuleNotFoundError: calibration_demo | 文件未放在示例工程，或终端位置不对；将脚本与模块放在同一工程目录并核对 `Get-Location` |
| 提示概率不在 [0,1] | 很可能传入了原始分数；先确认输出接口，不随意裁剪来隐藏错误 |
| 提示非空且等长 | 检查筛选标签与概率时是否使用同样样本，不能分别排序 |
| 空箱显示 `--` | 正常；不能补成零，也不能把它画成纵坐标零 |
| 概率全是 0.5，看起来接近对角线 | 检查是否失去区分能力，结合 AP、基线及样本数解释 |
| 改箱数后结论改变 | 报告分箱敏感性；不在测试集挑最有利的箱数作为唯一结果 |

现在应能说明“横轴是什么、空箱为什么未知、Brier 为什么不只是校准、ECE 为什么依赖分箱”。下一篇用未参与基础模型拟合的独立数据学习校准映射。
