## 1. 回归树怎样给出一个数字

分类树最后预测类别；回归树最后预测连续数值。本课采用平方误差准则：在当前节点比较候选切分，让左右组的平方误差之和更小；每个叶子用该叶训练目标的均值预测。这里不使用样本权重，若改变准则，叶子统计也可能不同。

四条样本：页数 `[1,2,3,4]`，耗时 `[2,2,8,8]`。若完全不切分，均值为 5，平方误差和为 `4×3²=36`。按 `页数 <= 2.5` 切分后，左组均值为 2、右组均值为 8，两组平方误差都是 0。

在本单元 `示例工程` 新建 `lesson_regression_tree.py`，用完整小例子核对：

```python
from sklearn.tree import DecisionTreeRegressor, export_text

model = DecisionTreeRegressor(max_depth=1, random_state=73)
model.fit([[1], [2], [3], [4]], [2, 2, 8, 8])
print(export_text(model, feature_names=["pages"]))
print(model.predict([[0], [1], [4], [10]]).tolist())
```

`max_depth=1` 只允许根节点切一次；`random_state` 固定存在并列选择时的随机行为；`export_text` 将树规则输出为文字，不需要绘图库。预期看到阈值 2.50，两个叶子值 2.00、8.00；预测为 `[2.0,2.0,8.0,8.0]`。

页数 10 仍落到右叶，输出 8。普通单棵均值叶回归树不会沿着直线趋势继续增长；这是它对训练范围外输入的边界，不能只看训练误差为零就认为会外推。线性模型能继续延长趋势，也不代表它的外推一定正确。[算法说明：scikit-learn 决策树](https://scikit-learn.org/stable/modules/tree.html)。

完整实验限制深度为 3、每叶至少 8 条训练样本，减少小分支记住噪声的倾向。限制复杂度仍不保证最优，需要开发集证据。

## 2. 准备同一份回归数据

从 [代码导航](../示例工程/README.md)打开 [regression_comparison.py](../示例工程/regression_comparison.py)。输入列和目标如下：

| 名称 | 含义与单位 | 是否给模型作输入 |
|---|---|---|
| page_count | 文档页数 | 是 |
| text_chars | 字符数量；与页数相关 | 是 |
| attachment_count | 附件数量 | 是 |
| duration_minutes | 整理耗时，分钟 | 否，这是要预测的目标 |

程序用种子 73 生成 300 行。字符数由“页数×400，加随机扰动，最低取 100”得到。耗时公式为：

`5 + 0.4×页数 + 0.001×字符数 + 1.5×附件数 + 8×(页数>12) + 噪声`

`(页数>12)` 在公式中为真时取 1，否则取 0；它产生一个突变，让线性模型不能完全表达这条合成规则。噪声来自均值为零、标准差为 2 的正态分布，表示教学中的不可预测扰动。先用完整特征生成目标，再把每个输入列的 15 个位置设为缺失，模拟部分信息没有记录。不同列缺失位置可以重叠，目标不设缺失。

例如忽略噪声时，10 页、4000 字符、2 个附件的结果为 16；13 页、5200 字符、2 个附件为 26.4。这是我们指定的生成规则，不是从现实归纳出的规律。

按行随机分成 **180 条训练、60 条开发、60 条测试**，原始行索引保留，特征与目标一起切分，避免错位。目标是连续数值，本课没有把每个不同耗时当成分类标签做分层。真实数据有用户重复、时间顺序时，应改用合适的分组或时间划分。

## 3. 五个候选怎样保持可比

| 名称 | 模型 | 预先确定的设置 |
|---|---|---|
| mean | 训练目标均值基线 | 每条预测相同，只使用训练 y 的均值 |
| linear | 普通多特征线性回归 | 默认拟合截距 |
| ridge_1 | Ridge | alpha=1，标准化后拟合 |
| ridge_100 | Ridge | alpha=100，标准化后拟合 |
| tree_depth_3 | 回归树 | 深度 3、每叶至少 8 条训练样本 |

所有模型使用相同训练、开发划分和输入列。每个模型独立创建中位数填补器，避免共享可变的拟合状态。线性与 Ridge 另加 StandardScaler；均值基线和树不要求这一步缩放。公平比较的关键是相同数据、同样的评估规则与正确的拟合边界，不是把不需要的变换强加给每种算法。

**中位数**是排序后居中的数，偶数个观测时取中间两个的均值。`SimpleImputer(strategy="median")` 按训练列的非缺失值计算中位数，再把缺失位置替换成它。之后 scaler 基于填补后的训练数据拟合。开发和测试只调用 `transform`，不会重新计算填补值或均值。

若训练数据某一列全部缺失，本课直接给出错误，不悄悄丢列或发明默认含义。一般工程可以事先定义其他策略，但需要说明业务理由。本课只演示数值列，没有同时引入类别编码、特征筛选或目标变换。

## 4. 运行并解释实际结果

在 VS Code 的 PowerShell 终端用 `Get-Location` 确认位于 `01_学习指南/07_传统机器学习与数据分析/示例工程`，运行：

```powershell
..\..\..\.venv\Scripts\python.exe regression_comparison.py
```

三个 `..` 返回仓库根，后面的路径是共享环境解释器。脚本只打印结果，不改写原分类报告。相同命令将文件名换成 `lesson_regression_tree.py` 可运行第 1 节小例子。

本次 Python 3.13.12、NumPy 2.5.3、pandas 3.0.6、scikit-learn 1.9.1 的输出如下；不同版本可能有数值差异，保留你的实际版本与结果：

| 模型 | 训练 RMSE | 开发 RMSE | 开发 MAE |
|---|---:|---:|---:|
| mean | 9.1583 | 9.1887 | 8.3008 |
| linear | 2.7994 | 2.9792 | 2.3680 |
| ridge_1 | 2.7996 | 2.9814 | 2.3743 |
| ridge_100 | 3.4523 | 3.6878 | 3.1075 |
| tree_depth_3 | 2.8420 | 3.3563 | 2.3085 |

按预定开发 RMSE 最小规则选中 **linear**。树的开发 MAE 更小，但 RMSE 更大，表示这两种误差汇总给出了不同排序；RMSE 对较大的误差更敏感。不能看到树的 MAE 更好，就临时把本次主指标换成 MAE。若业务事先更重视绝对误差，可设计另一场以 MAE 选模的实验，并明确它是另一种规则。

两个 Ridge 都未超过 linear；alpha=100 的训练误差也明显增大，提醒我们更强惩罚可能压制有效信号。这次结果不能证明 Ridge 或树普遍较差，也不能证明合成关系中的突变不存在。

### 最终只检查锁定方案与固定基线

本课选完不在 `train+dev` 上重训，直接保留原已拟合 Pipeline。最终 test 上：

| 模型 | MAE | RMSE | R² | 平均残差 | 最大绝对残差 |
|---|---:|---:|---:|---:|---:|
| mean | 7.9826 | 9.0840 | -0.0025 | 0.4524 | 15.9862 |
| linear | 2.6287 | 3.1625 | 0.8785 | -0.2410 | 8.2616 |

误差单位为分钟；R² 无单位。均值基线的 R² 可以略为负数，因为它预测的是**训练**均值，而 R² 分母使用**测试**目标均值对应的误差，这两者并不相同。

如果实际流程要在 train+dev 重训，应在查看 test 前决定，并重新拟合整个预处理与模型，重新记录版本。本课没有实现这一步，也不把开发分数当成重训后模型的测试表现。

## 5. 跟着源码检查数据流

1. `make_duration_dataset` 创建独立合成回归表；没有复用分类的续费标签或把 0/1 标签冒充耗时。
2. `split_regression_data` 检查列名、有限目标、行索引和全缺失列，再同时切分 X 与 y。返回 `RegressionSplits` 数据类；它只把六份表／序列命名保存，方便从 `splits.x_train` 读取，不负责拟合模型。
3. `make_regression_models` 每次创建全新的 Pipeline。步骤名字为 `imputer`、可选的 `scaler`、`model`，可以用 `named_steps` 读取。
4. `select_on_dev` 的四个参数只有训练／开发的特征和目标，**没有 test 参数**。每个模型只 `fit(x_train,y_train)`，分别预测训练／开发数据，调用上一课已有的 `regression_metrics`。
5. `min(..., key=...)` 按 `scores[name]["dev"]["rmse"]` 选择最小者；完全相同则保留候选定义中的第一个。这个并列规则是教学约定，不是统计显著性判断。linear 与 ridge_1 的微小分差也不能单独证明稳定优势。
6. `main` 拿到选中名称以后，才对它与均值基线读取测试预测并评分。不会把每个候选的 test 都算一遍再挑最好的。

没有在本例里增加交叉验证。想扩展时，在训练数据内部对**完整 Pipeline**做 CV，每折独立拟合填补与标准化，再明确开发集和测试集的用途；不能先对全体数据填补好，再把得到的矩阵拿去 CV。

## 6. 残差告诉你哪些信息

**残差**在本课定义为 `实际值 - 预测值`：正数表示低估耗时，负数表示高估。必须声明符号，因为其他资料可能取相反方向。

平均残差接近零，只说明正负偏差可能抵消。新建 `lesson_residuals.py`：

```python
from regression_comparison import residual_summary

report = residual_summary([10, 20], [15, 15])
for name in ["mean_residual", "mae", "rmse", "max_absolute_residual"]:
    print(name, report[name])
```

运行后应依次看到 `0.0、5.0、5.0、5.0`。平均残差为零，两条预测却都错了 5 分钟。检查误差时至少同时看 MAE／RMSE、样本数、最大误差或分位数，再检查异常输入与业务切片。最大残差受极端样本影响，不是“绝大多数样本的误差上限”，更不是未来误差保证。

若检查实际模型的某条大误差，应回到原始特征、缺失情况和标签来源核对原因。不能仅因为误差大就删除测试记录再重报成绩，也不能把残差相关性直接解释成因果。

## 7. 练习与答案解析

### 跟做：为什么没有选择 MAE 最小的树

用比较表写下按 RMSE 和按 MAE 分别会选谁，说明本次正式选择是哪一个。完成标准：区别“观测另一指标”与“事后改选模规则”。

> [!example]- 参考答案
> RMSE 选 linear，MAE 选 tree_depth_3。本次预先约定 RMSE，所以正式选 linear。可以报告这种差异，指出模型取舍受任务损失影响；若另做 MAE 探索，要重新说明规则与最终测试是否已被看过，不能把探索结果冒充预先登记的胜者。

### 独立：检查预处理没有偷看极端新输入

只拟合 linear，保存填补器中位数和 scaler 均值；预测一份特征放大 1000 倍的新输入，再比较统计量。提示：应使用 `.copy()` 保存数组。完成标准：两个比较为 True，并知道这不能证明新输入上的预测准确。

> [!example]- 参考答案
> 保存为 `lesson_regression_preprocessing.py`：
> ```python
> import numpy as np
> 
> from regression_comparison import (
>     make_duration_dataset,
>     make_regression_models,
>     split_regression_data,
> )
> 
> splits = split_regression_data(make_duration_dataset())
> model = make_regression_models()["linear"]
> model.fit(splits.x_train, splits.y_train)
> imputer = model.named_steps["imputer"]
> scaler = model.named_steps["scaler"]
> medians_before = imputer.statistics_.copy()
> means_before = scaler.mean_.copy()
> model.predict(splits.x_dev.fillna(0) * 1000)
> print(np.array_equal(medians_before, imputer.statistics_))
> print(np.array_equal(means_before, scaler.mean_))
> print(np.allclose(imputer.statistics_, splits.x_train.median().to_numpy()))
> ```
> 三行应为 True。这里放大输入只是在做状态不变检查，填 0 也只是构造扰动，并非推荐的新业务缺失处理方案。`np.allclose` 允许很小的浮点误差；训练列中位数与拟合填补值一致。预测不会重新 fit，但超出训练范围仍可能不可靠。

### 迁移：目标从分钟改成秒

将训练和开发目标都乘以 60，在同样配置下重新拟合 linear，比较开发集指标。暂不调用 test。提示：线性模型预测也应按比例变化。完成标准：MAE、RMSE 约乘 60，MSE 约乘 3600，R² 基本不变，并解释各自单位。

> [!example]- 参考答案
> 保存为 `lesson_regression_target_units.py`：
> ```python
> import numpy as np
> 
> from regression_comparison import (
>     make_duration_dataset,
>     make_regression_models,
>     split_regression_data,
> )
> from regression_demo import regression_metrics
> 
> splits = split_regression_data(make_duration_dataset())
> minute_model = make_regression_models()["linear"]
> second_model = make_regression_models()["linear"]
> minute_model.fit(splits.x_train, splits.y_train)
> second_model.fit(splits.x_train, splits.y_train * 60)
> minute_prediction = minute_model.predict(splits.x_dev)
> second_prediction = second_model.predict(splits.x_dev)
> before = regression_metrics(splits.y_dev, minute_prediction)
> after = regression_metrics(splits.y_dev * 60, second_prediction)
> print(np.allclose(second_prediction, minute_prediction * 60))
> print(round(after["mae"] / before["mae"], 4))
> print(round(after["rmse"] / before["rmse"], 4))
> print(round(after["mse"] / before["mse"], 4))
> print(np.isclose(after["r2"], before["r2"]))
> ```
> 预期 `True、60.0、60.0、3600.0、True`。这是同一任务换单位，不能用更小的分钟数值证明模型更优。前篇改的是输入单位并影响 Ridge 惩罚，这里改的是目标单位，两个实验不要混淆。

## 8. 常见错误与交付物

| 现象 | 排查与修复 |
|---|---|
| 提示特征列或目标列缺失 | 对照四列名称，目标不是分类工程的 renewed；不要传错数据表 |
| 训练划分整列缺失 | 检查数据来源；明确补采、丢列或固定填充值策略后再设计实验，不悄悄绕过 |
| 线性模型提示 NaN | 是否绕过了包含填补器的 Pipeline，或把缺失目标送进拟合 |
| 训练分数很好，开发较差 | 检查过拟合、噪声、划分和分布变化；不能靠更复杂模型或改种子保证修复 |
| 测试指标因反复试验越来越好 | 测试已参与选择；如实标为探索，需要新独立数据作最终评估 |

交付一页简报：写清数据来自合成公式、180/60/60 划分、五个固定候选、开发 RMSE 规则、入选结果、最终基线比较、残差符号和未改善方案。没有真实业务效果、预测区间或模型持久化实现时明确写“未验证／未实现”。之后回到主线第 8 讲，继续学习分类中的错误切片与业务阈值。
