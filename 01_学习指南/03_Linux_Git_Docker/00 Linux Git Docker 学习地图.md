## 开始前：打开示例工程

1. 在 VS Code 中打开 `01_学习指南/03_Linux_Git_Docker/示例工程/`。
2. 在工程根目录打开终端。
3. 查看 `README.md`，先运行本机 Python 版本和测试命令。
4. Linux 命令可以在 Linux、WSL、macOS 或远程 Linux 终端中运行；Windows PowerShell 的等价写法会在正文中标明。
5. Docker 部分需要已启动 Docker Desktop 或 Linux Docker Engine；没有 Docker 时先阅读 Dockerfile、完成无 Docker 的配置练习即可。
