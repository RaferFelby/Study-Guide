## 从这里运行

在 VS Code 打开本目录，使用工作区共享环境。程序只读取合成夹具，不安装依赖、不调用外部模型。

```powershell
& ..\..\..\.venv\Scripts\python.exe demo.py
```

预期8个技术子问题、10个工作日、30人时，预算100/估算20；模拟基准净28.750、低成功率净−6.250。所有金额为虚构单位，所有业务假设待证。程序检查通过不代表客服系统实现或业务验收完成。

## 代码导航

- [demo.py](./demo.py)：读取方案并展示结构检查与两种模拟收益。
- [planning.py](./planning.py)：预算、依赖、选项和字段一致性检查，以及十进制演算。
- [plan.json](./fixtures/plan.json)：明确标为模拟的需求、约束、八类候选、指标、风险与十日计划。
- [test_planning.py](./tests/test_planning.py)：正常结构及预算/选项/依赖/非法数字等失败路径。
- [requirements.txt](./requirements.txt)：运行代码仅使用Python标准库；作者验证用工作区已有pytest/Ruff。
