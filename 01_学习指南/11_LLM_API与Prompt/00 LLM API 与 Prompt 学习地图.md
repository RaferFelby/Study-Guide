## 在 VS Code 运行

1. 打开同级的 `示例工程` 文件夹。
2. 在该文件夹的 PowerShell 终端运行：

   ```powershell
   ..\..\..\.venv\Scripts\python.exe demo.py
   ```

   这会用工作区共享 `.venv` 的 Python 启动本机模拟服务并发送 HTTP 请求，全程不访问外网、不消耗模型额度。
3. 运行自动测试：

   ```powershell
   ..\..\..\.venv\Scripts\python.exe -m pytest -q
   ```

4. 从 [[01_学习指南/11_LLM_API与Prompt/示例工程/README|工程 README]] 打开源码导航，按课程顺序阅读 `api_client.py`、`structured_output.py` 和 `evaluation.py`。

## API 与模型服务说明

API（应用程序编程接口）是程序之间按约定交换数据的入口。LLM API 通常接收模型名、消息/输入与可选格式约束，返回生成内容、状态和 usage。不同服务的 URL、字段和响应结构可能不兼容。

教材以目前 OpenAI Responses API 的输入/响应思路作为资料参照；实际代码使用本机假服务，它只模拟必要的 HTTP 行为，不声称模拟了真实模型质量。OpenAI 官方 quickstart 展示 `client.responses.create(...)` 和 SDK 的 `response.output_text`；原始 API 响应则由多个 output item 组成，客户端要处理不同 item，不能默认第一个输出就是纯文本。参考 [官方 quickstart](https://platform.openai.com/docs/quickstart/make-your-first-api-request) 和[响应流/输出结构](https://platform.openai.com/docs/api-reference/responses-streaming/response/refusal)。

真实调用需要服务商账户、可用额度和密钥。此单元不要求你创建账户或安装 SDK；若之后要做真实调用，先按具体服务的文档选 SDK/模型/数据方案，密钥只放安全环境变量，确认费用后再运行。不同供应商的 JSON Schema 支持范围、幂等 header、速率限制和计费方式都应以当前 API 文档为准。
