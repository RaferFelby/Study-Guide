# 第 3 讲：拼齐变长序列并验证掩码

## 今天要解决什么问题

三条序列分别有 2、0、1 个整数，不能直接堆成每行等长的二维张量。我们要补齐它们，同时保留“哪些位置原本就有值”。这会用到列表、循环、函数、二维 Tensor 和切片；先完成前置讲的固定大小批次，不需要先理解语言模型。

分两次学习：第一次手填长度、补齐值和掩码，并运行跟做；第二次阅读组合函数、测试边界，再接 DataLoader。源码在 [batching.py](../示例工程/app/batching.py)，测试在 [test_batching.py](../示例工程/tests/test_batching.py)。

## 先手填一张表

原序列是 `[[4,0],[],[7]]`，其中第二条没有任何值，第一条的 0 是真实值。

| 行 | 原始序列 | 长度 | 右侧补零到长度 2 | 有效位置 mask |
| --- | --- | --- | --- | --- |
| 0 | `[4,0]` | 2 | `[4,0]` | `[True,True]` |
| 1 | `[]` | 0 | `[0,0]` | `[False,False]` |
| 2 | `[7]` | 1 | `[7,0]` | `[True,False]` |

padding 是补齐，mask 是按位置保存的布尔标记。本课明确 True 表示有效、False 表示补齐。这个约定必须随数据传递；别的库接口可能用 True 表示屏蔽，调用时重新核对，不能直接套用。

若用 `values != 0` 当 mask，会把第一条的真实零误删。因此应从原始长度生成 mask。长度为 0 的样本也有一行；它不同于“批次里一条样本都没有”。

## 跟做：运行并取回原序列

在 VS Code 打开本单元 `示例工程/`，用 `Get-Location` 检查终端目录。新建 `lesson_02_padding.py`，保存：

```python
from app.batching import collate_integer_sequences

sequences = [[4, 0], [], [7]]
padded_values, lengths, mask = collate_integer_sequences(sequences)
print(padded_values.tolist())
print(lengths.tolist())
print(mask.tolist())
for row in range(len(sequences)):
    print(padded_values[row][mask[row]].tolist())
```

运行 `..\..\..\.venv\Scripts\python.exe lesson_02_padding.py`，预期：

```text
[[4, 0], [0, 0], [7, 0]]
[2, 0, 1]
[[True, True], [False, False], [True, False]]
[4, 0]
[]
[7]
```

函数返回三个对象，用三个变量按顺序接住。`padded_values[row]` 取一行；再用同一行的布尔 mask 索引，只保留 True 位置。最后三行与原序列一致，说明补齐后仍能区分真实值与填充值。运行成功只完成跟做，下一步解释函数怎样产生这些值。

## 组合函数按什么顺序工作

打开 [batching.py](../示例工程/app/batching.py) 的 `collate_integer_sequences`。类型标注 `list[list[int]]` 表示列表中每项仍是整数列表；返回三个 Tensor 的元组。标注帮助阅读，实际检查由函数体执行。

1. 拒绝 `[]` 这样的空批次，否则无法求最长序列。允许 `[[]]`，因为它有一条长度为 0 的样本。
2. 遍历每条序列，把 `len(sequence)` 加入 `lengths_list`。检查每项是列表、值是有符号 64 位整数，范围为 `−2**63` 到 `2**63−1`；`**` 表示乘方，布尔值也拒绝。这里的整数可为负，并不是已经校验过词表范围的 token ID。
3. `batch_size` 是行数，`max(lengths_list)` 是最长长度。本例为 3 和 2。
4. `torch.zeros((batch_size,max_length), dtype=torch.long)` 创建全零整数矩阵；相同形状的 `dtype=torch.bool` 创建全 False 掩码。long 是本课使用的 64 位整数类型。此函数在 CPU 上组合，搬到模型设备在后续训练循环处理。
5. `enumerate` 给出行号和该行序列。`padded_values[row,:length]` 选从第 0 列到 length 之前，把原序列写入；`mask[row,:length] = True` 标记同样的位置。长度为 0 时跳过写入，该行保留填充值。
6. 把长度列表转为整数张量，依次返回值、长度和 mask。输入列表没有被修改。

如果二维切片还陌生，可先把它写成“第 row 行、前 length 格”。本例 row=2、length=1 时，只写第三行第一格，不会写第二格。

## 让 DataLoader 调用这个函数

另存为 `lesson_02_padding_loader.py`：

```python
from torch.utils.data import DataLoader
from app.batching import collate_integer_sequences

sequences = [[4, 0], [], [7]]
loader = DataLoader(
    sequences,
    batch_size=2,
    shuffle=False,
    collate_fn=collate_integer_sequences,
    num_workers=0,
)
for values, lengths, mask in loader:
    print(values.tolist(), lengths.tolist(), mask.tolist())
```

运行 `..\..\..\.venv\Scripts\python.exe lesson_02_padding_loader.py`，应看到：

```text
[[4, 0], [0, 0]] [2, 0] [[True, True], [False, False]]
[[7]] [1] [[True]]
```

传给 `collate_fn` 的是函数对象，名称后面没有括号。DataLoader 先取前两条，再调用它组合；最后一批只有 `[7]`，所以最长长度变成 1。每批按自己的最大长度补齐，不要求整个数据集都补到同一长度。`num_workers=0` 暂时让调用发生在当前进程，方便调试。

## 独立练习：边界与错误

先预测，再把第一个脚本的 sequences 分别改为 `[[1,2],[3,4]]`、`[[],[]]`、`[[],[1,2,3,4,5]]`。判断标准：每行 mask 的 True 数等于该行 lengths，mask 取回的值等于原序列。全空时还要打印 `list(padded_values.shape)`。

再单独运行非法输入 `[]`、`[ [True] ]`，确认清楚报 ValueError；每次修复后再做下一项，不能把预期失败当正常结果。若序列本身不是列表，例如用元组，则报 TypeError。

> [!example]- 独立练习参考答案与解析
> 等长时值原样保留，长度为 `[2,2]`，mask 四格均为 True。全空时值和 mask 的列表都为 `[[],[]]`，形状为 `[2,0]`，长度为 `[0,0]`。差异较大时第一行五个零、mask 五个 False；第二行五个原值、mask 五个 True。
>
> `[]` 报 `batch must contain at least one sequence`；`[ [True] ]` 报整数契约错误，布尔值不作为本课的整数输入。不要删掉检查来让坏数据通过。全空输出虽然组合合法，但许多模型不支持零长度或全屏蔽输入，进入模型前还要按任务过滤、拒绝或加有效标记。本函数没有声称全空可直接训练。

## 迁移练习：计算有效位置的平均值

对 `[[4,0],[],[7]]`，计算所有有效位置的平均数。提示：应为 `(4+0+7)/3`，不能把补齐的六格都算进分母；全空时还要先检查有效位置数。保存 `lesson_02_masked_mean.py`。

> [!example]- 迁移练习参考答案与解析
> ```python
> import torch
> from app.batching import collate_integer_sequences
>
> values, lengths, mask = collate_integer_sequences([[4, 0], [], [7]])
> valid_count = int(mask.sum().item())
> if valid_count == 0:
>     raise ValueError("没有有效位置，无法计算平均数")
> mean = values[mask].to(dtype=torch.float64).mean()
> print(round(mean.item(), 6))
> ```
> 输出应为 `3.666667`。布尔 mask 求和得到有效格数；`values[mask]` 取出有效整数，转成浮点再求平均。这里每个有效位置权重相同，不是每条序列权重相同；若任务要求逐样本等权平均，需要先定义空序列处理，再逐条求均值。完成判断：能解释分母为什么是 3；把输入改为 `[[],[]]` 时应先报清楚错误，避免对空张量求均值得到 NaN。

## 常见问题与完成判断

- 找不到 app：核对工程目录与脚本位置；不要把其他单元的 app 加入全局路径。
- 默认组合报长度不一致：检查 DataLoader 是否传入 `collate_fn`，以及输入是不是本题约定的整数列表。
- 输出大量补零：检查单批最长长度，按长度分组是后续优化；本课先保证值和 mask 正确。

能手填表、运行两个脚本、不看答案重建一行 mask、解释全空输入的模型限制，即可继续第 4 讲的模型与优化器。第 2 讲的分组划分迁移题可作为复习。本课仅处理整数序列，不包含标签移位、注意力方向或语言模型损失；这些在后续单元按实际接口继续学习。
