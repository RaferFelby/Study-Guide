## 开始前：打开示例工程

[[01_学习指南/06_PyTorch训练闭环/逐讲学习/05 训练验证与指标记录|第 5 讲：训练验证与指标记录]]先手算不同大小批次的损失，再用一个权重完成一轮训练，比较过程中记录的损失与轮末重新测量；日志解释后安排分层练习。[[01_学习指南/06_PyTorch训练闭环/逐讲学习/07 训练故障排查|第 7 讲：训练故障排查]]从只读观察器出发，完成正常运行、NaN 注入、定位与修复对照，最后写带实际证据的排错记录。

[[01_学习指南/06_PyTorch训练闭环/逐讲学习/02 Dataset与DataLoader|第 2 讲：Dataset与DataLoader]]先用四条样本练批次、末批、固定划分与指定顺序，再进入 [[01_学习指南/06_PyTorch训练闭环/逐讲学习/03 拼齐变长序列并验证掩码|变长批次详细课]]。第 3 讲提供长度、有效掩码、全空输入边界与独立答案，完成后继续第 4 讲。

[[01_学习指南/06_PyTorch训练闭环/逐讲学习/04 Module优化器与调度器|第 4 讲：Module优化器与调度器]]先用四个独立小实验核对参数数量、单步更新、AdamW 衰减和 StepLR 时机，再进入第 5 讲的完整训练循环。参数分组答案放在收起的提示框中；混合精度可在基础熟悉后回看。

1. 在 VS Code 中打开 01_学习指南/06_PyTorch训练闭环/示例工程/。
2. 按仓库根目录 README 选择 PyTorch CPU 或 CUDA 安装方式；本机所有单元共用根目录的 .venv。
3. 在工程根目录运行 `..\..\..\.venv\Scripts\python.exe -m pytest -q tests`，执行含续训对照在内的完整测试。
4. 再运行 `..\..\..\.venv\Scripts\python.exe train.py --epochs 30 --output-dir results/`，查看 history.json、last.pt 和 best.pt；使用未用过的输出目录以免覆盖旧实验。
5. 没有 GPU 时使用 CPU 运行；混合精度只在 CUDA 条件满足时启用，不把 CPU 运行伪装成 GPU 验证。
