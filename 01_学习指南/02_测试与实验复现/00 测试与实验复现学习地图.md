## 开始前：准备示例工程

教程说明在 Obsidian 阅读，源码与终端操作在 VS Code 中完成。

1. 用 VS Code 打开 `01_学习指南/02_测试与实验复现/示例工程/`。
2. 在工程根目录打开集成终端。
3. 按仓库根目录 README 一次性创建并准备共享 `.venv`。
4. 在本示例工程目录的 PowerShell 中运行 `..\..\..\.venv\Scripts\python.exe -m pip install --no-build-isolation -e .`，把当前源码包安装到共享环境。
5. 运行 `..\..\..\.venv\Scripts\python.exe -m pytest -q`。如果看到测试通过，说明本单元准备完成。

> [!info] 为什么要使用项目解释器
> `pytest`、`ruff` 等工具安装在仓库根目录的共享 `.venv` 中。使用 `..\..\..\.venv\Scripts\python.exe -m ...` 可明确选择工作区解释器，避免终端调用到其他 Python。
