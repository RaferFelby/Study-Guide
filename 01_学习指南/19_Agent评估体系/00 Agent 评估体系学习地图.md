## 操作与完成判断

示例工程终端：

```powershell
..\..\..\.venv\Scripts\python.exe evaluate.py --split test
..\..\..\.venv\Scripts\python.exe judging.py
..\..\..\.venv\Scripts\python.exe -m pytest -q tests
```

固定60条，dev/test各30，按10个服务分组；test五组。baseline任务成功10/30，guarded30/30，但二者回答指标都可为10/10。不能从100%合成规则得出真实LLM性能结论。

完成标准：给新任务写可操作gold；不把gold传给系统；明确每项n；指出工具选对但执行越权的失败；真实标注前不称人工一致率；配对报告可定位退步ID；成本注明实际或模拟。
