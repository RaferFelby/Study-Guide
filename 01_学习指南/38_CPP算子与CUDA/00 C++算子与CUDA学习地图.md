## 前置与完成标准

需要函数、循环、异常、命令行与测试的基础，陌生时回到 [[01_学习指南/01_Python工程化/00 Python 工程化学习地图|单元01]]、[[01_学习指南/02_测试与实验复现/00 测试与实验复现学习地图|单元02]]。Tensor、自动微分与CPU/GPU先到 [[01_学习指南/06_PyTorch训练闭环/00 PyTorch训练闭环学习地图|单元06]]；流与同步不默认掌握，第5、6讲会补讲。

教材在 Obsidian 读，源码由 [[01_学习指南/38_CPP算子与CUDA/示例工程/README|代码导航]]进入，在 VS Code 阅读与运行。所有 Python 命令使用根 `.venv`；本单元没有新的 Python 包。

| 路径 | 所需资源 | 完成判断 |
| --- | --- | --- |
| 第1～4讲CPU | 已有GCC、共享PyTorch环境 | C++程序与CPU DLL可编译、算子结果和梯度正确 |
| 第5～6讲CUDA | NVIDIA GPU、nvcc、Windows MSVC和SDK | CUDA DLL真正编译并执行，边界与流测试通过 |
| 暂无GPU或编译工具 | 先做CPU、手算线程索引 | 明确记录未执行的GPU项目，不能写成实测 |

> [!info] 本机环境
> 作者检测到GCC15.2、CUDA Toolkit13.2；用户批准后安装VS2022 Build Tools的MSVC v143和Windows SDK。PyTorch仍为2.14.0+cu130，运行时13.0。安装记录和实际范围见 [[90_参考与维护/单元验证/38 CPP算子与CUDA验证记录|作者验证]]。换机器先核对环境，缺依赖按工作区规则申请安装，不照抄系统安装命令。

**本单元完成标准：** 编译、检查边界、核对算子结果，再说明计时条件。

## 必须掌握与稍后扩展

必须能说明编译与运行的区别、对象与地址的区别、连续内存为什么重要、指针和长度必须一致、线程怎么找到元素、如何验证与公平计时。必须亲自保留至少一次失败排查和一个对照结果。

模板元编程、完整C++类体系、复杂ATen宏、共享内存优化、Tensor Core、CUDA Graph、跨GPU通信与生产发布都是后续扩展。本单元的DLL是教学用C接口，由Python注册PyTorch算子；没有编译依赖ATen对象的C++扩展，也不宣称覆盖所有PyTorch子系统。
