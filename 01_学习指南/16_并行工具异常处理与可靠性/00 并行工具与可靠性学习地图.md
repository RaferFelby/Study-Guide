## 运行与成功标准

在同级示例工程VS Code PowerShell终端：

```powershell
..\..\..\.venv\Scripts\python.exe demo.py
..\..\..\.venv\Scripts\python.exe -m pytest -q tests
```

预期三查询均成功，并行通常快于串行；冲突保留两份来源，不随便选一个；长输出有truncated和result_ref，可读回完整900字符文本。时间受系统调度影响，不要求固定毫秒。

完成标准：判断何时可并行、何时可重试；区分读超时与非幂等写的未知结果；解释并发上限与速率限制；取消后子协程清理；部分成功不会冒充全部完成。
