## 运行入口

在同级示例工程的VS Code PowerShell终端运行：

```powershell
..\..\..\.venv\Scripts\python.exe demo.py
..\..\..\.venv\Scripts\python.exe -m pytest -q tests
```

只用标准库；输出包括只读证据、确认前错误、确认后工单、同键重复结果和规则选择器评估。最终内存工单数1。
