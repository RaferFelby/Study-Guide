## 在哪个目录运行

在 VS Code 打开 `01_学习指南/13_RAG检索重排与评估/示例工程`，选择仓库根 `.venv` 解释器。PowerShell 终端执行：

```powershell
..\..\..\.venv\Scripts\python.exe demo.py
..\..\..\.venv\Scripts\python.exe -m pytest -q tests
```

第一个命令运行四种策略并保存 `results` 中的 JSON；第二个运行示例的自动检查。`..` 表示返回上一级目录，三个 `..` 从示例工程回到仓库根。若终端不在这个目录，先通过 VS Code 的“在集成终端中打开”切到它。

## 怎样判断完成

你能不看答案算出一条排名的 Recall/MRR/nDCG；解释 BM25、LSA 向量和融合的不同；区分漏召回、召回后答错、误拒和无依据回答；找到一条答案的证据原文；并说明这套 60 题为什么不能证明线上质量。

本单元有 24 个合成证据片段、48 条可回答题和 12 条无答案题。dev/test 各 30 题，同一服务分组不跨集合。稠密路线使用现有 scikit-learn 的 LSA；重排使用透明规则；答案层使用限定词白名单和原文抽取。**没有神经 Embedding、CrossEncoder 或真实 LLM 调用。** 这些简化让机制可读，也限制了实验的外推范围。
