## 前置与完成标准

本单元是原 38 个能力模块之外的**整合实战扩展**。它将已有单元 14～16、19～22、28～30 的接口思想连成同一工程，不直接导入各单元同名模块。基础正文仍应按前置学习，不需要先学原单元 38 的 CUDA。

先会 [[01_学习指南/14_Agent运行原理与状态机/00 Agent 运行原理与状态机学习地图|状态机]]、[[01_学习指南/15_工具调用协议与工具设计/00 工具调用协议与工具设计学习地图|工具契约]]、[[01_学习指南/17_SQL数据库与数据集成/00 SQL 数据库与数据集成学习地图|SQLite 与事务]]。不熟悉类／字典／异常时先返回 [[01_学习指南/01_Python工程化/00 Python 工程化学习地图|Python]]。本单元会重新解释 harness、动作摘要、事务恢复、角色交接等词。

进入本单元前，还应按 [[00_学习路线/02 学习Agent与RAG应用#阶段 5：审计、安全与整合|Agent 阶段 5 的顺序]] 补单元 10 第 1、3 讲与单元 28 第 1、5 讲的文本计数、模板和上下文预算；第 5 讲会直接使用这些概念。完整长期记忆、工作流与 MCP 可在后续扩展时继续。

完成后应能独立解释：谁提议动作，谁有权执行，状态存在哪里，批准绑定什么，崩溃后从哪里继续，以及为什么“模型回答了”不代表任务成功。完成物是一个数据库、一次正常轨迹、一次失败轨迹和一张组件职责图。

**本单元完成标准：** 保存正常与失败轨迹，解释批准、执行、恢复和答案核验。

## 本轮实践范围

使用共享 `.venv` 和 Python 标准库。默认规则后端、固定虚构政策、本地 SQLite 笔记；没有真实客户数据、邮件、支付或远程写入。真实模型接口保留为选做教程，按用户本轮选择，不作为学习验收要求。

这里没有生产身份认证、数据库加密、多进程并发写入或操作系统沙箱；一个数据库同一时刻只运行一个命令。SHA256 摘要防止批准内容错配，不是防篡改签名。外部副作用无法靠本地事务保证恰好执行一次。
