## 开始前：打开工程

教程里的说明和概念在 Obsidian 阅读，源代码在 VS Code 阅读和修改。

1. 在 VS Code 中打开工作区里的 `01_学习指南/01_Python工程化/示例工程/` 文件夹。
2. 打开“终端 → 新建终端”，查看终端当前位置；它应是示例工程目录。
3. 先检查仓库根目录是否已有 `.venv`，已有时直接使用；缺失时按根 README 核对版本并申请安装。工程声明要求 Python 3.11 或更新版本，实际验证版本以作者记录为准。
4. 在示例工程终端执行 `..\..\..\.venv\Scripts\python.exe --version`，确认正在使用根目录共享解释器。

> [!info] 后续讲的代码放在哪里运行
> 除了章节明确指定其他位置，练习文件都在 VS Code 打开的“示例工程”根目录新建，例如 `lesson_03.py`。一次复制并运行一个完整示例，不要把不同小节的代码全部拼在同一个文件里。PowerShell 中使用共享解释器运行：`..\..\..\.venv\Scripts\python.exe lesson_03.py`。如果代码从 `ticketkit` 导入内容，先按示例 README 安装当前单元。

> [!warning] 不熟悉终端也没关系
> 本课程的命令都在 VS Code 集成终端中运行。若提示“找不到文件”，先确认当前目录；若提示“找不到模块”，确认使用仓库根目录的共享 `.venv`，并按示例工程 README 安装当前单元。

## 建议的完成记录

每次学习后，在 [[02_学习记录/00 我的学习记录|我的学习记录]] 写几句话即可：学了哪一讲、亲自运行了什么、遇到什么问题、下次从哪里继续。

先完成每讲的跟做练习；能解释原因后，再做独立练习；最后用迁移练习证明你能把方法用于不同数据。不要把复制答案或参考工程运行成功写成自己独立完成。

> [!question] 求助时附上这些信息
> 说明你正在学哪一讲、运行了哪条命令、完整错误最后几行、你预期看到什么、实际看到什么。粘贴前检查并删除密码、token 和个人数据。
