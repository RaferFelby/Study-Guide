# 第 2 讲：沿轨迹找第一处错误与传播链

## 要解决的问题

最终任务failed只是传播链最后一环。先沿retrieval→planning→tool→model→parsing→task看哪步首次不符合预期。复习单元20trace关联，本工程事件简化成阶段序列，没有父子span与遥测平台。

## 执行链与缺失阶段

检索没证据时直接refused，不调用工具/模型；工具参数错时failed，也没有模型；模型输出已生成但JSON解析错时，model=ok/parsing=error。阶段缺失可能是前一步合理停止，不是日志漏记；需要对照实现和任务条件。

找第一处偏离是定位线索，不等于确定根因。例如tool invalid_arguments可能由planning写错参数，而工具正确拒绝。下一讲按职责区分。

## 最小示例：打印阶段而非只看结果

新建`lesson_events.py`：

```python
from cases import make_cases
from contracts import Settings
from pipeline import run_pipeline

for case in make_cases()[:3]:
    result = run_pipeline(case["input"], Settings())
    print("Case", case["case_id"])
    for event in result["events"]:
        print(event["stage"], event["status"], event["code"])
```

预期同义题retrieval missing→task refused；参数题retrieval ok→planning ok→tool error invalid_arguments→task failed；围栏题到model ok→parsing error invalid_output→task failed。stage=planning ok只表示提议已生成，不表示参数已经验证。

## 动手：为一条写传播链

选择parse-fence：输入format=markdown_json；工具读到days30；mock_model按夹具格式生成代码围栏JSON；strict json.loads看到首字符反引号，不能解析；输出仍保留默认failed。不是检索没找到，也不是天数算错。

写证据：tool read_completed、model mock_output_generated/format=markdown_json、parsing invalid_output。根因假设是解析契约不一致。修复可能是约束模型返回纯JSON，或接口合同确实允许围栏时加严格包装适配；不能盲目正则取任意花括号让垃圾输出“通过”。

## 上游重试的事件序列

upstream-transient baseline只有tool attempt1 upstream_timeout，task failed；max_attempts2则attempt1 error、attempt2 read_completed、model/parsing成功。只读查询可有限重试；参数/权限异常break，不通过重试改变授权。

本例失败用函数抛TimeoutError模拟，没有真实网络或backoff时间。生产退避/取消/限流处理沿单元16实现，不能把这里两次for循环说成完整可靠客户端。

## 权限错误为何没有error事件

baseline故意不检查owner，工具读取Bob常量成功、模型回答50、解析成功；任务answered。只有gold比较/权限策略检查能发现。修复enforce_owner后authorization deny owner_mismatch，并且actual_reads=0，没有model。

拒绝事件并非坏事：该任务本来不应读取。指标要区分预期权限拒绝与基础设施故障；不能为了减少error/deny日志删检查。

## 常见错误

- 缺modelspan就修模型：先看检索/工具是否已经停止。
- stage=ok当作整个任务正确：阶段日志是局部执行事实，gold/权限另检查。
- 最后一个错误就是根因：它可能只是上游错误的传播。
- 用模型生成的“我已读取”当工具日志：本工程事件来自应用函数，真实系统也要从执行层记录。

## 练习与答案

跟做：为三个Case写到首次偏离的序列。完成判断：不用“模型不好”概括全部失败。

独立：retrieval-alias的工具次数0是否说明工具坏了？

迁移：为你的多步任务画期望阶段与实际阶段，标证据缺失和需要加日志的位置。

> [!example]- 参考答案与解析
> 工具没有执行，无法从这次Case判断其行为；首次偏离是同义问题未检索到证据。先单测检索映射，再端到端重跑。
>
> 期望图不一定唯一，可允许合理替代路径；记录事实，不把模型未公开推理编造成轨迹。需要证据时在工具/资源边界加最小日志。
