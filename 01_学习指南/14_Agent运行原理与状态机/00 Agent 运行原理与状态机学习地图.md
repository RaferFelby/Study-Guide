## 前置与完成标准

- 会调用函数、读字典、写判断与循环；需要复习时从[[01_学习指南/01_Python工程化/00 Python 工程化学习地图|Python单元]]返回相应讲。
- 能区分工具返回和最终答案；回顾[[01_学习指南/11_LLM_API与Prompt/逐讲学习/03 用 Schema 验证结构化输出|结构校验]]。
- 理解引用/拒答；回顾[[01_学习指南/13_RAG检索重排与评估/逐讲学习/05 分别评估召回答案与拒答|答案评估]]。
- 不要求会Agent框架、异步或模型内部推理；枚举、状态机和trace在本单元从头解释。

**本单元完成标准：** 从 trace 解释决策、行动、反馈、预算和终止原因。

## 运行与成功判断

在 VS Code 打开同级 `示例工程`，从其PowerShell终端运行：

```powershell
..\..\..\.venv\Scripts\python.exe demo.py
..\..\..\.venv\Scripts\python.exe -m pytest -q tests
```

默认状态 `completed`、决策步数2、内存工单数0；答案包含30 days及逻辑引用。完成本单元时，你应能不用看答案说明“第一步查资料、第二步完成回答”，并解释为什么执行成功不等于答案质量已经通过评估。
