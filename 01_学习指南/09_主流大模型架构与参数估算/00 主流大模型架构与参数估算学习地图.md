## 打开并运行估算器

1. 在 VS Code 打开本单元的 示例工程 目录。
2. 在目录内的 PowerShell 运行：

~~~powershell
..\..\..\.venv\Scripts\python.exe estimate.py configs\qwen2_5_7b.json --batch-size 4 --sequence-length 8192
~~~

3. 把配置换为 configs\llama3_1_8b.json 再运行。batch 是并发序列数，sequence-length 是已缓存 token 数。
4. 运行单元测试：

~~~powershell
..\..\..\.venv\Scripts\python.exe -m pytest -q
~~~

输出是理论估算。权重体积不等于完整 GPU 显存需求；KV 公式假设普通逐层 K/V 缓存，不直接适用于 MLA 或量化缓存。
