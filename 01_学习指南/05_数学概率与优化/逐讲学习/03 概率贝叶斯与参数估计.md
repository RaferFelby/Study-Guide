## 这一讲要解决什么问题

模型面对的是不确定信息：一封邮件可能是垃圾邮件，一次观测可能来自多个分布。概率用来表达不确定性；参数估计用有限样本推测未知规律。先区分事件、条件和参数，后面的交叉熵与训练目标才不会变成公式记忆。

## 条件概率和贝叶斯公式

条件概率 P(A|B) 表示“已经知道 B 发生时，A 发生的概率”。贝叶斯公式把方向反过来：

~~~text
P(A|B) = P(B|A) P(A) / P(B)
~~~

其中 P(A) 是先验，P(B|A) 是似然，P(A|B) 是看到证据后的后验。分母 P(B) 负责归一化，让后验概率仍然落在 0 到 1 之间。

一个常见错误是把 P(阳性|患病) 当成 P(患病|阳性)。前者是检测敏感度，后者还受到患病率和假阳性率影响。

## 常见分布的用途

- 伯努利分布描述一次只有成功/失败的试验，参数是成功概率。
- 二项分布描述固定次数、相互独立且成功概率相同的伯努利试验中的成功次数。
- 正态分布常用于近似连续测量误差；均值控制中心，标准差控制分散程度。
- 分类模型输出的概率通常是离散类别分布，所有类别概率之和应为 1。

分布是建模假设，不是自然界保证。使用正态分布前要问数据是否近似对称、是否有明显长尾；使用独立同分布假设前要问样本是否来自相同过程。

本讲下面先用“已观察到三次成功、两次失败”的小例子理解最大似然，只需上面伯努利分布的定义和乘法。下一讲 [[01_学习指南/05_数学概率与优化/逐讲学习/04 用具体数据理解概率分布|用具体数据理解概率分布]] 再展开二项计数、均值、方差、标准差和正态区间概率，并提供完整脚本、分层练习和答案；不需要先掌握积分。

## 最大似然：让观测数据最可能

假设每次投掷相互独立，正面概率都是 θ。记录了一个包含 7 次正面、3 次反面的具体序列，该序列的似然函数是：

~~~text
L(θ) = θ^7 (1 - θ)^3
~~~

最大似然估计选择让 L(θ) 最大的 θ。对伯努利样本，答案是正面次数除以总次数，也就是 0.7。实际计算常使用对数似然，把连乘变成求和，减少下溢并更便于求导。

如果只记录“10 次中有 7 次正面”，而不记录顺序，二项概率还要乘以排列这些正反结果的方式数 120。这个因子与 θ 无关，所以两种观测方式的概率表达不同，但此处最大似然的最优 θ 都是 0.7。不要把省略常数后的优化目标直接当作事件的完整概率。

## 置信区间不是参数有某个概率

频率学派的 95% 置信区间，是一种重复抽样程序的覆盖率描述：如果用同一方法反复抽样并构造区间，长期约 95% 的区间会覆盖真实参数。不能严格表述为“这一次真实参数有 95% 概率在区间里”。贝叶斯可信区间的解释不同，需要区分术语。

## 动手操作

先把上面的符号换成能数出来的记录。用一个假设的故障检测器作练习：10 000 台设备中，约 100 台有故障；其中 99 台报警。其余 9 900 台无故障，若误报率为 5%，约 495 台也报警。报警设备共约 594 台，真正有故障的比例约为 `99 / 594 = 1/6`。这些是假设比例下的期望数量，不保证每一批真实设备恰好如此。

1. 在 VS Code 打开本单元 `示例工程` 文件夹，新建 `lesson_02_probability.py`。
2. 输入下面的完整代码并保存。函数实现可在 [math_basics.py](../示例工程/app/math_basics.py) 中对照。

~~~python
from app.math_basics import bayes_posterior, bernoulli_mle

posterior = bayes_posterior(
    prior=0.01,
    likelihood_if_true=0.99,
    likelihood_if_false=0.05,
)
print(posterior)
print(bernoulli_mle([1, 1, 0, 1, 0]))
~~~

`prior` 是故障发生率；`likelihood_if_true` 是有故障时报警的概率；`likelihood_if_false` 是无故障时报警的概率。这里的 true/false 对应“故障是否存在”，不是报警结果。参数写成 `名称=数值`，便于检查是否把两个条件方向放反；概率用 0～1 的小数，1% 写成 `0.01`。`bernoulli_mle` 接受 0/1 观测列表，返回成功次数除以样本总数。

3. 在这个示例工程目录的 PowerShell 运行：

~~~powershell
..\..\..\.venv\Scripts\python.exe lesson_02_probability.py
~~~

第一行接近 `0.16666666666666666`，即报警后约 16.7% 有故障；第二行是 `0.6`。公式中分子为 `0.99×0.01=0.0099`，分母为 `0.0099+0.05×0.99=0.0594`，与数设备的算法一致。

4. 只把 `prior` 改成 `0.10`，先预测结果变大还是变小，再运行。预期后验为 `0.6875`。传感器的两种条件概率没有改，但故障更常见时，报警中真故障的占比会增加。

完成标准：两个初始输出正确；能说明分母为什么包括误报，并解释修改先验后的变化。这里是固定条件概率的一次贝叶斯更新，没有用日志拟合传感器参数。

## 常见错误

- 混淆先验、似然、证据和后验。
- 看到样本比例就称为真实概率，没有说明抽样误差。
- 把置信区间和可信区间当成同一概念。
- 只写分布名称，不说明每个参数控制什么以及假设是否合理。
- `No module named 'app'`：确认练习文件在本单元示例工程根目录，终端也在该目录；不要从其他单元运行同名 app。
- 把百分数直接填为 99：本接口要求概率在 0～1 内，应填写 `0.99`；报错时检查每个参数的单位。

## 练习与答案解析

### 跟做练习：贝叶斯更新

某故障发生率为 2%，传感器在故障时报警率为 90%，无故障时误报率为 10%。求报警后真的发生故障的概率。

> [!example]- 参考答案
> 分子是 0.90×0.02 = 0.018。分母还要加上无故障误报 0.10×0.98 = 0.098，因此后验是 0.018 / 0.116，约为 15.5%。报警率高不代表报警后故障概率同样高，基准发生率很重要。

### 独立练习

写一个函数计算一组 0/1 样本的伯努利 MLE。测试空样本、全 0、全 1 和一半成功；明确空样本是报错还是返回约定值。

提示：`len(samples)` 得到列表长度，`sum(samples)` 求和；在除法前处理空列表。这里只接受由数字 0、1 组成的观测。完成标准：正常样例给出正确比例，空输入和混入 2 的输入明确报错。

> [!example]- 独立练习参考答案
> 新建 `lesson_02_mle.py`，使用同一个共享解释器运行。
> ~~~python
> def estimate_probability(samples):
>     if len(samples) == 0:
>         raise ValueError("至少需要一条观测")
>     for sample in samples:
>         if sample not in (0, 1):
>             raise ValueError("每条观测必须为 0 或 1")
>     return sum(samples) / len(samples)
>
> print(estimate_probability([0, 0]))
> print(estimate_probability([1, 1]))
> print(estimate_probability([0, 1]))
> ~~~
> `(0, 1)` 是包含两个允许值的元组，这里用于成员检查。三行应为 `0.0`、`1.0`、`0.5`。分别把最后一个调用的列表改成 `[]` 和 `[0, 2]`，应得到上述两类 ValueError。空列表无法估计比例，直接返回 0 会把“没有观测”误说成“观测中全部失败”。这里校验的是值，Python 中 `True`/`False` 会分别与 1/0 相等；如果业务禁止布尔值，还需额外检查类型。

### 迁移练习

在 Agent 日志中，把“工具调用失败”当作事件，设计一个简单的后验更新例子。说明哪些观测可能不是独立的，以及这会怎样影响结论。

提示：设 F 为调用失败，A 为出现超时预警；给出 P(F)、P(A|F)、P(A|非 F)，再计算 P(F|A)。这些概率可以是假设值，但必须写明，不要冒充真实日志测量。

> [!example]- 迁移练习参考答案
> 假设 P(F)=0.10，P(A|F)=0.80，P(A|非 F)=0.05。则 P(F|A)=0.08/(0.08+0.045)=0.64。解释为“在这组假设下，出现预警的调用有 64% 会失败”。一次贝叶斯公式不要求 F 与 A 独立；预警有信息，恰恰是两者相关。
> 同一次服务中断期间的多次重试可能相关，不能把它们随意视为多条独立证据，把相同似然反复相乘。估计这些概率时还应记录时间范围、请求类型与来源，避免用另一种流量的数据直接套用。能区分“一次条件概率更新”和“多条证据的独立性假设”即完成迁移目标。

## 本讲小结

概率先描述不确定性，贝叶斯用新证据更新信念，最大似然用观测数据选择参数。每个公式都依赖假设；说清假设比只报一个数字更重要。
