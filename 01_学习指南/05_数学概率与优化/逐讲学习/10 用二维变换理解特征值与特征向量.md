## 矩阵怎样改变一个向量

一个二维向量 `[x, y]` 可以画成从原点指向坐标 `(x, y)` 的箭头。矩阵规定如何从原坐标算出新坐标。取：

```text
A = [2  1]       v = [x]       Av = [2x + y]
    [1  2]           [y]            [ x + 2y]
```

这是线性变换：对输入先相加再变换，与先分别变换再相加相同；对输入乘一个数也能提到变换外面。这里没有另加偏置项。若使用神经网络的 `Wx+b`，`b` 非零时整体是仿射变换，不能直接用 `Wv=λv` 描述整个输出。

先算三种输入：

| 输入 v | 第一行计算 | 第二行计算 | 输出 Av | 观察 |
|---|---|---|---|---|
| `[1, 0]` | 2×1+1×0=2 | 1×1+2×0=1 | `[2, 1]` | 不再沿横轴 |
| `[1, 1]` | 2×1+1×1=3 | 1×1+2×1=3 | `[3, 3]` | 整个向量乘了 3 |
| `[1, -1]` | 2×1+1×(-1)=1 | 1×1+2×(-1)=-1 | `[1, -1]` | 整个向量乘了 1 |

后二者很特别：变换后的箭头仍落在原向量所在的直线上。**特征向量（eigenvector）**就是满足这种倍数关系的非零向量；对应倍数叫**特征值（eigenvalue）**，常用希腊字母 λ（lambda）表示：

```text
A v = λ v，且 v 不能是零向量。
```

左侧用矩阵乘法，右侧用一个数乘向量的每个分量。对同一个特征对，两侧结果相同。`[1,1]` 对应 λ=3，`[1,-1]` 对应 λ=1。`[1,0]` 不是本矩阵的特征向量：无论 λ 取什么，`λ[1,0]` 的第二个分量都是 0，不可能等于 `[2,1]`。

这种方向能帮助我们拆解变换。例如 `[2,0]=[1,1]+[1,-1]`，所以 `A[2,0]=3[1,1]+1[1,-1]=[4,2]`。把输入拆成两个已知方向后，每个部分只需乘自己的倍数。这是后面重构公式的直觉。

### 倍数与方向，必须分开说

| λ 的情况 | 对特征向量的作用 | 简单例子 |
|---|---|---|
| λ=3 | 长度乘 3，朝向保持 | `[1,1]` 变成 `[3,3]` |
| λ=0.5 | 长度减半，朝向保持 | `[2,0]` 变成 `[1,0]` |
| λ=-2 | 长度乘 2，朝向翻转 | `[1,0]` 变成 `[-2,0]` |
| λ=0 | 输出变为零，输出没有方向 | `[0,1]` 变成 `[0,0]` |

所以“特征向量方向不变”不够准确：负数会反向，零会把它压到原点。应先检查倍数等式，再用“仍在同一直线内”理解非零输出。

不能把零向量当作特征向量，因为对任意矩阵、任意 λ，都有 `A0=λ0=0`，它无法告诉我们哪个 λ 是矩阵的特征值。**λ 可以为零，v 不能为零。**

如果 v 是特征向量，2v、-v 也对应同一个 λ。它描述的是一条方向线，不是唯一长度、唯一符号的箭头。不能把软件输出与自己手写向量逐元素不同，就判断计算错误。

## 动手二：让程序寻找方向并重构矩阵

### 为什么选择实对称矩阵

方阵的行数与列数相同；本课 `A` 还是**对称矩阵**：转置后与原矩阵相同，即 `A.T == A` 逐项成立。对角线两侧对应的元素相等，不能只检查对角线。

实对称矩阵的特征值都是实数，而且可以选到一组两两垂直、长度为 1 的特征向量，叫**正交归一**的向量组。NumPy 的 `eigh` 适用于这一类矩阵；返回特征值按升序排列，特征向量放在对应的列中。[接口依据：NumPy eigh](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eigh.html)。

`eigh` 默认只读取下三角，不能把“调用没有报错”当作输入对称的证明。配套 [eigen_demo.py](../示例工程/eigen_demo.py) 的 `decompose_symmetric_matrix` 先检查形状、实数、有限值与严格对称，再调用它。这里要求上下三角逐项完全相等是**教学接口约定**；工程中来自浮点计算的近似对称数据需要另行讨论误差，不能随意改一半数据后宣称求解的是原矩阵。

阅读函数时沿下面的顺序看，不必先记住每个检查函数的拼写：

1. `np.asarray` 将输入组织成数组，`ndim` 是维度数，`shape[0]`／`shape[1]` 是行数／列数；先确认二维非空，才读取第二个轴，避免检查本身越界。
2. `np.iscomplexobj` 判断是否为复数类型；本课只处理实数。随后 `dtype=np.float64` 统一成 64 位浮点数，允许原输入是整数数组。
3. `np.isfinite` 对每个元素检查是否为有限值，`np.all` 要求全部通过；NaN 表示无效数值，inf 表示无穷，都不交给本教学接口求解。
4. `np.array_equal(matrix, matrix.T)` 逐项检查严格对称。失败时 `raise ValueError(...)` 停止调用并解释输入问题，不伪造结果。
5. 条件满足后才调用 `eigh` 并返回两个数组。函数不写文件、不修改调用者的数组；脚本底部的入口判断保证导入函数时不会自动打印实验。

### 先运行工程，再读自己的检查脚本

在相同终端运行 `..\..\..\.venv\Scripts\python.exe eigen_demo.py`。它输出特征值 `[1.0,3.0]`、两个特征对的残差、重构检查，以及负特征值对照；详细机制在下文展开。

创建 `lesson_05_eigen_reconstruction.py`：

```python
import numpy as np

from eigen_demo import decompose_symmetric_matrix

matrix = np.array([[2.0, 1.0], [1.0, 2.0]])
eigenvalues, eigenvectors = decompose_symmetric_matrix(matrix)
print("形状：", eigenvalues.shape, eigenvectors.shape)
print("特征值：", eigenvalues.tolist())
for index in range(len(eigenvalues)):
    eigenvector = eigenvectors[:, index]
    residual = matrix @ eigenvector - eigenvalues[index] * eigenvector
    print(index, "残差足够小：", bool(np.linalg.norm(residual) < 1e-10))
    print("长度约为 1：", bool(abs(np.linalg.norm(eigenvector) - 1.0) < 1e-10))

diagonal = np.diag(eigenvalues)
reconstructed = eigenvectors @ diagonal @ eigenvectors.T
error = np.linalg.norm(matrix - reconstructed)
print("重构通过：", bool(error < 1e-10))
```

用 `..\..\..\.venv\Scripts\python.exe lesson_05_eigen_reconstruction.py` 运行，预期：

```text
形状： (2,) (2, 2)
特征值： [1.0, 3.0]
0 残差足够小： True
长度约为 1： True
1 残差足够小： True
长度约为 1： True
重构通过： True
```

按执行顺序理解：

1. 函数返回两个数组，左侧两个变量按顺序接收；`eigenvalues` 是两个数，`eigenvectors` 是两行两列。
2. `range(len(eigenvalues))` 产生索引 0、1。`eigenvectors[:, index]` 的 `:` 取所有行，第二个索引取指定列；不要写成 `eigenvectors[index]`，后者取行。
3. **残差**是本应相等的两侧之差 `Av-λv`；对残差向量取 L2 范数，得到非负误差大小。`np.linalg.norm` 对向量把平方和开方，对此处二维差矩阵默认计算 Frobenius 范数，也是所有元素平方和开方。
4. 理论残差是 0，浮点计算可能得到约 `1e-15`。先检查量级和容差，不强制要求 `== 0`。`bool` 把 NumPy 的布尔标量转成 Python 布尔值，打印为 `True`／`False`。
5. `np.diag(eigenvalues)` 把两个值放到方阵对角线上，其他位置填 0。它不负责排序，顺序沿用函数结果。
6. `Q = eigenvectors`，`Λ = diagonal`，这里重构式为 `A=QΛQᵀ`。所有因子都是 2×2。

为什么重构成立？Q 的列是两条单位方向，`Qᵀx` 用点积求输入在它们上的坐标，Λ 分别乘上特征值，Q 再把两个分量合回原坐标。对本例，两条方向可选为 `[1,-1]/√2` 与 `[1,1]/√2`；除以 √2 后长度变成 1。利用正交归一性质，`QᵀQ` 是单位矩阵 I（对角线 1，其余 0），因此上述来回转换不会凭空改变输入。

这个转置重构式依赖所选方向正交归一。不要把任意矩阵的一组特征向量都直接代入。若只给向量取反，公式仍成立；若任意把它放大两倍而不调整坐标转换，公式一般会失效。

再做一次失败检查：只把脚本矩阵右上角的 1.0 改为 2.0，左下角仍保持 1.0。运行应停止，终端最后一行提示 `ValueError: 矩阵必须严格对称；请核对上下三角元素。`。这说明输入检查发现了不适用的矩阵；修正练习中的录入值后再继续。不要通过删掉检查来让它“运行成功”。

## 三条容易误导人的推广

### 特征值相同，不代表特征向量只有一个答案

对 `2I`，任意非零 v 都有 `2Iv=2v`；二维情况下软件仍只返回两列作为一组基（能组合出平面任意向量的方向组）。这是**重复特征值**的例子。软件可能选择不同的正交归一基，既不能要求它列出无限多个向量，也不能要求每次返回相同列。

检查每列是否满足等式、长度是否为 1、列间点积是否接近 0，以及重构是否正确。不能用“与我的参考向量逐元素相等”作为唯一通过标准。

### 普通实方阵不一定有实特征向量

考虑逆时针旋转 90 度的矩阵：

```text
R = [0 -1]       R[x,y]ᵀ = [-y,x]ᵀ
    [1  0]
```

每个非零实向量都被转到垂直方向，无法成为原向量的实数倍，因此没有实特征向量。若扩展到复数（包含满足 i²=-1 的虚数单位 i），可以讨论它的复特征值，但当前无需学习复数运算。

一般方阵使用 `np.linalg.eig`，其结果不保证升序，也可能包含复数；它还不保证有足够多的独立特征向量完成对角分解。[接口依据：NumPy eig](https://numpy.org/doc/stable/reference/generated/numpy.linalg.eig.html)。这不是实对称例子计算失败，而是适用条件不同。矩形矩阵也不能直接套用同一 `Av=λv`：两侧向量长度不同。

### 奇异值不是把所有特征值换个名字

下一讲会完整讲 SVD。这里先把**奇异值**当作矩阵沿适当输入方向的非负长度缩放量；它允许输入方向与输出方向不同，也适用于矩形矩阵。先用反例避免混淆，分解形状留到下一讲。

创建 `lesson_05_eigen_vs_svd.py`：

```python
import numpy as np

negative_matrix = np.diag([-2.0, 1.0])
print("对称特征值：", np.linalg.eigh(negative_matrix)[0].tolist())
print("对称奇异值：", np.linalg.svd(negative_matrix, compute_uv=False).tolist())

shear = np.array([[1.0, 1.0], [0.0, 1.0]])
print("剪切特征值：", np.linalg.eig(shear)[0].tolist())
print("剪切奇异值：", np.linalg.svd(shear, compute_uv=False).round(6).tolist())
```

按前面的命令换成这个文件名运行，预期：

```text
对称特征值： [-2.0, 1.0]
对称奇异值： [2.0, 1.0]
剪切特征值： [1.0, 1.0]
剪切奇异值： [1.618034, 0.618034]
```

`eigh(...)[0]`、`eig(...)[0]` 只取返回结果的第一项，即特征值数组。`compute_uv=False` 表示只求奇异值，暂时不求两侧的方向数组；`round(6)` 保留六位小数用于展示。NumPy 的 SVD 将奇异值从大到小返回，与 `eigh` 的升序不同。[接口依据：NumPy SVD](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)。

第一个矩阵沿横轴反向放大 2 倍，所以特征值有 -2，长度缩放量却是 2。**对于实对称矩阵，奇异值是特征值绝对值再按降序排列**；这并非任意方阵的规则。

第二个矩阵是剪切：`[x,y]` 变为 `[x+y,y]`，上方的点横向移动。λ=1 时，等式要求 y=0，所以只有横轴这一条独立特征方向。两个特征值虽然都是 1，却不能据此说它保持所有长度：`[0,1]` 长度为 1，输出 `[1,1]` 长度为 √2。奇异值也确实不是 `[1,1]`。这些数描述变换的不同方面，不直接代表模型质量或业务效果。

## 常见错误与排查

| 现象 | 检查什么 | 怎样修正 |
|---|---|---|
| `ModuleNotFoundError: eigen_demo` | 当前目录与文件位置 | 用 `Get-Location` 确认在本单元工程目录；不要从其他单元的 `app` 目录运行 |
| `No module named numpy` | 是否误用了系统 Python | 使用仓库共享解释器；确实缺包时按依赖规则处理 |
| 提示方阵、严格对称或有限实数错误 | `shape`、上下三角、NaN／inf | 核对录入数据；非对称任务应重新选择算法，不强制复制一侧来掩盖问题 |
| 取出的特征向量核对失败 | 是否取成了一行，值与列是否错配 | 使用 `[:, index]`；若重新排序值，必须同步重排向量列 |
| 向量符号与答案相反 | 两侧等式是否仍成立 | 同时给 v 与 Av 取反不改变 λ，比较残差 |
| 零向量也得到残差 0 | 是否检查 v 非零 | 将“非零”作为定义的一部分，不能只比较两侧 |
| 误差显示 `2e-16` | 是否把浮点舍入当成算法错误 | 本课小矩阵用 1e-10 容差；大尺度问题需另选误差标准 |
| `LinAlgError` 或浮点范围异常 | 输入尺度、求解器是否收敛 | 保留原始错误，先用本课小矩阵复现；不要把失败替换成全零结果 |

## 练习：先预测，再运行

### 跟做：换一条方向

将第一个脚本改为 v=`[1,-1]`、λ=1，再改为 v=`[-2,2]`、λ=1。先写出两侧，再运行。完成判断：两次都通过，并能说明第二次只是第一条方向的 -2 倍。

> [!example]- 参考答案
> 第一组两侧都是 `[1,-1]`。第二组矩阵乘法得到 `[-4+2,-2+4]=[-2,2]`，右侧也为 `[-2,2]`。向量倍乘并不会改变对应特征值；不能把向量扩大两倍误写成特征值也乘两倍。

### 独立：负数与零是否都合法

矩阵 B 的对角线是 -2、0，其他元素为 0。分别检查 v₁=`[1,0]`、v₂=`[0,1]`。两者的 λ 是多少？输出为零时，输入是否仍可以是特征向量？零输入又为什么不行？提示：把两行乘法分别写出。

完成判断：写出两个特征对，明确负数翻转、零值压扁与零向量被排除的区别，再核对以下脚本。

> [!example]- 参考答案与运行核对
> Bv₁=`[-2,0]`，λ₁=-2；Bv₂=`[0,0]`，λ₂=0。v₂ 本身非零，合法；v=0 对任意 λ 都成立，不合法。保存为 `lesson_05_eigen_boundary.py`，使用共享解释器运行：
>
> ```python
> import numpy as np
> 
> from eigen_demo import decompose_symmetric_matrix
> 
> matrix = np.diag([-2.0, 0.0])
> eigenvalues, eigenvectors = decompose_symmetric_matrix(matrix)
> print("特征值：", eigenvalues.tolist())
> print("两个输入的输出：", (matrix @ np.eye(2)).tolist())
> for index in range(2):
>     vector = eigenvectors[:, index]
>     residual = matrix @ vector - eigenvalues[index] * vector
>     print(bool(np.linalg.norm(vector) > 0), bool(np.linalg.norm(residual) < 1e-10))
> ```
>
> `np.eye(2)` 创建 2×2 单位矩阵，它的两列正好是题目给出的两个输入；相乘后每列是相应输出。预期特征值 `[-2.0,0.0]`，输出矩阵第一行 `[-2.0,0.0]`、第二行全零，之后两行均为 `True True`。显示 `-0.0` 与 `0.0` 在本例中数值相同。

### 迁移：能否先预测新的矩阵

把动手二的矩阵对角线改为 3，非对角线保持 1。不要先运行：预测 `[1,1]`、`[1,-1]` 的特征值，再预测软件返回顺序。然后改为 `2*np.eye(2)`，说明为什么不应固定要求某一组返回向量。

完成判断：第一组特征值顺序正确、两次残差和重构通过；对第二组能同时给出横纵轴与两条对角线这两种合法的单位方向组。

> [!example]- 参考答案与推理
> 新矩阵把 `[1,1]` 变成 `[4,4]`，对应 λ=4；把 `[1,-1]` 变成 `[2,-2]`，对应 λ=2。软件升序返回 `[2,4]`，所以第 0 列对应反向符号的一对分量，第 1 列对应同号分量，整体正负号不限。
>
> `2I` 返回 `[2,2]`。可选 `[1,0]` 与 `[0,1]`，也可选 `[1,1]/√2` 与 `[1,-1]/√2`；两组都长度为 1、互相垂直。按动手二替换矩阵后，特征对残差和重构检查都应通过。这里只要求数学性质成立，不要求软件一定返回第二种基。
