# 第 8 讲：链式法则与反向传播

## 这一讲要解决什么问题

训练模型时，损失只在最后产生，但我们需要知道每个前面参数应该怎样改变。链式法则把一长串函数的影响逐段相乘；反向传播就是按计算图从后往前应用链式法则。

本讲需要会乘法、平方和代入一个函数，不要求已经学过微积分。Python 函数不熟时先回到 [[01_学习指南/01_Python工程化/逐讲学习/01 运行Python并统计工单|函数、判断与运行脚本]]。阅读顺序是：变化率 → 单个参数的导数 → 链式法则 → 数值核对 → 练习。PyTorch 部分可在理解手算以后再做。

## 先理解导数和偏导数

设 `f(w) = w²`，意思是输入一个数 w，输出它的平方。w 从 3 增加到 3.1 时，输出从 9 增加到 9.61。平均变化率是输出变化量除以输入变化量，即 `(9.61 - 9) / (3.1 - 3) = 6.1`。它描述这一个区间的变化。

如果输入只增加很小的 h，就有：

~~~text
[f(w + h) - f(w)] / h
= [(w + h)² - w²] / h
= [2wh + h²] / h
= 2w + h       （h 不为 0）
~~~

让 h 越来越接近 0，变化率越来越接近 `2w`。这个极限存在时，称为函数在该点的**导数**，记为 `f'(w)` 或 `df/dw`；在 w=3 时为 6。不能直接在原分式里把 h 设为 0，因为会除以零。

把它类比成速度：平均速度看一段路，导数看某个位置附近的变化快慢。实际机制是函数值的局部变化率，不要求变量真的是时间或距离。导数为 6 表示很小的输入变化 Δw 会带来约 `6 × Δw` 的输出变化；这是局部近似，不能用它保证任意大步长的结果。

当 `L(w, b)` 同时依赖 w 和 b，求 w 的**偏导数**就是固定 b 等其他量，只改变 w。常写作 `∂L/∂w`；下文为便于文本阅读也写 `dL/dw`，含义仍是固定其他独立输入。把各参数的偏导排在一起，就得到**梯度**，例如 `(∂L/∂w, ∂L/∂b)`。本讲先处理标量，也就是单个数；矩阵梯度稍后再学。

需要的三条局部规则：`z²` 对 z 的导数是 `2z`；固定 x 和 b 时，`wx+b` 对 w 的偏导是 x，对 b 的偏导是 1。这后两条可用“w 增加 h，z 就增加 xh；b 增加 h，z 就增加 h”直接验证。

## 一个可以手算的网络

定义：

~~~text
z = w x + b
a = z²
L = a
~~~

这里 x 是固定输入，w 是可调整的权重，b 是可调整的偏置；z 是乘加中间值，a 是平方结果，L 是为了练习求导选的标量目标。此处没有真实标签，不表示所有训练任务都应该最小化输出平方。

取 x = 2、w = 3、b = 1。前向计算是 z = 7，a = 49，L = 49。w 先影响 z，z 再影响 a，a 最后成为 L；把每段的变化倍率相乘，就是链式法则。现在求 w 对损失的影响：

~~~text
dL/dw = dL/da × da/dz × dz/dw
      = 1 × 2z × x
      = 1 × 14 × 2
      = 28
~~~

同理 dL/db = 14，因为 dz/db = 1。梯度为正，说明在当前点增大 w 或 b 会让这个损失增大；梯度下降会沿相反方向更新。

用 Δw=0.001 作直觉核对：局部预测 ΔL≈28×0.001=0.028；实际 `(3.001×2+1)² - 49 = 0.028004`。很接近但不完全相同，因为函数有弯曲，线性近似没有保留平方变化项。

## 计算图和局部导数

把每个中间变量画成节点，把函数关系画成箭头。前向时保存中间值，反向时从损失开始，把“上游梯度”乘以当前节点的局部导数，再传给前一个节点。共享变量会收到来自多条路径的梯度之和。

这就是自动求导的核心。自动求导不是数值差分，也不是把公式全部符号化简；它是在实际执行计算时记录运算图，再用局部导数传播。

## 有限差分核对

对于函数 f(w)，用很小的 ε 估计导数：

~~~text
f'(w) ≈ [f(w + ε) - f(w - ε)] / (2ε)
~~~

有限差分适合检查一个小函数的手算梯度，但它需要多次前向计算，且 ε 太大或太小都可能有误差。它不是训练大模型的替代方案。

ε 读作 epsilon，是向左右各挪动的距离。过大时可能跨过曲线明显弯曲的区域；过小时两个很接近的浮点数相减，会损失有效数字。对这里的平方函数，中心差分在精确算术中恰好给出导数，但在计算机里仍有舍入误差，不应推广成任意函数都精确。

在 VS Code 打开本单元 `示例工程`，新建 `lesson_04_difference.py`，保存完整内容：

~~~python
from app.math_basics import finite_difference_gradient

def loss_from_weight(weight):
    return (weight * 2.0 + 1.0) ** 2

def loss_from_bias(bias):
    return (3.0 * 2.0 + bias) ** 2

weight_gradient = finite_difference_gradient(loss_from_weight, 3.0)
bias_gradient = finite_difference_gradient(loss_from_bias, 1.0)
print(loss_from_weight(3.0))
print(weight_gradient, bias_gradient)
~~~

第一个函数只改变权重，固定输入 2 和偏置 1；第二个只改变偏置，固定输入 2 和权重 3。传入 `loss_from_weight` 时没有括号，传的是“可调用的函数”，使差分工具能分别代入左右两个点。若写 `loss_from_weight(3.0)`，传入的就是数字 49，之后会报数字不可调用。

工具默认取 `epsilon=1e-5`，也就是 `0.00001`；这种写法中的 `e-5` 表示乘以十的负五次方。它各运行一次 `f(value + epsilon)` 和 `f(value - epsilon)`，然后按上面的中心差分公式计算。想比较不同步长时，显式传第三个参数，例如 `finite_difference_gradient(loss_from_weight, 3.0, epsilon=0.001)`。

在该目录的 PowerShell 运行：

~~~powershell
..\..\..\.venv\Scripts\python.exe lesson_04_difference.py
~~~

第一行是 `49.0`，第二行接近 `28.0 14.0`，最后若干小数可不同；与手算值的绝对误差各小于 `0.000001` 即通过本例核对。这里“通过”只指这组输入，完整实现仍应检查其他点和边界。

## PyTorch 自动求导验证

如果共享环境已安装 PyTorch，把下面的最小例子保存为同一工程的 `lesson_04_autograd.py`。张量 Tensor 是 PyTorch 保存数值的对象；这里每个张量只装一个浮点数，不涉及 GPU 或批处理：

~~~python
import torch

x = torch.tensor(2.0)
w = torch.tensor(3.0, requires_grad=True)
b = torch.tensor(1.0, requires_grad=True)
loss = (w * x + b) ** 2
loss.backward()
print(loss.item(), w.grad.item(), b.grad.item())
~~~

`requires_grad=True` 表示需要追踪该变量的梯度。前向计算得到 `loss`；`loss.backward()` 从这个标量目标反向计算梯度，存入 `w.grad` 和 `b.grad`。`.item()` 取出只含一个元素的张量里的 Python 数字，方便打印。用 `2.0` 而不是整数 `2` 建立浮点输入，要求梯度的张量不能是普通整数类型。

运行 `..\..\..\.venv\Scripts\python.exe lesson_04_autograd.py`，预期输出 `49.0 28.0 14.0`。重复执行整个脚本会重新创建变量；不要在同一张已释放的计算图上直接再调用一次 backward。多次新前向后做 backward 时，梯度默认累加，训练如何清理梯度见 [[01_学习指南/06_PyTorch训练闭环/逐讲学习/05 训练验证与指标记录|训练循环]]。接口细节可查 [PyTorch backward 文档](https://docs.pytorch.org/docs/2.14/generated/torch.Tensor.backward.html)。

工程现有 [app/optional_autograd.py](../示例工程/app/optional_autograd.py) 也实现同一核对。若提示没有 PyTorch，先核对共享解释器并按根 README 申请安装，等待时继续有限差分练习；不要把提示文字或脚本正常退出当作自动求导已验证。

3. 如果环境有 PyTorch，再运行 `..\..\..\.venv\Scripts\python.exe app/optional_autograd.py`；没有则记录“自动求导尚未执行”，按共享环境规则申请所需依赖。
4. 把损失改成 L = 0.5 × a，重新计算梯度，观察系数如何传播。

## 常见错误

- 忘记链式法则中间的某个局部导数。
- 只算 dL/dz，却把它误写成 dL/dw；必须继续乘 dz/dw。
- 把梯度方向和更新方向混淆，梯度下降是参数减去学习率乘梯度。
- 在自动求导中重复使用计算图，却不理解框架是否需要保留图。
- `No module named 'app'`：把练习文件保存在本单元示例工程根目录，并在此打开终端；不要从另一个单元导入同名 app。
- 数字不可调用：检查是否把函数调用结果传给差分工具，应该传函数名本身。

## 练习与答案解析

### 跟做练习：加入 ReLU

ReLU 是“负数变成 0，正数保留”的函数，写成 `max(0, z)`；在网络里常用于引入非线性。定义 z = wx + b，a = max(0, z)，L = a。固定 x=2、b=1，分别取 w=1 和 w=-1，先求 z，再说明 dL/dz、dL/dw 有什么差异。

> [!example]- 参考答案
> w=1 时 z=3，ReLU 的局部导数为 1，dL/dw=1×2=2。w=-1 时 z=-1，局部导数为 0，dL/dw=0。z=0 处函数连续，但左右导数分别为 0 和 1，因此数学上不可导；框架需要选定边界上的反向传播约定，不能把“连续”当作“可导”。能先判断分支再相乘即完成。

### 独立练习

手算 L = (w1 x1 + w2 x2 + b - y)² 对 w1、w2、b 的梯度，并用有限差分验证。测试 x1 或 x2 为 0 的情况。

提示：x1、x2 是两个固定输入，y 是固定目标值；先把括号内记为误差 e，再对三个参数分别求导。先取 x1=2、x2=-1、w1=3、w2=4、b=1、y=0。完成标准：三个梯度均核对，并解释输入为 0 时为什么对应权重的梯度为 0。

> [!example]- 独立练习参考答案与核对程序
> e=w1x1+w2x2+b-y，因此三个梯度是 `2e×x1`、`2e×x2`、`2e`。给定数值时 e=3，L=9，梯度为 12、-6、6。把以下程序另存为 `lesson_04_two_inputs.py`，使用共享解释器运行。
> ~~~python
> from app.math_basics import finite_difference_gradient
>
> def check_case(x1, x2):
>     def loss(w1, w2, bias):
>         return (w1 * x1 + w2 * x2 + bias) ** 2
>
>     def vary_w1(value):
>         return loss(value, 4.0, 1.0)
>
>     def vary_w2(value):
>         return loss(3.0, value, 1.0)
>
>     def vary_bias(value):
>         return loss(3.0, 4.0, value)
>
>     error = 3.0 * x1 + 4.0 * x2 + 1.0
>     expected = [2 * error * x1, 2 * error * x2, 2 * error]
>     actual = [
>         finite_difference_gradient(vary_w1, 3.0),
>         finite_difference_gradient(vary_w2, 4.0),
>         finite_difference_gradient(vary_bias, 1.0),
>     ]
>     print(expected)
>     print(actual)
>
> check_case(2.0, -1.0)
> check_case(0.0, -1.0)
> check_case(2.0, 0.0)
> ~~~
> 内层函数在当前 `check_case` 调用内使用其 x1、x2，每次只放开一个参数；这使“其他输入固定”在代码中可见。三组手算依次为 `[12, -6, 6]`、`[0, 6, -6]`、`[28, 0, 14]`，对应数值结果误差应各小于 `0.000001`。输入变成 0 时，要重新算 e，不能只改原梯度列表里的一个位置。

### 迁移练习

解释深层网络为什么可能出现梯度消失或爆炸。先用多个小于 1 或大于 1 的局部导数相乘说明直觉，再列出一种工程缓解方法。

提示：先比较一条路径上十个 0.5 相乘、十个 2 相乘的值。完成标准：既给出数值，也说明这只是简化路径的直觉，不能代替实际模型梯度检查。

> [!example]- 迁移练习参考答案
> `0.5 ** 10 = 0.0009765625`，`2 ** 10 = 1024`。在这种简单路径里，局部倍率连乘可能让梯度很小或很大。实际网络包含矩阵运算和多条路径相加，不能只凭层数断言一定消失或爆炸。梯度裁剪会在梯度过大时限制其范数，是缓解爆炸的一种措施；它不自动修复梯度消失，具体实现留到 [[01_学习指南/06_PyTorch训练闭环/逐讲学习/07 训练故障排查|训练故障排查]]。

## 本讲小结

反向传播就是计算图上的链式法则。先保证前向值正确，再逐段写局部导数；有限差分和自动求导都适合做小规模核对，但各有成本和边界。
