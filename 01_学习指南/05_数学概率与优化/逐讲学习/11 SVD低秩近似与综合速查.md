## 从二维方向理解秩

在 [[01_学习指南/05_数学概率与优化/逐讲学习/10 用二维变换理解特征值与特征向量|特征值详细课]]中，我们已比较负对角矩阵和剪切矩阵：特征值描述 `Av=λv` 的倍数关系，奇异值描述非负长度缩放。下面讲解 SVD 的两侧方向和矩形形状；不能把二者当作同一组数。

两个向量若能用倍数相互表示，就没有提供第二个独立方向。例如 `[2,4]` 是 `[1,2]` 的两倍。矩阵的秩（rank）描述其列向量中最多有多少个彼此独立的方向；它不是行数，也不是非零元素个数。

矩阵 `[[1,2],[2,4]]` 有两列，但第二列是第一列的两倍，所以秩为 1。矩阵 `[[3,0],[0,1]]` 的两列分别沿横轴和纵轴，互相不是倍数，所以秩为 2。零矩阵没有独立方向，秩为 0。

对于实数二维矩阵，SVD（奇异值分解）把变换拆成方向变换、沿各轴缩放、再变换方向。可以想象旋转与拉伸；实际方向变换也可能包含镜像，不能只理解为平面旋转。奇异值是非负的缩放量，最大的奇异值对应放大最多的方向。它反映矩阵变换的尺度，不能单凭这个数判断某个方向对业务最有价值。

## SVD 和低秩近似

对矩阵 W，SVD 写作：

~~~text
W = U Σ Vᵀ
~~~

`U` 和 `V` 提供两侧的方向，`Vᵀ` 是 V 的转置，`Σ`（大写 sigma）是把奇异值放在对角线上的矩阵。奇异值按从大到小排列。对形状为 `m×n` 的实数矩阵，令 `k=min(m,n)`，精简分解形状为 `U:m×k`、`Σ:k×k`、`Vᵀ:k×n`，相乘仍是 `m×n`。

保留前 r 项，就是把后面的奇异值及对应方向舍弃，得到秩最多为 r 的近似。r 减小时，重构误差不会下降，但可能保持不变：如果舍弃的值都是零，仍能精确重构。参数和运算是否减少还取决于是否保留因子形式，以及 r 是否足够小；如果重新乘回完整矩阵，其存储形状仍与原矩阵相同。

先手算对角矩阵 `[[3,0],[0,1]]`。横轴缩放 3、纵轴缩放 1，奇异值是 3 和 1。保留第一项得到 `[[3,0],[0,0]]`：对 `[0,1]` 的输出从 `[0,1]` 变成 `[0,0]`。这就是本例丢掉的变化。

重构误差在本节使用 Frobenius 范数：把差矩阵每个元素平方、求和、再开平方。本例差矩阵只有右下角是 1，误差为 1；保留两项时误差为 0。范数的单位与矩阵元素一致。

LoRA（低秩适配）冻结原权重 W，即不更新它，只训练两个较小矩阵构成的更新。本节先省略缩放系数，实际实现常写成 `W' = W + (α/r)BA`：

~~~text
W' = W + B A
~~~

`d` 是输入特征数，`d_out` 是输出特征数。若 A 为 `r×d`，B 为 `d_out×r`，则 BA 为 `d_out×d`，能与 W 相加。更新的秩最多为 r；LoRA 直接从任务损失训练 A、B，并不要求先对 W 做 SVD。SVD 是理解低秩结构的工具，原权重低秩也不能直接证明任务所需的更新低秩。

只计这些矩阵时，可训练参数从 `d_out×d` 变成 `r×d+d_out×r`。以 4×4、r=1 为例，16 个变成 8 个；r=3 则为 24 个，比 16 还多。节省需要 r 足够小。原 W 仍要存储，激活也仍占内存，不能把可训练参数减少比例直接称为总显存减少比例。

## 用 NumPy 看奇异值

### 实验一：比较两个保留数的误差

保存为 `lesson_06_svd.py`：

~~~python
import numpy as np
from app.math_basics import truncated_svd

matrix = np.array([[3.0, 0.0], [0.0, 1.0]])
u, singular_values, vt = np.linalg.svd(matrix, full_matrices=False)
print("奇异值：", singular_values.tolist())
print("因子形状：", list(u.shape), list(vt.shape))
for rank in [1, 2]:
    approximation = truncated_svd(matrix, rank=rank)
    error = np.linalg.norm(matrix - approximation, ord="fro")
    print(rank, approximation.tolist(), round(float(error), 6))
~~~

运行 `..\..\..\.venv\Scripts\python.exe lesson_06_svd.py`，预期：

```text
奇异值： [3.0, 1.0]
因子形状： [2, 2] [2, 2]
1 [[3.0, 0.0], [0.0, 0.0]] 1.0
2 [[3.0, 0.0], [0.0, 1.0]] 0.0
```

`np.array` 把嵌套列表变为二维数组；`linalg.svd` 返回 U、奇异值数组和 V 的转置。`full_matrices=False` 请求上述精简形状，本例方阵两种形状相同。变量解包按返回顺序接收；`tolist()` 转成列表便于阅读。`truncated_svd` 是配套 [math_basics.py](../示例工程/app/math_basics.py) 的函数，返回已经重构的完整形状矩阵；`ord="fro"` 明确使用 Frobenius 范数。`float` 转成 Python 数后取六位小数。

数学上，截断 SVD 在给定秩上限下使这种误差最小；不保证让任意分类或生成任务的损失最小。不同实现可能给 U、V 某些列同时取反，或在相等奇异值处选择不同基；比较重构结果和误差，不要要求因子逐元素一致。

### 实验二：检查低秩是否一定有损失

保存为 `lesson_06_exact.py`：

```python
import numpy as np
from app.math_basics import truncated_svd

matrix = np.array([[3.0, 0.0], [0.0, 0.0]])
approximation = truncated_svd(matrix, rank=1)
error = np.linalg.norm(matrix - approximation, ord="fro")
print(approximation.tolist())
print(round(float(error), 6))
```

按同样命令运行该文件，应输出 `[[3.0, 0.0], [0.0, 0.0]]` 和 `0.0`。第二个方向本来就没有贡献，舍弃它没有引入截断误差。一般浮点矩阵可能残留约 1e-15 的误差，可用绝对误差小于 1e-10 核对本节小矩阵。数学秩与浮点软件按容差判断的数值秩也要区分。

## 训练常用公式与形状速查

| 内容 | 公式或规则 | 形状/注意事项 |
|---|---|---|
| 线性层 | y = XWᵀ + b | X: batch×in，W: out×in，y: batch×out |
| 点积 | x·w = Σ xᵢwᵢ | 两个向量长度相同 |
| L2 范数 | ‖x‖₂ = √Σxᵢ² | 不要把平方范数和范数混写 |
| softmax | exp(zᵢ) / Σexp(zⱼ) | 输出非负且和为 1，注意稳定性 |
| 交叉熵 | -Σpᵢ log qᵢ | q 为预测分布，方向不能反 |
| KL | Σpᵢ log(pᵢ/qᵢ) | 不对称，不是普通距离 |
| 梯度更新 | θ ← θ - η∇L | η 是学习率，形状与 θ 一致 |
| 链式法则 | df/dx = df/dy · dy/dx | 逐段相乘，分支梯度相加 |
| SVD | W = UΣVᵀ | 奇异值表示各方向的缩放尺度 |

## 一条统一排错顺序

当训练或数学实验结果异常时，按以下顺序检查：

1. 输入和标签是否符合预期，是否有空值、越界值或错位。
2. 每一步的 shape、概率和是否为 1、损失是否为有限数。
3. 用极小输入手算前向结果。
4. 用有限差分或自动求导核对梯度。
5. 检查学习率、初始化、批量平均方式和更新方向。
6. 最后再考虑换模型、优化器或增加复杂度。

## 动手操作

1. 先手算两个对角矩阵的 rank=1 结果，再运行两个实验核对。
2. 将实验一改成 `[[5.0,0.0],[0.0,2.0]]`，预测误差后运行。用独立练习的答案检查。
3. 根据速查表写出一个 batch=4、in=3、out=2 的线性层各张量形状。
4. 把一次手算反向传播写成三行“前向值—局部导数—参数梯度”。

## 常见错误

- 把低秩截断一概说成有损或无损：检查舍弃的奇异值是否为零，并说明浮点容差。
- LoRA 中 A、B 的形状不匹配，或者 BA 与原权重形状不同。
- 只看参数数量减少，却不检查低秩假设是否适合任务。
- 公式记住了，但没有标出 batch、序列、输入和输出维度。
- `ModuleNotFoundError: app`：确认脚本和终端都在本单元示例工程，不要从另一个单元导入同名 app。
- rank=0 或大于 `min(m,n)` 报 ValueError：本工程函数只接受 1 到该上限；零矩阵的数学秩仍可以是 0，接口范围与数学定义不同。

## 练习与答案解析

### 跟做练习：估算 LoRA 参数量

原矩阵形状为 4096×4096，低秩 r=8。分别计算原参数量和 A、B 两个矩阵的参数量。

> [!example]- 参考答案
> 原矩阵有 16,777,216 个参数。A 为 8×4096，B 为 4096×8，合计 65,536 个，为原矩阵的 1/256，约 0.390625%。这只比较矩阵的可训练参数；原 W 仍存储，其他层、偏置与优化器状态另计。完成判断：能解释为什么不是把整个模型缩小到 1/256。

### 独立练习

完成一页自己的“训练数学速查笔记”，至少包含线性层、softmax、交叉熵、KL、链式法则、梯度下降和张量形状。每条公式旁边写一个输入输出例子。

先完成两道有确定结果的核对题：对角矩阵 `diag(5,2)` 保留 1、2 项，结果与误差各是多少？线性层 `batch=4,in=3,out=2` 的输入、权重、偏置、输出形状是什么？提示：沿用实验一与第 1 讲矩阵乘法。笔记可参考上表，但需补自己的输入输出。

> [!example]- 独立练习参考答案与解析
> `diag(5,2)` 保留一项为 `diag(5,0)`，误差是 2；保留两项等于原矩阵，误差为 0。输入 X 为 `[4,3]`，W 为 `[2,3]`，偏置为 `[2]`，`XWᵀ+b` 输出 `[4,2]`。完成判断：先写预测，再运行修改后的实验一核对，能解释为什么丢掉的 2 而不是 5 决定本例误差。
>
> 笔记中的其余最小例子可用：softmax 输入 `[0,0]` 输出 `[0.5,0.5]`；目标分布 `[1,0]`、预测 `[0.5,0.5]` 的交叉熵为自然对数 `ln 2`；相同分布的 KL 为 0；`f=(2x)²,x=1` 的链式梯度为 8；参数 1、梯度 2、学习率 0.1 更新后为 0.8。逐条写出中间步骤，不能只抄结果。

### 迁移练习

选择一个后续训练问题，写一页设计说明：哪些参数冻结、哪些参数训练、为什么可以低秩、怎样用保留集判断 rank 太小或太大。不要把参数更少直接等同于效果更好。

具体使用一个 `4×4` 线性权重，候选 r=1 和 r=3；只能选一个作为先做的小实验。写出参数量、假设、验证与停止条件。提示：这里没有任务结果，方案只能提出待检验假设。

> [!example]- 迁移练习参考答案与解析
> 冻结原 16 个权重，训练 A、B，先省略偏置与缩放参数。r=1 时训练 8 个参数，r=3 时训练 24 个；若目标先控制训练参数，优先试 r=1。它假设所需更新能由一个方向近似，尚未得到数据支持。
>
> 固定训练集与验证集、记录相同训练预算下的训练／验证损失，并和冻结 Base、全量训练作对照。若小 rank 训练和验证都差，可检查优化与容量；若训练改善而验证变差，可能过拟合或划分有问题，不能仅归因于 rank。候选都不能满足事先规定的验证目标时，停止采用该方案。反复据验证结果选 rank 后，还需另留最终测试数据。完成判断：方案明确冻结与训练对象、8/24 的数值、比较条件和失败处理，而非预先声称收益。
