## 为什么需要分布

一次调用成功或失败是一个结果；分布告诉我们所有可能结果分别有多大概率。用随机变量 X 记录结果，例如成功记 1、失败记 0。随机变量是把不确定的结果转成数值的规则，并不是“每次都由代码随机生成”的变量。

假设一次成功概率 p=0.5，X=1 与 X=0 的概率各 0.5，这就是伯努利分布。p 是模型参数，通常需要观测或先验支持；本课先使用假设值来验证机制。

## 三次试验：从伯努利到二项分布

设每次成功概率都是 0.5，三次相互独立。独立表示已知其他次结果也不会改变这一次的成功概率；在这个假设下，一条具体序列的概率可以相乘，都是 0.5³=0.125。

| 成功次数 k | 具体序列 | 序列数 | 总概率 |
| --- | --- | --- | --- |
| 0 | 000 | 1 | 0.125 |
| 1 | 100、010、001 | 3 | 0.375 |
| 2 | 110、101、011 | 3 | 0.375 |
| 3 | 111 | 1 | 0.125 |

概率相加为 1，因为四个成功次数覆盖了全部结果，而且互不重叠。注意 110 是一条序列，成功两次是三条序列的合并事件；不能只写 0.125。

固定 n 次、独立、每次成功概率同为 p 时，成功次数 K 服从二项分布：

```text
P(K=k) = C(n,k) × p^k × (1-p)^(n-k)
```

C(n,k) 是从 n 个位置挑 k 个位置的方式数；`C(3,2)=3`。p^k 表示成功位置的概率连乘，另一个幂表示失败位置。p 不为 0.5 时，各序列不再全部等概率，但成功次数相同的序列在这些假设下仍具有相同的乘积。

### 动手运行

在 VS Code 打开 `01_学习指南/05_数学概率与优化/示例工程`，新建 `lesson_distribution_binomial.py`，保存完整内容：

```python
from app.distributions import binomial_probability

total = 0.0
for successes in range(4):
    probability = binomial_probability(3, successes, 0.5)
    print(successes, probability)
    total += probability
print(total)
```

在该工程 PowerShell 运行：

```powershell
..\..\..\.venv\Scripts\python.exe lesson_distribution_binomial.py
```

`range(4)` 产生 0、1、2、3；每行打印成功次数与概率，最后为 `1.0`。预期前四行是 `0 0.125`、`1 0.375`、`2 0.375`、`3 0.125`。完整函数在 [distributions.py](../示例工程/app/distributions.py)，其中 `math.comb` 计算方式数；[官方接口](https://docs.python.org/3.13/library/math.html#math.comb)要求整数。

零次试验时只有空序列，成功零次概率为 1；p=0 或 1 时结果确定。成功次数超出 0～n、本例次数不是整数、概率越界或不有限，都报 ValueError。此函数用于小规模手算核对，大 n 时应考虑专门的数值统计库，避免巨大组合数及连乘的数值问题。

## 均值：中心在哪里

比较两个列表 A=`[8,8,12,12]`、B=`[6,6,14,14]`。均值是总和除以数量，两者均值都是 10，但 B 明显离中心更远。均值只说明一个中心，不能充分说明分散程度。

这里把列表内所有观测本身当作完整总体；n 表示列表长度。均值 μ（读作 mu）为 `sum(values)/n`。一个数据点偏离均值的量是 `value-μ`。直接把带正负的偏差求平均，两边会相互抵消，所以用偏差平方再平均，这叫总体方差。

| 量 | A | B |
| --- | --- | --- |
| 均值 | 10 | 10 |
| 每个偏差 | -2、-2、2、2 | -4、-4、4、4 |
| 偏差平方 | 4、4、4、4 | 16、16、16、16 |
| 方差（平方平均） | 4 | 16 |
| 标准差（方差平方根） | 2 | 4 |

**平方根**是平方后得到原数的非负数，例如 2²=4，所以 √4=2。标准差是方差的非负平方根，符号 σ（读作 sigma）。如果观测单位是毫秒，方差单位是毫秒的平方，标准差单位又回到毫秒，便于解释。

把标准差理解为分散程度的量尺，不是“所有值与均值的平均绝对距离”，也不是最大误差。两组数据标准差不同，表示平方偏差的平均尺度不同；不能由此判断哪组业务表现更好。

### 手算后核对标准库

新建同一工程内的 `lesson_distribution_spread.py`：

```python
from app.distributions import summarize_population

print(summarize_population([8, 8, 12, 12]))
print(summarize_population([6, 6, 14, 14]))
```

运行共享解释器加文件名，输出字典分别为 `{'mean': 10, 'variance': 4, 'standard_deviation': 2.0}` 与 `{'mean': 10, 'variance': 16, 'standard_deviation': 4.0}`。数字显示为整数或浮点均可，不影响含义。

源函数使用 statistics.mean、pvariance、pstdev；其中 p 表示总体计算，方差除以 n。若把少量观测当样本，估计更大总体的方差，常用除以 n-1 的样本方差 `statistics.variance`，至少需要两项；不能默默更换分母后仍与本课手算比较。[统计函数官方说明](https://docs.python.org/3.13/library/statistics.html#statistics.pvariance)。

## 连续量：正态分布回答区间概率

二项结果只能是 0、1、2 等离散次数；假设不四舍五入的测量误差，可以用连续量模型描述。正态分布是一个对称、钟形的连续模型，由中心 μ 和标准差 σ>0 指定。

先**假设**一个测量值服从均值 10、标准差 2 的正态分布。它不是因为上面 A 的均值和标准差相同就被证明成立；A 实际只取两个不同值，不能据此认定钟形。

连续模型的曲线高度叫概率密度；区间下的面积才是概率。某点高度可以大于 1，这不意味着某事件概率大于 1。连续正态模型精确取值 10 的概率是 0，区间 `[8,12]` 的概率却为正；仪器显示“10”通常包含舍入后的一个区间，不能把显示值的概率也当作 0。

CDF 是 Cumulative Distribution Function，中文叫累积分布函数；`cdf(x)` 返回 `P(X≤x)`。不必先会积分，用 `cdf(上界)-cdf(下界)` 就能求一个连续区间的概率。

新建 `lesson_distribution_normal.py`：

```python
from statistics import NormalDist

model = NormalDist(mu=10, sigma=2)
print(model.cdf(10))
print(model.cdf(12) - model.cdf(8))
wider_model = NormalDist(mu=10, sigma=4)
print(wider_model.cdf(12) - wider_model.cdf(8))
```

运行后接近 `0.5`、`0.6826894921370859`、`0.38292492254802624`。对称模型在中心左边包含一半概率；相同 `[8,12]` 区间下，标准差更大时概率更少，因为分布更分散。约 68.3% 在均值加减一个标准差内，是正态模型的结论，不是所有数据的保证。

NormalDist 是标准库中的正态分布对象，其构造参数和 CDF 定义见 [官方接口](https://docs.python.org/3.13/library/statistics.html#statistics.NormalDist)。本例没有采样，也没有拟合真实测量数据。

## 常见错误与排查

- 把“恰好成功两次”写成一条序列概率：先列出成功位置的三种组合，再相加。
- 重试都发生在同一次服务中断，却按独立试验相乘：先说明独立和固定成功率是否合理，相关记录不能直接套二项模型。
- 把方差当标准差：查看结果键，方差还需开平方；核对单位。
- 空观测调用 summarize_population：没有均值可计算，函数应报“至少需要一个有限观测值”；不要填成 0。
- 所有数据都用正态分布：检查是否有长尾、多个峰或明显边界，且仅凭均值标准差不能判断分布形状。
- 找不到 app：确认脚本存于本单元示例工程根目录；不要从单元 04 导入另一份同名包。

## 跟做练习：改变一次成功概率

把三次试验的 p 改为 0.2，先手算 k=0、1、2、3，再运行。完成标准：四项之和接近 1，解释“成功两次”的组合数为什么仍为 3。

> [!example]- 参考答案与过程
> k=0 为 0.8³=0.512；k=1 为 3×0.2×0.8²=0.384；k=2 为 3×0.2²×0.8=0.096；k=3 为 0.2³=0.008，总和 1。位置数由 n 和 k 决定，不由 p 决定；浮点最后几位不同属正常现象。只需修改上面完整循环中的 0.5，不要改变 range(4)。

## 独立练习：不用统计函数手算分散程度

为 `[1,3,5,7]` 计算均值、总体方差、标准差。提示：先计算均值，再逐个累加偏差平方，最后除以长度并开平方。完成标准：结果为 4、5、√5，能说明为什么不是除以 3。空输入和含无穷／NaN 的输入应明确拒绝；NaN 表示不是有效数值的特殊浮点值。

> [!example]- 完整参考答案
> 在示例工程另存为 `lesson_distribution_manual.py`：
> ```python
> import math
>
> def describe_values(values):
>     if len(values) == 0:
>         raise ValueError("观测不能为空")
>     for value in values:
>         if not math.isfinite(value):
>             raise ValueError("观测必须为有限数")
>     mean = sum(values) / len(values)
>     squared_total = 0.0
>     for value in values:
>         squared_total += (value - mean) ** 2
>     variance = squared_total / len(values)
>     return mean, variance, math.sqrt(variance)
>
> print(describe_values([1, 3, 5, 7]))
> print(describe_values([7]))
> ```
> 输出接近 `(4.0, 5.0, 2.23606797749979)`、`(7.0, 0.0, 0.0)`。第一组偏差 -3、-1、1、3，平方和 20，除以 4 得 5。这里描述列表自身，采用总体方差；不是估计未知总体时的无偏样本方差。

## 迁移练习：选择日志的模型

某天统计每个时间窗内 3 次工具调用的失败次数，另统计单次延迟。能否分别直接套二项和正态？先列出需要检查的条件，再给一个使模型失效的反例。完成标准：能解释整数计数与连续测量的差别，也能说明历史计数、模型假设和实际结果是三件事。

> [!example]- 参考答案
> 三次失败计数可以尝试二项模型，但需要相同失败率和独立性。若三次都在同一服务故障期间，失败相关；若跨不同工具，失败率可能不同。这些都破坏简单二项假设，不能靠代入样本平均失败率解决。
> 延迟是非负量，可能有大量小值和少量极大值，呈长尾；正态模型还可能给负延迟分配概率，因此未必合适。应先查看记录的分布和分位数，再判断模型。也可以先报告实测直方计数和分位数，不强行套分布；这些方法留到 [[01_学习指南/07_传统机器学习与数据分析/逐讲学习/01 用 pandas 看懂一张数据表|数据分析]]。本题没有真实日志，不能把假设算出的数字称为服务实测质量。
