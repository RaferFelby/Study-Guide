## 从哪里开始，怎样判断完成

模型常输出任意实数分数，例如 `[0,1,2]`，但分类或注意力需要一组非负、总和为 1 的权重。softmax 是一种把分数变成这种权重的方法。它并不自动保证预测正确或概率已校准。校准是指预测概率与实际发生频率相符：例如模型对一组事件都预测 70%，这些事件应大约有 70% 发生；仅让概率总和为 1 还做不到这一点。

先完成矩阵课与 [[01_学习指南/05_数学概率与优化/逐讲学习/02 按轴计算并分清数组视图与副本|axis 详细课]]。需要会列表、函数和基本四则运算，指数、对数在本页讲。所有文件保存于 VS Code 中的 `01_学习指南/05_数学概率与优化/示例工程/`，终端也在此目录。共享环境已有 NumPy；本课只使用 CPU，不安装新库。

完成标准：手算 `[0,ln(3)]` 的 softmax；解释沿哪一维归一化；说明为什么减去同一行最大值；核对大分数仍输出有限值，并知道本课函数不接受 NaN、无穷或空输入。

阅读顺序：指数／对数 → 单行 softmax → 数值稳定 → 批量与轴 → 三层练习。证明与完整数值分析可稍后深入。

## 指数把加法变成乘法，对数做反向操作

`exp(z)` 表示 `e` 的 z 次方，e 约等于 2.71828。几个有用的事实是：`exp(0)=1`，`exp(1)=e`，`exp(a+b)=exp(a)×exp(b)`。实数输入的指数在数学上始终为正，输入越大，指数越大。

自然对数 `ln(x)` 回答“e 的多少次方等于 x”，例如 `ln(1)=0`、`ln(e)=1`，且 `exp(ln(3))=3`。NumPy 的 `np.log` 使用自然对数；信息论正文的 `log2` 使用以 2 为底的对数，数值和单位不同。

有限实数对数要求 x>0；`ln(0)` 不会得到有限数。浮点数只是有限精度表示，极大的指数会溢出为无穷，极小的正数可能下溢为 0；不能认为计算机可以表示所有数学实数。

在工程目录创建 `lesson_softmax_single.py`：

~~~python
import numpy as np


def main():
    scores = np.array([0.0, np.log(3.0)])
    positive_weights = np.exp(scores)
    probabilities = positive_weights / positive_weights.sum()
    print("指数：", positive_weights.round(6).tolist())
    print("概率：", probabilities.round(6).tolist())
    print("总和：", round(float(probabilities.sum()), 6))
    print("反向对数：", np.log(positive_weights).round(6).tolist())


if __name__ == "__main__":
    main()
~~~

~~~

预期指数 `[1.0,3.0]`、概率 `[0.25,0.75]`、总和 `1.0`、反向对数 `[0.0,1.098612]`。`round(6)` 仅方便显示，不应在训练计算中随意提前舍入。

先对每个分数取指数得到正权重，再除以这些权重的总和，就是单行 softmax：`p_i = exp(z_i) / Σ exp(z_j)`。下标 i 表示当前候选，Σ 表示把所有候选加起来。它不是 `分数/分数总和`；原分数可以为负、总和可以为 0，直接相除不能一般性得到概率。

## 为什么减去最大值后结果不变

对同一行的每个分数减去同一个有限常数 c：

~~~text
exp(z_i-c) / Σ exp(z_j-c)
= [exp(z_i) / exp(c)] / [Σ exp(z_j) / exp(c)]
= exp(z_i) / Σ exp(z_j)
~~~

分子和分母除以同一个量，因此数学比例不变。选择 `c=这一行的最大分数`，每个新分数都不大于 0，最大项等于 0；指数最大为 1，分母至少包含一个 1。这避免直接对大正数取指数造成的溢出。

例如 `[1000,1001,1002]` 减最大值后变为 `[-2,-1,0]`，其指数约为 `[0.135335,0.367879,1]`，再除以约 1.503215，得到约 `[0.090031,0.244728,0.665241]`。与 `[0,1,2]` 相同；分数的共同平移不影响理想 softmax。

### 运行大分数实验

创建 `lesson_softmax_batch.py`：

~~~python
import numpy as np

from app.numerics import softmax_rows


def main():
    scores = np.array([[1000.0, 1001.0, 1002.0], [0.0, 0.0, 0.0]])
    try:
        with np.errstate(over="raise"):
            np.exp(scores)
    except FloatingPointError:
        print("直接指数发生溢出")
    probabilities = softmax_rows(scores)
    print("稳定结果：", probabilities.round(6).tolist())
    print("每行总和：", probabilities.sum(axis=1).round(6).tolist())
    print("原始分数：", scores.tolist())


if __name__ == "__main__":
    main()
~~~

~~~powershell
..\..\..\.venv\Scripts\python.exe lesson_softmax_batch.py
~~~

预期第一行是 `直接指数发生溢出`；稳定结果两行为 `[0.090031,0.244728,0.665241]` 和 `[0.333333,0.333333,0.333333]`；每行总和为 `[1.0,1.0]`，原始分数保持不变。显示到六位后，三个 0.333333 相加看起来少一点，这是显示舍入，不是函数漏了概率。

`np.errstate(over="raise")` 仅在这个 `with` 范围内把浮点溢出当作异常，退出后恢复设置。这里故意制造失败来对照稳定实现；没有忽略失败后拿无穷继续计算。

### 顺着函数理解每一步

打开 [numerics.py](../示例工程/app/numerics.py) 的 `softmax_rows`：

1. 只接受非空二维有限实数分数，并转换成 float64 计算。每行是一条样本，每列是一个候选；返回同样形状。它是本课约定，不是所有 softmax 接口的唯一形式。
2. `max(axis=1, keepdims=True)` 得到每行一个最大值，形状为 `(B,1)`；B 是行数。
3. `(B,C)` 的分数减去 `(B,1)` 的最大值时，NumPy 在候选轴上广播，相当于每行所有候选都减该行最大值，不需要手动复制 C 次。
4. 对平移后的分数取指数，再以 `sum(axis=1, keepdims=True)` 得到每行一个分母；最后按行相除。
5. 极端有限数相减可能得到负无穷，其指数按浮点极限变成 0；源码只在这两步允许这种溢出／下溢。原始输入 NaN／Inf 仍先被拒绝，最大项始终贡献 1，因此不靠吞掉无效数维持运行。普通课堂值不需要触及这个极端边界。

## 归一化轴改变了问题

两条样本、每条三个候选的分数形状为 `(2,3)`，我们要的是每个样本的三个概率总和为 1，所以沿轴 1 计算。若对六个元素整体归一化，两条不同样本会互相竞争，总和虽然为 1，但每行不再是一份独立分布。

注意力中，一行通常表示一个查询对各个键的分数，应沿键所在轴归一化。到 [[01_学习指南/08_Transformer从零实现/逐讲学习/01 看懂缩放点积注意力|注意力课]] 时，要先写出每个轴的含义，再选择维度，不能永远照抄 `axis=1`。

本课函数明确拒绝无穷，所以**不能直接接收用负无穷屏蔽后的注意力分数**。注意力课的 mask 实现有专门规则，特别要处理整行全部被屏蔽；不要把本课的有限输入契约擅自去掉。

## softmax 与交叉熵之间还隔着什么

大分数共同平移可以避免上溢，但极小概率仍可能舍入为 0。再计算 `-log(概率)` 时仍可能得到无穷。因此真实分类训练通常把原始 logits（未归一化分数）交给框架提供的稳定交叉熵／log-softmax，不先经过本课 NumPy 函数。

这里是教学实现，未提供 PyTorch 自动求导，也没有 GPU 支持。不能把训练张量转成 NumPy 后再期待梯度自动回到模型。先理解概率变换，再返回 [[01_学习指南/05_数学概率与优化/逐讲学习/06 熵交叉熵与KL散度|信息论第 6 讲]]学习损失。

## 常见错误与排查

| 现象 | 检查 | 修复 |
|---|---|---|
| 输入一维分数时报形状错误 | 本课函数要求二维 | 用 `np.array([scores])` 明确只有一行 |
| 六个概率总和为 1，但每行不是 1 | 是否跨样本归一化 | 沿候选轴分别计算 |
| 共同平移后结果看起来不同 | 是否先舍入／使用很低精度 | 保留计算精度，使用容差比较；极端平移本身也可能丢失分数差 |
| 已减最大值，log 后仍为无穷 | 概率是否下溢为 0 | 训练使用稳定 logits 损失，不随意截断来掩盖数值问题 |
| mask 后被拒绝 | 本课有限输入契约 | 进入注意力专用 mask 讲解，不将两种接口混用 |

## 练习与答案解析

### 跟做：两个相等的负分数

手算 `[-5,-5]` 的结果；再调用 `softmax_rows(np.array([ [-5.0,-5.0] ]))` 核对。完成标准：解释“减最大值后是 `[0,0]`，指数都是 1”，而非只记结果。

> [!example]- 参考答案
> 分母为 2，两个概率均为 0.5。原分数为负不代表概率必须为负。共同平移保留了候选之间的相对差。

### 独立：检查三类非法输入

创建 `lesson_softmax_invalid.py`，分别传入一维数组、空二维数组、含 NaN 的二维数组，并解释拒绝原因。提示：使用函数的明确契约。完成标准：出现三次预期错误，而不是返回一个看似合理的空结果。

> [!example]- 完整答案
> 保存以下代码，运行 `..\..\..\.venv\Scripts\python.exe lesson_softmax_invalid.py`：
>
> ~~~python
> import numpy as np
>
> from app.numerics import softmax_rows
>
>
> def main():
>     invalid_inputs = [np.array([1.0, 2.0]), np.empty((0, 2)), np.array([[np.nan, 0.0]])]
>     for values in invalid_inputs:
>         try:
>             softmax_rows(values)
>         except ValueError as error:
>             print("预期拒绝：", error)
>
>
> if __name__ == "__main__":
>     main()
> ~~~
>
> 前两项分别缺行轴、没有样本；最后一项不是有限输入。对应英文错误前两次包含 `non-empty two-dimensional`，第三次包含 `finite`。这里只捕获预期类型，不捕获所有异常来伪装完成。

### 迁移：从注意力权重算一个输出

某个查询对两个位置的分数是 `[0,ln(3)]`，两个位置的 Value 向量分别为 `[2,0]`、`[0,4]`。求加权后的输出。提示：先做 softmax，再将每个 Value 乘自己的权重并相加。完成标准：输出 `[0.5,3.0]`，并说明输出不是概率向量。

> [!example]- 参考答案
> 权重是 `[0.25,0.75]`，输出为 `0.25×[2,0]+0.75×[0,4]=[0.5,3]`。权重和为 1，不要求 Value 或最终表示的各元素和为 1。完整注意力还需处理 Q/K 投影、点积缩放、mask 和批次形状，本例只隔离其中“归一化再加权求和”的步骤。
