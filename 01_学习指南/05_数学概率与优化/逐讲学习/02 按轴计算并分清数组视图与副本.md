## 索引定位一个值，切片取一段

索引从 0 开始。先用 Python 列表 `values=[10,20,30,40]` 理解位置：`values[1]` 是第二个值 20；`values[1:3]` 选索引 1、2，结果是 `[20,30]`。冒号表示切片，“起点包含、终点不包含”。`values[:2]` 从开头取到索引 2 之前，`values[2:]` 从索引 2 取到结尾；`values[-1]` 表示最后一项。一维 NumPy 数组沿用这些位置规则，但切片是否共享数据不同，下文单独观察。

对二维表 `table`，`table[行号,列号]` 取一个值；`table[:,1]` 中的 `:` 表示所有行，1 表示第二列；`table[:,1:2]` 保留第二列的轴，所以形状不同。切片越过边界通常会截到已有部分，但单个越界整数索引会报 `IndexError`。

在示例工程创建 `lesson_array_axes.py`：

~~~python
import numpy as np


def main():
    table = np.array([[1, 2, 3], [4, 5, 6]])
    print("单个值：", table[0, 1])
    print("取一列：", table[:, 1].tolist(), table[:, 1].shape)
    print("保留列轴：", table[:, 1:2].tolist(), table[:, 1:2].shape)
    print("沿轴0求和：", table.sum(axis=0).tolist())
    print("沿轴1求和：", table.sum(axis=1).tolist())
    print("全部求和：", table.sum().item())
    row_sums = table.sum(axis=1, keepdims=True)
    print("保留轴：", row_sums.tolist(), row_sums.shape)
    print("逐行平均：", table.mean(axis=1).tolist())


if __name__ == "__main__":
    main()
~~~

预期依次看到：`2`；`[2,5] (2,)`；`[[2],[5]] (2,1)`；`[5,7,9]`；`[6,15]`；`21`；`[[6],[15]] (2,1)`；`[2.0,5.0]`。列表显示中的空格不影响结果。

## axis 指的是哪一个坐标在变化

对于形状 `(2,3)`：第 0 轴是行坐标，第 1 轴是列坐标。**沿某轴求和，就是让那个坐标变化，把它对应的多个数合起来。**

- `axis=0`：列坐标固定，行坐标从 0 变到 1，得到 `1+4、2+5、3+6`，形状为 `(3,)`。
- `axis=1`：行坐标固定，列坐标从 0 变到 2，得到 `1+2+3、4+5+6`，形状为 `(2,)`。
- 不给 axis：全部元素相加，得到标量 21。

不要只背“0 是按列、1 是按行”，遇到三维就容易混淆。先给每个轴写上业务含义，再找哪个坐标要被合并。

`keepdims=True` 把被合并的轴保留为长度 1，因此 `(2,3)` 沿轴 1 聚合得到 `(2,1)`；这方便每一行用自己的总和进行后续运算。`mean` 求平均而不是总和。第 5 讲的 softmax 示例会实际使用“每行一个分母”。

`tolist()` 把数组结果转成 Python 列表显示；`item()` 把这里的 NumPy 标量转成一个 Python 数。两者用于输出展示，不是求和步骤。

## 赋值、视图和副本：为什么修改会传过去

Python 的 `alias = original` 让两个名字指向同一个对象，没有复制。NumPy **视图**是共享同一块数值存储的另一种访问方式；例如普通切片可以只记录从哪里开始、取多少。**副本**拥有独立复制的数据，修改数值不会传回原数组。

在同一目录创建 `lesson_array_copy.py`：

~~~python
import numpy as np


def main():
    original = np.array([10, 20, 30, 40])
    alias = original

    view = original[1:3]
    copied = original[1:3].copy()
    picked = original[[1, 2]]
    print("是否同一对象：", alias is original)
    print("是否共享数据：", np.shares_memory(original, view), np.shares_memory(original, picked))
    view[0] = 99
    copied[1] = -1
    picked[0] = -2
    print("原数组：", original.tolist())
    print("别名：", alias.tolist())
    print("切片视图：", view.tolist())
    print("显式副本：", copied.tolist())
    print("索引列表结果：", picked.tolist())
    original[[1, 2]] = [7, 8]
    print("直接索引赋值：", original.tolist())


if __name__ == "__main__":
    main()
~~~

~~~powershell
..\..\..\.venv\Scripts\python.exe lesson_array_copy.py
~~~

预期：同一对象为 `True`；共享数据为 `True False`；原数组和别名都为 `[10,99,30,40]`；视图为 `[99,30]`；显式副本为 `[20,-1]`；索引列表结果为 `[-2,30]`；最后原数组变为 `[10,7,8,40]`。

执行顺序很重要：三个派生数组先建立，然后才修改视图。因此 `copied` 与 `picked` 保留各自复制时的 20、30。`is` 判断是否同一个对象，`np.shares_memory` 检查是否共享数据；同一对象和共享部分数据不是同一个问题。

`original[ [1,2] ]` 使用整数列表选择位置，属于高级索引，**读出的数组是副本**。但 `original[ [1,2] ] = [7,8]` 是直接向原数组指定位置赋值，会改变原数组。不要误推成“高级索引永远改不到原数据”。布尔索引读取也会得到副本，本课先不组合多个高级索引。

以上规则针对本课普通数值 NumPy 数组。Python 列表切片建立新列表，但嵌套对象仍可能共享；object dtype 数组复制也不意味着递归复制所有对象。PyTorch 的视图、梯度记录规则要另看对应章节，不能把 NumPy 规则直接扩展到所有库。

## 常见错误

| 现象 | 原因 | 修复 |
|---|---|---|
| 取一列后少了一维 | 整数索引去掉该轴 | 要保留二维时用 `[:,1:2]` |
| 平均值数目不对 | 沿错误轴聚合 | 先标出样本轴、特征轴，再手算一个输出 |
| 清洗子数组却改了原数据 | 子数组是共享数据的视图 | 若需要独立修改，先 `.copy()` |
| 以为赋值创建了副本 | 两个变量只是别名 | 用 `.copy()` 并实际检查原数组 |
| 把 reshape 当成必然复制 | reshape 可能返回视图，也可能复制 | 需要独立存储时明确复制，不靠形状推断 |

## 练习与答案解析

### 跟做：换一个非方阵

把轴实验的表改成三行两列：`[[1,2],[3,4],[5,6]]`，先预测两个轴的和、均值和形状。提示：axis=0 消去行坐标。完成标准：输出个数与留下的轴长度一致。

> [!example]- 参考答案
> 沿轴 0 的和为 `[9,12]`，均值 `[3,4]`，形状 `(2,)`；沿轴 1 的和为 `[3,7,11]`，均值 `[1.5,3.5,5.5]`，形状 `(3,)`。保留轴时分别为 `(1,2)` 与 `(3,1)`。非方阵更容易暴露把两个轴记反的错误。

### 独立：标准化只使用训练统计量

训练表两行为 `[1,10]`、`[3,30]`，新样本一行为 `[5,50]`。按特征分别计算训练均值与总体标准差，用 `(值-均值)/标准差` 转换新样本。提示：同一列是同一特征，需沿 axis=0 计算。完成标准：新样本得到 `[3,3]`；不使用新样本更新统计量。

> [!example]- 完整答案
> 保存为 `lesson_array_standardize.py`，使用共享解释器运行：
>
> ~~~python
> import numpy as np
>
>
> def main():
>     train = np.array([[1.0, 10.0], [3.0, 30.0]])
>     incoming = np.array([[5.0, 50.0]])
>     feature_mean = train.mean(axis=0, keepdims=True)
>     feature_std = train.std(axis=0, keepdims=True, ddof=0)
>     safe_std = np.where(feature_std == 0, 1.0, feature_std)
>     converted = (incoming - feature_mean) / safe_std
>     print(feature_mean.tolist(), feature_std.tolist())
>     print(converted.tolist())
>
>
> if __name__ == "__main__":
>     main()
> ~~~
>
> 输出均值 `[ [2.0,20.0] ]`、标准差 `[ [1.0,10.0] ]`、结果 `[ [3.0,3.0] ]`。`ddof=0` 表示方差除以样本数量，标准差是其平方根；需要复习时进入 [[01_学习指南/05_数学概率与优化/逐讲学习/04 用具体数据理解概率分布|概率分布详细课]]。`np.where(条件,真时值,假时值)` 把零标准差临时替换为 1，避免除零：常量训练列中心化后是 0，新样本不同则保留差值。这是本练习明确的策略，真实任务可选择删除常量列。近乎零的标准差仍需检查，不能视为万能预处理。

### 迁移：安全修改一小段数据

你要把数组 `[10,20,30,40]` 的中间两项作为独立实验输入，把其中第一项改成 -1，同时保留原数据。写出三步并解释为何普通切片不够。完成标准：原数组不变、实验数组为 `[-1,30]`。

> [!example]- 参考答案
> 第一步创建原数组；第二步 `experiment = original[1:3].copy()`；第三步 `experiment[0] = -1`。先打印原数组，再打印 experiment，分别应为 `[10,20,30,40]` 与 `[-1,30]`。删掉 `.copy()` 做反例会把原数组的第二项也改掉；这解释了为何数据预处理需要明确所有权。副本有额外内存开销，只在需要独立修改时创建。
