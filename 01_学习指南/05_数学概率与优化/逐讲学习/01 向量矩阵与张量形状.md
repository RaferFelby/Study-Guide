## 用形状说明每一维是什么

标量是一个数，例如温度 25。向量是一组按顺序排列的数，例如一条样本的三个特征 `[2,1,4]`。矩阵是按行列排列的数表，例如两条样本、每条三个特征。张量是这些多维数值组织的统称；本讲先使用一维和二维。

NumPy 的 `array` 把 Python 列表转换为便于数值计算的数组，`shape` 返回每个轴的长度。轴可以先理解为“用第几个坐标取数据”；二维数组取一个元素需要行号和列号，所以有两个轴。

代码中的 `import numpy as np` 导入 NumPy，并使用惯用简称 `np`；所以 `np.array(...)` 就是在调用这个库的数组创建函数。`features.shape` 是读取数组的形状属性，不需要像调用函数那样加括号。

| 代码 | shape | 本讲含义 |
|---|---|---|
| `np.array([2,1,4])` | `(3,)` | 一维数组，没有单独的行轴和列轴 |
| `np.array([[2],[1],[4]])` | `(3,1)` | 三行一列，即列向量 |
| `np.array([ [2,1,4] ])` | `(1,3)` | 一行三列，即行向量 |

`(3,)` 里的逗号说明这是只含一个长度的元组，不表示还有一个省略的维度。二维数组的外层列表表示行，内层列表表示该行各列。每一行长度应相同。

“把向量看作一列数”只是纸面类比；代码中的一维数组并不自动等同形状为 `(3,1)` 的列向量。遇到运算问题，先看形状再看数值。

## 点积和范数分别量什么

两个同长度向量的**点积**是对应元素相乘后求和：`[1,2,3]` 与 `[4,5,6]` 的点积为 `1×4 + 2×5 + 3×6 = 32`。在线性模型中，一组权重与输入特征做点积，得到一个加权总分。点积会受方向和长度共同影响，不能不考虑长度就把它当成纯方向相似度。

**范数**用一个非负数表示向量的大小：

- L1 范数：各元素绝对值相加。`[3,-4]` 得到 `3+4=7`。
- L2 范数：各元素平方、相加、再开平方。`[3,-4]` 得到 `sqrt(9+16)=5`，即熟悉的平面长度。

`abs` 表示绝对值，`sqrt` 表示平方根。两种范数度量方式不同，所以不必相等；零向量的两种范数都是 0。

## 矩阵乘法与转置

### 用一行乘一列求一个输出

若 A 是 `m×n`、B 是 `n×p`，A 与 B 的矩阵乘积是 `m×p`。中间两个 n 必须相同；结果第 i 行第 j 列，来自 A 第 i 行与 B 第 j 列的点积。

本例权重两行分别为 `[1,2,3]` 与 `[0.5,1,-1]`，输入为 `[2,1,4]`：第一行结果 `2+2+12=16`，第二行 `1+1-4=-2`。NumPy 中 `@` 表示矩阵乘法；`*` 表示逐元素乘法，含义不同。

形状 `(2,3) @ (3,)` 得到 `(2,)`，这是 NumPy 对一维输入的规则；如果使用真正的列向量 `(3,1)`，结果就是 `(2,1)`。不能只按纸上的“列向量”想象代码形状。

### 转置交换二维矩阵的行和列

转置记为 `Aᵀ`，代码是 `A.T`。原来的第 i 行第 j 列移到第 j 行第 i 列；数值不变，坐标角色交换。例如：

~~~text
原矩阵，两行三列：       转置，三行两列：
1  2  3                1  4
4  5  6                2  5
                       3  6
~~~

所以 `(2,3)` 变成 `(3,2)`。对一维数组做 `.T`，形状仍为 `(3,)`；想得到列向量，需要明确 `reshape(3,1)`。`reshape` 指定新形状，元素总数必须不变。它不是矩阵转置：把 2×3 的数组重排为 3×2，读取顺序也不等于行列互换。

本节 `.T` 的行列交换解释限定二维；更高维数组的 `.T` 会反转全部轴，不能直接当成“只转最后两维”。后面的 Tensor 课再讲指定维度。

## 动手运行完整例子

在上述示例工程目录创建 `lesson_01_matrix.py`，粘贴并保存：

~~~python
import numpy as np

from app.math_basics import dot, matrix_multiply, vector_norm


def main():
    weights = np.array([[1.0, 2.0, 3.0], [0.5, 1.0, -1.0]])
    features = np.array([2.0, 1.0, 4.0])
    column = features.reshape(3, 1)
    print("点积：", dot([1, 2, 3], [4, 5, 6]))
    print("L1、L2：", vector_norm([3, -4], 1), vector_norm([3, -4], 2))
    print("一维输入：", (weights @ features).tolist(), (weights @ features).shape)
    print("列输入：", (weights @ column).tolist(), (weights @ column).shape)
    print("一维转置：", features.T.shape)
    table = np.array([[1, 2, 3], [4, 5, 6]])
    print("转置：", table.T.tolist(), table.T.shape)
    print("重排：", table.reshape(3, 2).tolist())
    try:
        matrix_multiply([[1, 2, 3]], [[1, 2], [3, 4]])
    except ValueError as error:
        print("预期形状错误：", error)


if __name__ == "__main__":
    main()
~~~

~~~powershell
..\..\..\.venv\Scripts\python.exe lesson_01_matrix.py
~~~

三个 `..` 从示例工程返回工作区根目录，再进入共享环境。`tolist()` 只把输出转成列表便于阅读，不改变运算结果。预期输出：

~~~text
点积： 32.0
L1、L2： 7.0 5.0
一维输入： [16.0, -2.0] (2,)
列输入： [[16.0], [-2.0]] (2, 1)
一维转置： (3,)
转置： [[1, 4], [2, 5], [3, 6]] (3, 2)
重排： [[1, 2], [3, 4], [5, 6]]
预期形状错误： inner matrix dimensions must match
~~~

逐步看：创建权重与输入 → 明确列向量形状 → 计算点积／范数 → 比较两种输入的输出 → 对照转置和重排 → 故意构造不匹配的矩阵。`try/except ValueError` 只接住本次预期的形状错误并打印原因；真实训练不能这样忽略坏批次继续更新。完整函数见 [math_basics.py](../示例工程/app/math_basics.py)。

## 常见错误与检查顺序

| 现象 | 先看什么 | 处理 |
|---|---|---|
| 找不到 Python 或文件 | 终端当前目录、脚本是否保存 | 回到本工程目录，使用共享解释器 |
| `No module named numpy` | 是否选到共享 `.venv` | 按根 README 核对已有包，安装需按工作区约定批准 |
| `@` 报维度错误 | 两边 `shape` | 先写出行／列含义和内维度，不盲目加 `.T` |
| `.T` 后仍是 `(3,)` | 输入是否一维 | 明确 reshape 成 `(3,1)` 或 `(1,3)` |
| 数字相同但后续相加错误 | `(B,)` 与 `(B,1)` 是否混用 | 对齐期望形状，避免广播变成意外的 `(B,B)` |

## 练习与答案解析

### 跟做：线性层与转置

输入 `[2,1]`，权重两行为 `[1,3]`、`[2,-1]`，偏置 `[0,4]`。求 `W @ x + b`，并写出 W 转置。提示：每个输出是一行权重的加权和，再加该输出的偏置。完成标准：输出 `[5,7]`，能解释每一项。

> [!example]- 参考答案
> 第一项 `1×2+3×1+0=5`，第二项 `2×2-1×1+4=7`。W 转置的两行是 `[1,2]` 与 `[3,-1]`。因为 W 恰好是方阵，转置前后形状都为 `(2,2)`，但元素位置仍发生变化；形状相同不代表数值排列相同。

### 独立：只用形状判断乘法是否兼容

写 `product_shape(left_shape, right_shape)`，这里只处理两个非空二维矩阵的形状，不支持批量广播。合法时返回输出形状；非法时明确报错。提示：先检查二元组与正整数维度，再比较内维度。完成标准：`(2,3)` 乘 `(3,4)` 返回 `(2,4)`，乘 `(2,4)` 失败；一维形状和零维度也被拒绝。

> [!example]- 完整答案
> 在同一工程目录创建 `lesson_01_shapes.py`，保存并用共享解释器运行：
>
> ~~~python
> def product_shape(left_shape, right_shape):
>     for shape in (left_shape, right_shape):
>         if not isinstance(shape, tuple) or len(shape) != 2:
>             raise ValueError("需要二维形状元组")
>         for size in shape:
>             if type(size) is not int or size <= 0:
>                 raise ValueError("本练习维度必须是正整数")
>     if left_shape[1] != right_shape[0]:
>         raise ValueError("两个内维度不同")
>     return (left_shape[0], right_shape[1])
>
>
> def main():
>     print(product_shape((2, 3), (3, 4)))
>     for left, right in [((2, 3), (2, 4)), ((3,), (3, 2)), ((0, 3), (3, 2))]:
>         try:
>             product_shape(left, right)
>         except ValueError as error:
>             print("预期拒绝：", error)
>
>
> if __name__ == "__main__":
>     main()
> ~~~
>
> 先输出 `(2,4)`，再出现三次明确拒绝。Python 索引从 0 开始，所以 `[1]` 取第二维。正维度限制是本练习的接口选择，NumPy 自身支持某些零维长度的矩阵运算；不能推广成“数学或 NumPy 禁止空矩阵”。
>
> `isinstance(shape, tuple)` 检查形状是否为元组，`len(shape)` 检查含几个维度；`or` 任一侧为真就进入拒绝分支，并在左侧已经为真时跳过右侧求值。`type(size) is int` 严格要求 Python 整数，也拒绝会被 `isinstance(True, int)` 接受的布尔值。这里没有支持 NumPy 整数类型，属于练习的简化输入范围。`for left, right in ...` 把每对测试形状拆成两个名字，再按相同流程检查。

### 迁移：一次计算两条样本

把两条输入排成两行：`[2,1,4]` 与 `[0,1,1]`，沿用本讲两行权重。输入 X 是 `(2,3)`，权重 W 是 `(2,3)`，应如何一次得到两个输出？提示：每条样本需要与每行权重做点积。完成标准：写出 `X @ W.T`，结果每行对应一条样本。

> [!example]- 完整答案与形状约定
> 保存为 `lesson_01_batch.py`，使用共享解释器运行：
>
> ~~~python
> import numpy as np
>
>
> def main():
>     features = np.array([[2.0, 1.0, 4.0], [0.0, 1.0, 1.0]])
>     weights = np.array([[1.0, 2.0, 3.0], [0.5, 1.0, -1.0]])
>     outputs = features @ weights.T
>     print(outputs.tolist(), outputs.shape)
>
>
> if __name__ == "__main__":
>     main()
> ~~~
>
> 输出 `[[16.0,-2.0],[5.0,0.0]]`，形状 `(2,2)`。X 为 `(样本数,输入数)`，本例 W 为 `(输出数,输入数)`，所以用 W.T。若作者把 W 定义成 `(输入数,输出数)`，公式才写 `X @ W`；两种记号都可用，必须先声明。矩阵乘法让数值库批量执行，但微型例子不保证比所有 Python 写法都快，速度要实际测量。

## 特征值和 SVD 接下来学什么

秩描述独立方向的数量，SVD 用来组织这些方向和缩放，详见 [[01_学习指南/05_数学概率与优化/逐讲学习/11 SVD低秩近似与综合速查|第 11 讲：SVD低秩近似与综合速查]]。对实方阵，非零向量 v 若满足 `Av=λv`，称为特征向量，λ 是对应特征值；λ 为负时方向反转，λ 为零时输出为零，不能一概说“方向不变”。本讲先定位用途；详细手算、数值求解、残差与反例见 [[01_学习指南/05_数学概率与优化/逐讲学习/10 用二维变换理解特征值与特征向量|特征值详细课]]，可按地图在第 9 讲后学习。
