## 词怎样变成分类目标

token 是模型处理的一段文本单位，可能是一个字、一个词、词的一部分或字节等，具体由分词方法决定。本节把每个示例词当作一个 token，是教学简化，不代表真实中文模型一定这样分词。

词表把 token 对应到整数编号。每个预测位置都可以看成一次分类：给词表里的每个候选一个概率，真实下一个 token 的编号指出要取哪一项。本课直接提供那一项概率；真实模型仍需要计算完整候选分数并归一化。

原始窗口 `[猫,在,睡,觉]` 只有四个词，按“根据前文预测下一个”对齐：

| 预测位置 | 当前位置输入 | 可用前文 | 目标 |
| --- | --- | --- | --- |
| 0 | 猫 | 猫 | 在 |
| 1 | 在 | 猫、在 | 睡 |
| 2 | 睡 | 猫、在、睡 | 觉 |

输入列表是 `tokens[:-1]`，去掉最后一个元素；目标列表是 `tokens[1:]`，从第二个元素取到结尾。长度从 4 变成 3。若原始数据没有提供“觉”之后的内容，不能凭空多加一个监督目标。

训练中使用真实前文帮助学习下一词，称为 teacher forcing（教师强制）。模型不能偷看当前位置之后的真实目标；后续注意力模型通过因果遮挡实现这一点。本脚本只检查数据和损失，没有实现注意力。

## 结束标记与补齐位置不一样

为了展示开始、结束和补齐，本例另用一条更短的句子“猫 睡”，添加三个特殊标记：

- `<BOS>`：beginning of sequence，序列开始；作为提示预测第一个内容词。
- `<EOS>`：end of sequence，序列结束；让模型学习何时停止，通常是有效预测目标。
- `<PAD>`：padding，补齐占位；为了组成一样长的批次，本例不把它当有效目标。

这些名字和编号是本课选择，实际分词器未必都有独立 BOS、EOS、PAD，甚至可能共用编号。届时应按数据长度和标签语义确定有效位置，不能机械复制本例按 PAD 编号排除的逻辑。

本例词表为 `<BOS>=0`、`猫=1`、`睡=2`、`<EOS>=3`、`<PAD>=4`。带补齐的原始序列长度为 5：

```text
原始：[<BOS>, 猫, 睡, <EOS>, <PAD>]
输入：[<BOS>, 猫, 睡, <EOS>]
目标：[猫,    睡, <EOS>, <PAD>]
有效：[True, True, True, False]
```

mask（掩码）是标记哪些位置参与某项计算的一组值。本页的 mask 只决定哪些**目标位置计入损失**。注意力 mask 则限制模型能读取哪些位置，两者职责不同。排除 padding 损失不会自动防止模型读取未来词。

## 先手算平均值

假设前三个正确目标的概率为 0.5、0.25、0.5，相应损失为 1、2、1 bit。第 4 个目标是 PAD，所以不读取它的概率、不算对数，也不计入分母：

```text
有效损失总和 = 1 + 2 + 1 = 4 bit
有效位置数 = 3
平均损失 = 4 / 3 ≈ 1.333333 bit/有效位置
```

如果分母错误地使用补齐后的长度 4，会得到 1，造成虚假的下降。继续添加 PAD 不应该改变同一有效内容的损失。

## 动手：创建脚本逐位置核对

在 VS Code 打开 `01_学习指南/05_数学概率与优化/示例工程`，与 `app` 平级新建 `lesson_03_token_alignment.py`，保存以下完整脚本：

```python
import math


def main():
    token_names = ["<BOS>", "猫", "睡", "<EOS>", "<PAD>"]
    pad_id = 4
    token_ids = [0, 1, 2, 3, 4]
    input_ids = token_ids[:-1]
    target_ids = token_ids[1:]
    correct_probabilities = [0.5, 0.25, 0.5, 0.0]
    total_loss = 0.0
    valid_count = 0
    for position in range(len(target_ids)):
        target_id = target_ids[position]
        if target_id == pad_id:
            print(position, "PAD：不计算损失")
            continue
        probability = correct_probabilities[position]
        loss = -math.log2(probability)
        total_loss += loss
        valid_count += 1
        input_name = token_names[input_ids[position]]
        target_name = token_names[target_id]
        print(position, input_name, "->", target_name, f"{loss:.6f} bit")
    print("有效位置数=", valid_count)
    print(f"平均损失={total_loss / valid_count:.6f} bit")


if __name__ == "__main__":
    main()
```

在该目录 PowerShell 运行：

```powershell
..\..\..\.venv\Scripts\python.exe lesson_03_token_alignment.py
```

命令使用根目录共享环境。预期输出：

```text
0 <BOS> -> 猫 1.000000 bit
1 猫 -> 睡 2.000000 bit
2 睡 -> <EOS> 1.000000 bit
3 PAD：不计算损失
有效位置数= 3
平均损失=1.333333 bit
```

`range(len(target_ids))` 按位置编号循环；`token_names[id]` 把编号转回方便阅读的文字。`continue` 提前进入下一轮，所以不会对第 4 个占位概率 0 取对数。不要先算 `log(0)` 再乘 0，后者不能消除前面的数学错误。

这个最小脚本使用固定非空数据。下面独立题将检查长度、有效概率和全无效的边界，不能把固定脚本直接当作通用训练损失函数。

## 常见错误

| 现象 | 原因与排查 | 修复 |
| --- | --- | --- |
| 模型学会复制输入 | 输入和目标相同 | 逐位置写出“已看到什么、要预测什么” |
| 原始长度 4 却写出 4 个下一词标签 | 擅自补了未知未来 | 检查是否真的提供了 EOS 或额外词 |
| 多补 PAD 后损失下降 | 分母用了补齐长度 | 分母只数参与监督的位置 |
| 没有学习停止 | EOS 也被当占位排除 | 本例 EOS 是有效目标 |
| `math domain error` | 对零概率取了对数 | 先跳过无效位置；有效目标概率为零则明确处理失败 |
| 所有位置无效仍返回 0 | 把无监督批次伪装成完美预测 | 明确拒绝或由训练流程按约定跳过，并记录原因 |

## 跟做练习：多补一个占位

把原始编号改为 `[0,1,2,3,4,4]`，正确目标概率改为 `[0.5,0.25,0.5,0.0,0.0]`。先预测有效位置数和均值，再运行。

> [!example]- 参考答案
> 输入与目标各变成 5 个位置，但有效位置仍为 3，平均损失仍为 `1.333333`。两个 PAD 行都在取对数前跳过。只改编号不改概率表虽然可能碰巧未访问多出的占位，也不构成正确的数据契约；两个列表应明确一一对应。

## 独立练习：比较按词与按句平均

新建 `lesson_03_masked_mean.py`。写 `masked_loss_totals(probabilities, keep_positions)` 返回损失总和与有效个数。长度必须相同；掩码是 Python 布尔值；只检查有效位置的概率且要求有限、`0<q<=1`；全无效时抛出错误，不返回零。

两条样本的正确目标概率为 A=`[0.5,0.25,0.5,0.0]`、B=`[0.25,0.0,0.0,0.0]`；相应有效掩码为 `[True,True,True,False]` 和 `[True,False,False,False]`。手算整个批次按有效 token 平均的损失；再与两条句子先各自平均、再等权平均的结果比较。

> [!example]- 完整参考答案与解析
> ```python
> import math
>
>
> def masked_loss_totals(probabilities, keep_positions):
>     if len(probabilities) != len(keep_positions):
>         raise ValueError("probabilities and mask must have the same length")
>     total = 0.0
>     count = 0
>     for probability, keep in zip(probabilities, keep_positions):
>         if type(keep) is not bool:
>             raise ValueError("mask entries must be bool")
>         if not keep:
>             continue
>         if type(probability) not in (int, float):
>             raise ValueError("valid probability must be a Python number")
>         if not math.isfinite(probability) or not 0 < probability <= 1:
>             raise ValueError("valid probability must be finite and in (0, 1]")
>         total -= math.log2(probability)
>         count += 1
>     if count == 0:
>         raise ValueError("no supervised positions")
>     return total, count
>
>
> def main():
>     total_a, count_a = masked_loss_totals([0.5, 0.25, 0.5, 0.0], [True, True, True, False])
>     total_b, count_b = masked_loss_totals([0.25, 0.0, 0.0, 0.0], [True, False, False, False])
>     token_mean = (total_a + total_b) / (count_a + count_b)
>     sequence_mean = (total_a / count_a + total_b / count_b) / 2
>     print(f"按有效 token 平均={token_mean:.6f} bit")
>     print(f"按句等权平均={sequence_mean:.6f} bit")
>     try:
>         masked_loss_totals([0.0], [False])
>     except ValueError as error:
>         print("预期拒绝：", error)
>
>
> if __name__ == "__main__":
>     main()
> ```
> 运行 `..\..\..\.venv\Scripts\python.exe lesson_03_masked_mean.py`。输出依次为 `1.500000 bit`、`1.666667 bit`、`预期拒绝： no supervised positions`。
>
> A 总损失 4、有效位置 3；B 总损失 2、有效位置 1。按 token 平均为 `(4+2)/(3+1)=1.5`；按句平均为 `(4/3+2)/2≈1.666667`。两种指标给样本的权重不同，都需要声明；本题要求前者，不能把后者冒充同一个指标。q=1 是有限的零损失，本函数允许；上一讲严格二分类练习排除端点是另一项明确接口选择。

## 迁移练习：提示词是否计入损失

一段训练对话包含“用户问题”和“助手回答”。如果任务只监督助手回答，用户问题应从输入里删除吗？提示：区分“作为条件可读取”与“作为预测目标计入训练”。

> [!example]- 参考答案
> 通常仍保留用户问题作为上下文，只在需要监督的助手目标位置计入损失。对齐时应看当前位置预测的**目标 token**属于哪个片段，不能仅按当前输入 token 的角色排除；否则可能漏掉第一个回答 token。具体模板、结束标记和边界取决于数据契约。前文仍要满足因果读取限制。后续详细实践见 [[01_学习指南/10_Tokenizer对话模板与训练样本/逐讲学习/04 给 assistant 目标构造 labels|助手标签构造]] 与 [[01_学习指南/10_Tokenizer对话模板与训练样本/逐讲学习/05 用两种 mask 组成批次|两类 mask]]。
