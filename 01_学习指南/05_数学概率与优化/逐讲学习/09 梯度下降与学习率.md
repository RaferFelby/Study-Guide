## 这一讲要解决什么问题

有了梯度之后，怎样更新参数才能让损失变小？梯度下降把参数沿负梯度方向移动；学习率决定每一步走多远。学习率太小会慢，太大可能震荡甚至发散。

## 前置知识

本讲需要会把一元函数写成公式，并理解“导数表示当前位置的变化方向和快慢”。如果对导数还不熟，先复习 [[01_学习指南/05_数学概率与优化/逐讲学习/08 链式法则与反向传播|第 8 讲中的导数与梯度]]。本讲先用一个简单的一维函数推导更新，再观察不同学习率造成的结果。

阅读顺序：先手算一步和三种学习率，再运行一维实验；第二次做二维独立练习，最后用排错表解释结果。函数、循环与变量赋值不熟时，先回看 [[01_学习指南/01_Python工程化/逐讲学习/01 运行Python并统计工单|Python 基础]]。本讲的小实验用普通 Python，不需 GPU。

## 从一元函数开始

对 f(w) = (w - 3)²，导数是 2(w - 3)。更新规则为：

~~~text
w_new = w_old - learning_rate × gradient
~~~

`w` 是当前参数，目标是让函数值尽量小，不是让参数越小越好。当 w 小于 3 时，梯度为负，减去负数会让 w 增大；当 w 大于 3 时，梯度为正，w 会减小。本函数在 3 处取得最小值 0；一般函数导数为零也可能是极大值或鞍点，不能仅凭梯度为零就判定训练成功。

令误差 `e = w - 3`，它表示当前参数离最小点 3 有多远。代入更新式可得 `e_new = (1 - 2 × learning_rate) × e_old`。这个因子能直接说明学习率的效果：

- `0 < learning_rate < 1` 时，因子的绝对值小于 1，误差会逐步缩小；因子为负时，参数会在最小点两侧来回移动，但距离越来越近。
- `learning_rate = 0.5` 时，因子为 0，从 `w = 0` 出发一步就到 `w = 3`。
- `learning_rate = 1` 时，因子为 -1，参数会在两侧等距离来回跳，不会收敛。
- `learning_rate = 1.1` 时，因子为 -1.2，误差每步放大 1.2 倍；损失每步放大 `1.2² = 1.44` 倍，所以本例会发散，而不只是轻微震荡。

这些结论只针对这里的固定学习率、精确梯度和一维二次函数。神经网络的梯度会受到数据、批次、模型结构和优化器状态影响，不能把 `1` 当成通用学习率上限。

## 多参数和批量

多个参数组成向量，梯度也组成同形状向量。每次更新必须保持参数和梯度形状一致。训练数据通常分为：

- 全批量梯度：使用全部样本，方向稳定但每步成本高。
- 随机梯度：一次使用一个样本，更新快但噪声大。
- 小批量梯度：在成本和稳定性之间折中，是常见选择。

平均损失和求和损失会产生不同梯度尺度，学习率不能脱离损失定义和批量大小讨论。

## 学习率实验

在 VS Code 打开 `01_学习指南/05_数学概率与优化/示例工程/`，集成终端运行 `Get-Location` 核对目录。新建 `lesson_05_rates.py`，保存：

~~~python
from app.optimization import quadratic_descent

for rate in (0.05, 0.5, 1.1):
    history = quadratic_descent(start=0.0, learning_rate=rate, steps=3)
    print("学习率：", rate)
    for step, (value, loss) in enumerate(history):
        print(step, round(value, 6), round(loss, 6))
~~~

运行 `..\..\..\.venv\Scripts\python.exe lesson_05_rates.py`，预期：

```text
学习率： 0.05
0 0.0 9.0
1 0.3 7.29
2 0.57 5.9049
3 0.813 4.782969
学习率： 0.5
0 0.0 9.0
1 3.0 0.0
2 3.0 0.0
3 3.0 0.0
学习率： 1.1
0 0.0 9.0
1 6.6 12.96
2 -1.32 18.6624
3 8.184 26.873856
```

每组下面三列是步骤编号、当前参数、当前损失；第 0 行是更新前状态，所以 steps=3 会有四行。配套 [optimization.py](../示例工程/app/optimization.py) 的函数返回 `(参数,损失)` 元组组成的列表。`enumerate` 同时给出序号和该元组，`(value,loss)` 进一步解包；`round(...,6)` 将显示结果保留到六位小数，未修改真实更新值。

先手算学习率 0.05 的第一步：梯度为 −6，参数变为 0.3，损失为 7.29；这与表中第 1 行相符。0.5 一步到达 3，1.1 则越跳越远。把 steps 改为 50 后，0.05 的最后参数约 2.984539、损失约 0.000239；1.1 的损失仍增长。函数拒绝非正或非有限学习率，遇到 ValueError 应先检查输入；任意大数与极多迭代还可能溢出，当前实验不覆盖它们。

再在文件末尾加入单调性检查。单调不增表示后一项不大于前一项，允许相等；我们在这个小实验使用 1e-12 绝对容差：

```python
for rate in (0.05, 0.5, 1.1):
    history = quadratic_descent(start=0.0, learning_rate=rate, steps=3)
    is_nonincreasing = True
    for index in range(1, len(history)):
        previous_loss = history[index - 1][1]
        current_loss = history[index][1]
        if current_loss > previous_loss + 1e-12:
            is_nonincreasing = False
    print(rate, is_nonincreasing)
```

此段依赖前一段的导入，继续保存为同一文件再运行。末尾应增加 `0.05 True`、`0.5 True`、`1.1 False`。`history[index][1]` 先取第 index 条记录，再取其损失；不把参数坐标当损失检查。完成判断：解释为什么已经到达 0 后保持不变也算 True。真实小批次损失含噪声，不要求每步单调；若存在 NaN，必须先检查有限值，因为与 NaN 比较不能正常判断大小。

## 常见优化改进

- 动量保存部分过去的更新方向，减少狭长谷底中的来回摆动。
- 学习率调度随训练阶段变化，例如预热后衰减。
- Adam 对梯度的一阶和二阶统计做自适应缩放，但额外状态和超参数也会增加复杂度。
- 梯度裁剪限制极端梯度的大小，常用于处理训练不稳定。

这些方法解决的是不同问题，不要把“换优化器”当作所有损失异常的万能修复。先检查数据、标签、损失、形状和梯度。

## 偏差—方差的连接

偏差描述方法反复从数据学习时，其平均预测与真实规律之间的系统性差异；过于简单的模型可能有高偏差。方差描述换一批训练数据后预测有多大变化。训练好、验证差可能提示过拟合，也可能来自分布变化或数据问题，单次结果不足以证明完整的偏差—方差分解。优化器影响找参数的过程，降低训练损失不保证泛化变好；调参使用验证数据，最终测试集保留到方案确定后再评估。

## 动手操作

1. 手算第一步后运行 quadratic_descent，比较三个学习率的损失历史。
2. 把 steps 从 3 改为 50，观察小学习率是否只是收敛较慢。
3. 设置一个明显过大的学习率，记录损失变大的过程。
4. 为 history 增加“是否单调下降”的检查；说明在噪声梯度下为什么不一定单调。

## 常见错误

- 只看最后一个损失，不看中间是否发散或震荡。
- 学习率单位和梯度尺度不匹配，换了损失归一化却不调整。
- 把训练集损失下降当成泛化证明。
- 看到 Adam 就默认一定比普通梯度下降更好，忽略任务、调参和可解释性。

## 练习与答案解析

### 跟做练习：更新一步

当前 `w = 0`，目标点为 3，学习率为 0.1。求梯度和更新后的 `w`，并计算误差绝对值从更新前到更新后缩小了多少比例。

> [!example]- 参考答案
> 梯度是 `2(0 - 3) = -6`，更新后 `w = 0 - 0.1×(-6) = 0.6`。更新前误差绝对值为 3，更新后为 `|0.6 - 3| = 2.4`，因此这一步把误差缩小了 20%。它向目标点移动，但还没有到达目标。

### 独立练习

实现二维函数 f(x, y) = x² + 4y² 的梯度下降。比较相同学习率下 x 和 y 的收敛速度，解释曲率不同带来的影响。

从 `(x,y)=(1,1)` 出发，分别比较学习率 0.1 与 0.3，各更新三步。先写偏导数 `∂f/∂x=2x`、`∂f/∂y=8y`，每步两个梯度都从同一组旧参数计算。曲率在这里表示沿该方向弯曲的程度；y 的系数更大，同一偏移对应更大的梯度。提示：记录初始状态，用两个梯度变量再更新。

> [!example]- 独立练习完整答案与解析
> 在同一工程另存 `lesson_05_two_parameters.py`：
> ```python
> import math
>
> def descend_two_parameters(x, y, learning_rate, steps):
>     if not all(math.isfinite(value) for value in (x, y, learning_rate)):
>         raise ValueError("初始参数与学习率必须有限")
>     if learning_rate <= 0:
>         raise ValueError("学习率必须为正")
>     if type(steps) is not int or steps < 0:
>         raise ValueError("更新次数必须为非负整数")
>     history = [(x, y, x * x + 4 * y * y)]
>     for _ in range(steps):
>         gradient_x = 2 * x
>         gradient_y = 8 * y
>         x = x - learning_rate * gradient_x
>         y = y - learning_rate * gradient_y
>         loss = x * x + 4 * y * y
>         if not all(math.isfinite(value) for value in (x, y, loss)):
>             raise ValueError("更新产生非有限值，请检查步长与迭代规模")
>         history.append((x, y, loss))
>     return history
>
> for rate in (0.1, 0.3):
>     print("学习率：", rate)
>     history = descend_two_parameters(1.0, 1.0, rate, steps=3)
>     for step, (x, y, loss) in enumerate(history):
>         print(step, round(x, 6), round(y, 6), round(loss, 6))
> ```
> 运行 `..\..\..\.venv\Scripts\python.exe lesson_05_two_parameters.py`。`math.isfinite` 判断值是否不是 NaN 或无穷；`all` 要求这些检查全部为 True，括号中的生成器逐项提供检查结果。`_` 表示循环计数在这里不用；返回列表保留每步三元组，便于比较，不是用于超长训练的日志方案。
>
> 0.1 的三次更新分别为 `(0.8,0.2,0.8)`、`(0.64,0.04,0.416)`、`(0.512,0.008,0.2624)`，初始损失为 5。0.3 则为 `(0.4,-1.4,8.0)`、`(0.16,1.96,15.392)`、`(0.064,-2.744,30.12224)`。用六位小数核对，零的显示和微小舍入差异正常。
>
> 原因是 `x_new=(1−2η)x`、`y_new=(1−8η)y`，η 是学习率。两坐标都收敛需同时满足因子绝对值小于 1，对本函数为 `0<η<0.25`。η=0.1 时 y 比 x 更快接近零；η=0.3 时 x 虽缩小，y 却交替放大，导致总损失增长。η=0.25 时 y 等幅振荡。完成判断：解释为何不能只观察 x；再把 steps 改为 0，应只返回初始状态，负数或小数次数应报错。这些边界不是神经网络的通用学习率规则。

### 迁移练习

为一个分类训练实验设计学习率排错表：损失为 nan、损失几乎不变、损失剧烈震荡、训练集下降但验证集变差时，分别优先检查什么。

每项写“现象 → 先检查什么 → 一次只改什么 → 如何确认”。可以参考下一单元 [[01_学习指南/06_PyTorch训练闭环/逐讲学习/07 训练故障排查|训练故障排查]]，但先用本节更新规则自己判断。

> [!example]- 迁移练习参考排错表
>
> | 现象 | 先检查 | 下一步单变量实验 | 确认依据 |
> | --- | --- | --- | --- |
> | NaN／无穷 | 输入、标签、前向、损失、梯度在哪一步先失去有限性；是否有非法除法或对数 | 若确定更新后才异常，保持数据与模型不变，只降低学习率重跑 | 首次异常的位置和新结果有记录，不把降低学习率当所有 NaN 的修复 |
> | 损失几乎不变 | 梯度是否存在、参数是否更新、是否清梯度后忘记 backward／step、显示精度、学习率是否接近零 | 若更新流程正确，只试一个更合适步长，在相同小数据上核对 | 前后参数、梯度与更多有效小数，不只看四舍五入的日志 |
> | 剧烈震荡 | 当前学习率、标签对应、批次大小、损失求和还是平均、是否混看不同批次 | 先固定一批数据，只降低学习率 | 同一输入的损失与梯度轨迹改善，不能把随机批次变化都归因于步长 |
> | 训练下降、验证变差 | 划分、重复与分布变化、验证是否 eval 且关闭梯度、训练／验证指标是否同口径 | 先排除计算错误；再固定其他条件尝试早停或正则化之一 | 用验证集比较并保留旧基线，最终测试集不反复用于调参 |
>
> 完成判断：四种现象均包含可执行检查、具体改动和观察依据；能解释损失下降与新数据效果之间为什么不是等号。单次曲线不能唯一确定错误原因。

## 本讲小结

梯度给方向，学习率给步长，损失历史告诉你更新过程。优化要和数据、模型、损失及泛化一起观察，不能只比较最终训练数字。
