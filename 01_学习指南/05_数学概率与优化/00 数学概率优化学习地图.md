## 开始前：打开示例工程

第 1 讲先创建 `lesson_01_matrix.py`，比较一维／列向量、转置与重排，再做形状检查和批量乘法练习。之后进入 [[01_学习指南/05_数学概率与优化/逐讲学习/02 按轴计算并分清数组视图与副本|数组详细课]]，观察 axis、切片和复制。第 5 讲进入 [[01_学习指南/05_数学概率与优化/逐讲学习/05 从指数与对数走到稳定softmax|数值详细课]]，从指数／对数计算一行概率，再检查大分数、归一化轴和失败输入；第 6 讲再将这些基础用于熵与交叉熵。

1. 在 VS Code 中打开 01_学习指南/05_数学概率与优化/示例工程/。
2. 按仓库首页的共享环境说明选择根目录 `.venv`，在本示例工程目录运行 `..\..\..\.venv\Scripts\python.exe -m unittest discover -s tests -v`。
3. 示例工程需要 NumPy；如果环境没有，先确认共享解释器，再按根 README 说明版本、位置和用途并获得安装批准。
4. PyTorch 自动求导是第 8 讲的可选验证。没有安装 PyTorch 时，先使用纯 Python 手算和有限差分完成同一逻辑。

第 3 讲提供 `lesson_02_probability.py` 的完整调用与预期数字；第 8 讲先从变化率补讲导数和偏导，再通过 `lesson_04_difference.py` 核对梯度。若仍不熟悉函数和循环，先复习 [[01_学习指南/01_Python工程化/逐讲学习/01 运行Python并统计工单|Python 第 1 讲]]，不要只运行工程测试就跳过这些手算与练习。

[[01_学习指南/05_数学概率与优化/逐讲学习/06 熵交叉熵与KL散度|第 6 讲：熵交叉熵与KL散度]]先创建 `lesson_03_information.py` 比较熵、交叉熵和 KL，再用 `lesson_03_boundaries.py` 检查零目标、零预测和极小正概率。独立完成二分类损失后，进入 [[01_学习指南/05_数学概率与优化/逐讲学习/07 对齐下一个词并只统计有效损失|下一词与有效损失详细课]]，画对齐表、区分 EOS 与 PAD、比较有效 token 平均和句子平均，再进入第 8 讲。

第 3 讲完成概率与参数估计后，第 4 讲进入 [[01_学习指南/05_数学概率与优化/逐讲学习/04 用具体数据理解概率分布|概率分布详细课]]，完成二项概率、均值与标准差、连续区间概率，结合上一讲的最大似然解释参数与观测。相关课程与示例只用 Python 标准库，复用共享环境，不需新增依赖。
