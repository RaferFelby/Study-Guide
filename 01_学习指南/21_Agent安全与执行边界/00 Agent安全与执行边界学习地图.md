## 运行与验收

示例工程终端使用根共享环境：

```powershell
..\..\..\.venv\Scripts\python.exe demo.py
..\..\..\.venv\Scripts\python.exe -m pytest -q tests
```

六提议全部按预期拒绝；合法Alice读取成功；批准后仅创建一份内存工单，重复回同ID，改subject需要重新确认；审计链校验True。没有真实账户或外部写操作。

完成标准：身份/角色/批准不从模型字段取；跨用户读取拒；资料指令不增权；写前比完整动作；重复不新增；拒绝留审计；明确文件检查与系统隔离区别；攻击集通过仍报告残余风险。
